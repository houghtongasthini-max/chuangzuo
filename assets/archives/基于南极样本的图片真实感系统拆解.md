# 基于南极样本的图片真实感系统拆解

当前资料实际包含一条完整作品：**1张封面重复图＋30张连续正文图**。内容以“南极研究生参加冬季观测项目”为现实入口，并明确标注为AI虚构作品。

因此，下面所说的“稳定共性”，主要指这条作品内部反复使用、已经形成系统的真实感机制；不能直接视为多位作者、多条作品的统计结论。

------

## 1. 总结判断

这组图片最核心的真实感，不是来自“画面足够清楚”，也不是来自“看起来像手机拍摄”，而是来自一条完整的：

> **现实经历记录 → 工作过程记录 → 仪器发现异常 → 多设备交叉求证 → 人员实地接近 → 最终奇观兑现**

它没有一开始就展示冰墙、外星人或地下文明，而是先用校园、城市、同学合照、打包设备、运输机、科考站、仪器维护等大量普通画面，建立一份近似真实相册和工作日志的可信底盘。

异常最初也不是直接出现在一个“很酷的怪物特写”里，而是依次出现在：

- 远距离监测画面；
- 笔记本照片序列；
- 雪地痕迹；
- 无人机遥控器；
- 热成像界面；
- 车辆前方；
- 冰墙和洞口；
- 最终地下世界。

所以，这组作品真正有效的部分，是它把“不可能事件”包装成了一个**逐步生成的证据链**。

其中最值得继承的是前23张的纪实逻辑。第24张之后开始切换画幅、摄影语言和视觉质感；第30—31张虽然奇观回报很强，但已经明显接近科幻概念图，摄影机来源、曝光结果和现实材质感都开始减弱。

一句话概括：

> **真实感不是单张图片的风格，而是整组画面共同证明“这件事曾被某些人、用某些设备、在某个过程中记录下来”。**

## A. 这条作品内部稳定存在的真实感共性

这些是后续最值得继承的底层方法：

1. **先记录现实，再记录异常。**
2. **人物始终在做事，而不是展示自己。**
3. **每张图背后都有可推断的拍摄者。**
4. **异常最初只占画面很小的比例。**
5. **重要证据往往通过仪器或二次屏幕出现。**
6. **人物、衣服、设备箱、车辆等持续作为连续性锚点。**
7. **现场光线不均匀，允许暗部、偏色和局部过曝。**
8. **最终奇观之前，至少经历两轮以上求证。**
9. **环境中存在大量不服务剧情的普通细节。**
10. **连续图片通过行动和证据升级，而不是单纯换机位。**

------

## B. 只在部分画面中出现的可选技巧

这些可以按题材选择，并非每次必用：

- 出发前团队合照；
- 电脑屏幕中的异常序列；
- 无人机视角或无人机控制器；
- 热成像、红外、雷达等专业成像；
- 车内追踪视角；
- 人物站在巨物前提供尺度；
- 洞穴中的手电探索；
- 从黑暗空间逐渐走向高亮出口；
- 横竖画幅混用；
- 最终超现实城市或宏大文明揭示。

其中，**专业设备、车内视角和屏幕证据属于有效可选技巧**。

而**无理由切换画幅、突然转成概念艺术、奇观画面失去拍摄者**，不应作为稳定方法继承。

# 3. 十大真实感设计规律

## 规律一：先建立“摄影机合同”

### 规律

生成每张图前，先确定：

- 谁在拍；
- 用什么拍；
- 为什么此刻拍；
- 拍摄者站在哪里；
- 主体是否知道自己被拍。

### 为什么有效

用户会本能判断一个镜头是否可能存在。

只要机位没有现实来源，即使人物、冰雪和材质都很逼真，画面仍然会像电影剧照或AI概念图。

### 后续怎么用

不要先写“宏伟冰墙前站着一个人”。

先写：

> 同行驾驶员停下车辆后，从副驾驶座拿手机隔着半开的车门记录前方冰壁，车门边缘和仪表台进入前景。

摄影机有了位置，真实感才有骨架。

------

## 规律二：现实信息必须长期占据多数

### 规律

在异常真正爆发前，画面里应有足够多的普通世界：

- 正常场所；
- 普通行动；
- 工作过程；
- 人际关系；
- 设备准备；
- 没有异常的等待。

### 为什么有效

前段普通画面是在积累“信任资本”。

异常越不可能，前面越需要证明：这群人、这些设备、这个空间和这段行动是真实存在的。

### 后续怎么用

整组图可大致遵循：

- 前30%：现实与身份；
- 中间40%：异常线索和求证；
- 后30%：风险升级与视觉兑现。

不必机械套比例，但不要第一张就把最大奇观全部亮出来。

------

## 规律三：动作比面孔更能证明人物真实

### 规律

人物应处在具体动作中：

- 搬箱子；
- 看地图；
- 接线；
- 检查仪器；
- 蹲下观察；
- 驾驶；
- 举起遥控器；
- 向同伴指认异常。

### 为什么有效

模特是在“被看”，真实人物是在“处理事情”。

动作会自然决定身体姿态、目光方向、手的位置和衣服褶皱，减少AI常见的摆拍感。

### 后续怎么用

每个人物画面至少让一只手被工作占用，目光落在任务对象上。

除非剧情需要合照，否则不要让人物正面看镜头。

------

## 规律四：异常首先应该成为“证据”，而不是“主角”

### 规律

异常第一次出现时，应尽量：

- 距离远；
- 尺寸小；
- 位于边缘；
- 被部分遮挡；
- 出现在屏幕或反射里；
- 只有少量特征可以确认。

### 为什么有效

直接把怪物、神明或巨物摆到画面正中央，是展示逻辑。

先让它以痕迹、数据或模糊轮廓出现，则是发现逻辑。

真实事件通常先产生疑问，再产生结论。

### 后续怎么用

异常升级可以采用：

> 模糊轮廓 → 连续帧仍存在 → 地面痕迹 → 其他设备确认 → 现场目击 → 完整揭示。

------

## 规律五：物理互动比单纯“画得逼真”更重要

### 规律

异常必须和现实环境发生关系：

- 被前景遮挡；
- 在地面留下压痕；
- 反射在水面或玻璃上；
- 被车灯照亮；
- 投下阴影；
- 推动积雪、灰尘、雾气或植被；
- 在热成像、雷达或监控中留下对应结果。

### 为什么有效

贴图感的本质，不是材质不够高清，而是异常和环境彼此不认识。

### 后续怎么用

每个异常至少满足三项：

1. 同一光源；
2. 合理遮挡；
3. 尺度参照；
4. 接触关系；
5. 环境反馈。

------

## 规律六：光线必须来自现场，而不是来自导演

### 规律

画面主要光源应能够被指出：

- 顶灯；
- 路灯；
- 手机屏幕；
- 仪器灯；
- 车灯；
- 手电；
- 窗外自然光；
- 火光；
- 极光或月光。

### 为什么有效

真实记录通常无法随意补光，所以人物面部可能偏暗、背景可能看不清、不同区域色温也不一致。

这种不完美反而建立现场感。

### 后续怎么用

一张图只确定一至两个主光源。

不要同时加入逆光、轮廓光、体积光、柔光补脸和地面反光。

情绪应来自现实光源的强弱和方向，而不是增加摄影棚灯。

------

## 规律七：环境要有“不为剧情服务的东西”

### 规律

真实空间必须包含一些普通、无戏剧功能的细节：

- 半开的抽屉；
- 用过的杯子；
- 乱放的线缆；
- 皱掉的地图；
- 普通塑料袋；
- 磨损的地面；
- 不整齐的衣服；
- 标签和胶带；
- 被遮住一半的设备。

### 为什么有效

概念图中的每个物体都在服务主题；真实空间中的大多数物体只是因为人们生活和工作而存在。

### 后续怎么用

每个主要场景加入三至五个“非剧情性细节”，但不要刻意把环境弄成垃圾场。

真实是使用痕迹，不是脏乱滤镜。

------

## 规律八：连续性靠固定锚点，变化性靠新动作

### 规律

连续图片中应固定：

- 核心人物；
- 服装；
- 标志性道具；
- 车辆；
- 场景结构；
- 时间和天气逻辑。

同时不断改变：

- 人物动作；
- 所在位置；
- 证据类型；
- 镜头距离；
- 风险等级；
- 拍摄媒介。

### 为什么有效

全变会像拼图；全不变会像重复生图。

真实连续叙事必须在“同一件事”与“事情正在发展”之间保持平衡。

### 后续怎么用

相邻两张至少改变两个维度，但保留两个以上连续锚点。

例如：

> 同一人物＋同一无人机，上一张在雪地起飞，下一张改为遥控器屏幕发现痕迹。

------

## 规律九：成像缺陷必须由拍摄条件产生

### 规律

低照度噪点、轻微虚焦、过曝、屏幕反光、透视偏斜等缺陷，都必须有原因。

### 为什么有效

真正的成像缺陷是不均匀、局部和偶发的。

故意在整张图上叠加统一颗粒、色差、划痕和模糊，会产生“装旧滤镜感”。

### 后续怎么用

每张图只选一至两种符合情境的缺陷：

- 夜间：高ISO颗粒、暗部彩噪；
- 走动中：轻微动态虚焦；
- 拍屏幕：摩尔纹、反光、透视偏斜；
- 强光出口：局部高光溢出；
- 车内：玻璃反射和前景遮挡。

------

## 规律十：最终视觉回报可以宏大，但不能脱离记录系统

### 规律

高潮可以极其壮观，但至少保留一个现实锚点：

- 人物；
- 门框；
- 车辆；
- 手电；
- 设备屏幕；
- 洞口；
- 建筑边缘；
- 摄影者身体的一部分。

### 为什么有效

观众需要同时感受到：

> “这个东西太不可思议了。”

以及：

> “某个人真的站在这里看到了它。”

第30—31张地下城市的视觉回报很强，但因为高亮、整洁、对称、无人和缺乏摄影者位置，开始更像科幻设定图。

### 后续怎么用

奇观画面不要完全抛弃前景。

比起纯净全景，更真实的方式是：

- 隔着洞口看；
- 隔着破损车窗看；
- 从人的肩后看；
- 被岩壁遮住一部分；
- 镜头因为强光而局部过曝；
- 画面无法完整装下巨物。

------

# 4. 五大假感来源

## 一、摄影机不存在

这是最致命的问题。

典型表现：

- 主角独自行动，却总有摄影师从十米外跟拍；
- 危险发生时仍出现完美正面全身照；
- 巨物前使用低机位英雄构图；
- 镜头悬浮在人物头顶或洞穴半空；
- 拍摄者没有可以站立的位置。

用户不会认真计算机位，但会本能觉得“这张图不可能被拍到”。

------

## 二、画面首先追求漂亮，而不是可信

典型表现：

- 主体永远位于黄金分割；
- 大量完美对称；
- 电影式冷暖对撞；
- 人物面部始终有柔光补亮；
- 大光圈虚化背景；
- 每张都是壁纸和海报级构图。

真实记录允许画面好看，但好看应该是事件本身带来的，而不是每张图都被精密布光和设计。

------

## 三、人物和环境过于洁净

典型表现：

- 所有人都像演员；
- 皮肤平滑、五官高度对称；
- 衣服全新，没有穿着痕迹；
- 工作空间干净得像展厅；
- 工具按颜色和尺寸整齐排列；
- 背景空旷，只放剧情所需物品。

真实空间具有冗余、摩擦和使用痕迹。

------

## 四、异常只是贴在背景上

典型表现：

- 没有接触阴影；
- 光线方向不同；
- 尺度无法判断；
- 前景永远不会遮挡异常；
- 周围人物和环境不受影响；
- 只靠发光、闪电、红雾和粒子特效表现异常。

异常越华丽，越需要更多物理关系支撑。

------

## 五、连续图片之间视觉系统崩溃

典型表现：

- 人物长相变化；
- 衣服和设备突然替换；
- 时间、天气和光线无过渡；
- 横图、竖图、监控和电影画面随意切换；
- 前一张还是工作手机照片，下一张变成科幻游戏CG；
- 同一环境反复换角度，却没有新信息。

这条样本在第24张以后就出现了部分这种问题，尤其是最终城市画面和前段科考记录之间的成像语言差距过大。

------

## 《这类内容最容易翻车的假感来源清单》

| 假感来源         | 常见表现                                         |
| ---------------- | ------------------------------------------------ |
| 海报感           | 主体居中、姿态完整、背景干净、构图为标题预留空间 |
| 摆拍感           | 人物停下动作看镜头，手脚刻意摆放                 |
| 演员感           | 精致脸、统一妆容、强烈表情管理                   |
| 概念图感         | 空间只表达一个主题，没有生活和使用痕迹           |
| 电影剧照感       | 摄影师机位过于专业，灯光戏剧性过强               |
| 过度精修感       | 全画面锐利、皮肤无纹理、色彩统一高级             |
| 故意低清装真     | 全屏噪点、划痕、失焦、压缩块同时出现             |
| 滤镜感           | 固定青橙色、绿色夜视或复古色覆盖所有场景         |
| 无来源戏剧光     | 环境没有灯，人物却被漂亮轮廓光照亮               |
| 异常特效廉价化   | 霓虹边缘、浓雾、闪电、红眼、粒子乱飞             |
| 背景空洞         | 除主角和剧情道具外没有任何普通物件               |
| 镜头不成立       | 拍摄者无法站在该位置，或没有理由继续拍           |
| 连续分镜重复     | 同一地点、同一动作、同一信息，只改变角度         |
| 媒介无理由切换   | 手机、航拍、监控、电影镜头混用却无来源解释       |
| 奇观脱离物理世界 | 无尺度、无空气透视、无遮挡、无环境反馈           |

# 5. 对标作品真实感方法库

## 5.1 影像来源方法

### 可直接用于创作的约束

> 每张图片必须预先指定一种现实影像来源：手机照片、普通相机、视频截帧、监控画面、车载记录、无人机、设备屏幕、新闻照片、档案扫描或专业检测图像。

> 同一段落以一种主要媒介为主，只有当人物行动或求证方式发生变化时，才切换媒介。

> 媒介切换必须带来新的证据能力，而不是单纯为了换视觉风格。

例如：

- 手机无法看清远处，因此使用无人机；
- 普通画面无法判断温度，因此切换热成像；
- 现场无法进入，因此查看监控；
- 需要确认时间连续性，因此查看照片序列。

------

## 5.2 拍摄者逻辑方法

每张图必须能回答四个问题：

1. 谁在拍？
2. 为什么拍？
3. 从哪里拍？
4. 为什么没有拍得更好？

第四个问题很重要。

真实照片经常不完美，是因为拍摄者：

- 正在走路；
- 穿着手套；
- 需要保持距离；
- 只能隔着玻璃；
- 光线不足；
- 来不及重新构图；
- 同时还在操作其他设备。

------

## 5.3 镜头方法

### 建立正常现实

使用：

- 平视广角；
- 普通中景；
- 人物和环境同时出现；
- 拍摄距离符合同行者站位；
- 构图略松，不突出戏剧中心。

### 发现异常

使用：

- 肩后；
- 门外；
- 车内；
- 局部遮挡；
- 异常位于远处或边缘；
- 人物先注意到，镜头后跟随。

### 证据确认

使用：

- 屏幕近景；
- 手持设备；
- 仪器读数；
- 地面痕迹；
- 局部材质；
- 同一异常的连续帧对照。

### 高潮兑现

使用：

- 带人物或建筑参照的大全景；
- 洞口、门框和车窗作为画框；
- 巨物超出画面；
- 允许局部过曝或看不完整；
- 保留摄影者所在现实空间。

------

## 5.4 人物方法

### 可直接用于创作的约束

> 人物使用普通、可辨认但不明星化的面孔，保留轻微面部不对称、疲惫、风吹乱的头发、眼镜压痕和真实皮肤纹理。

> 人物大多数时间正在执行动作，目光落在工具、同伴或异常上，不正面展示脸。

> 服装首先服从天气、职业和行动需求，其次才考虑颜色搭配。

> 固定一至两个可持续识别的人物锚点，例如眼镜、帽子、衣服补丁、背包或手套。

### 如何做到“普通但不无聊”

普通不等于没有辨识度。

辨识度可以来自：

- 特定眼镜；
- 不同穿衣习惯；
- 固定工具；
- 动作习惯；
- 人物之间的职责关系；
- 谁总在记录、谁总在操作、谁总在判断。

------

## 5.5 环境方法

### 可直接用于创作的约束

> 场景中至少保留三类非剧情性细节：使用中的物件、长期磨损痕迹和临时摆放物。

> 物品摆放必须服从使用顺序，而不是构图美感。

> 不清空背景，不把所有杂物集中到画面边缘，不让空间像刚布置完成的摄影棚。

有效环境细节包括：

- 磨损的箱角；
- 胶带和编号；
- 卷起的电线；
- 半张露出的表格；
- 湿鞋印；
- 雪水和泥点；
- 墙面残留标记；
- 不同年代的设备；
- 不统一的椅子和容器。

------

## 5.6 光线方法

### 可直接用于创作的约束

> 画面只使用场景内真实存在或能够合理推断的光源。

> 保留混合色温、局部照明和自然暗部；不要求人物脸部始终清楚。

> 情绪通过真实光源的位置、范围和强弱建立，不额外添加电影式轮廓光。

实用组合：

- 冷白顶灯＋暖色台灯；
- 车灯＋仪表盘；
- 手电＋黑暗环境；
- 屏幕光＋室内微弱顶灯；
- 路灯＋店铺灯；
- 阴天自然光＋室内灯；
- 火光＋环境冷光。

------

## 5.7 异常融合方法

异常必须通过“五个接口”接入现实：

### 光线接口

异常受到同一现场光源影响。

### 空间接口

异常能够被前景、人物、建筑或天气遮挡。

### 材质接口

异常表面反应符合材料属性，不全部使用高亮金属、湿润皮肤或霓虹光。

### 接触接口

异常与地面、墙面、水面、空气或物体产生接触结果。

### 证据接口

异常可以被至少两种不同证据确认，例如：

- 目视＋热成像；
- 监控＋脚印；
- 雷达＋现场声响；
- 无人机＋地面拍摄；
- 屏幕记录＋物理残留。

------

## 5.8 连续分镜防重复方法

相邻图片至少改变以下六项中的两项：

1. 拍摄位置；
2. 人物动作；
3. 景别；
4. 证据类型；
5. 影像来源；
6. 风险等级。

同时至少保留两项连续锚点：

- 同一人物；
- 同一服装；
- 同一道具；
- 同一场景结构；
- 同一天气；
- 同一异常特征。

最稳定的三图单元是：

> **建立现场 → 人物采取行动 → 得到新证据**

例如：

1. 人物在雪地布置仪器；
2. 回到室内查看数据；
3. 屏幕中出现无法解释的轮廓。

------

## 5.9 媒介切换方法

媒介切换不能只是“换种好看的画面”。

正确逻辑：

> 手机看不清 → 无人机接近
> 无人机无法判断性质 → 热成像确认
> 设备失去目标 → 车辆实地追踪
> 车辆无法进入 → 人员步行探索

错误逻辑：

> 手机照片 → 无理由航拍 → 电影特写 → 监控画面 → 概念艺术

------

## 5.10 最终视觉回报方法

最终画面可以突破前段的视觉规模，但必须保留：

- 一个拍摄者位置；
- 一个现实尺度；
- 一个前景遮挡；
- 一种前面已经出现过的成像特征。

例如地下文明揭示，不宜直接生成纯净城市全景。

更可信的方式是：

> 从狭窄湿滑的洞口向外拍摄，洞壁和积水占据前景，出口强光局部溢出，远处城市只有部分结构清楚，上方飞行器被洞顶裁掉一半。

------

# 6. 可直接复用的真实性写法模板

## 6.1 影像来源模板

> 由【拍摄者身份】使用【设备类型】在【具体行动状态】下记录的【照片／视频截帧／工作影像】，属于临时记录而非宣传拍摄，保留设备自动模式产生的自然成像结果。

------

## 6.2 拍摄者逻辑模板

> 镜头位于【拍摄者真实可站立的位置】，拍摄者因为【记录任务／向同伴汇报／保存证据／确认异常】举起设备，视线受到【门框／车窗／前方人物／设备】部分限制，不使用无人存在的上帝视角。

------

## 6.3 镜头机位模板

> 【景别】，机位约在【胸口／眼睛／腰部】高度，从【人物侧后方／肩后／门外／车内／桌边】拍摄，主体不正对镜头，构图略偏，关键异常位于【中远景／画面边缘／局部遮挡后方】。

------

## 6.4 环境细节模板

> 空间保留真实使用状态，可见【工具、耗材、线缆、记录表、普通容器、磨损痕迹】，物品摆放有工作顺序但并不整齐，不做展览式陈列，背景包含少量与剧情无直接关系的普通杂物。

------

## 6.5 自然光源模板

> 现场主要由【顶灯／路灯／窗光／车灯／手电／屏幕／火光】照明，光线覆盖不均匀，近处可能稍亮或局部过曝，远处自然沉入暗部，保留轻微混合色温，不增加摄影棚补光和无来源轮廓光。

------

## 6.6 人物普通感模板

> 【年龄和身份】的普通人物，面部存在轻微不对称和真实皮肤纹理，发型受【风、帽子、湿气或长时间工作】影响，神情专注或疲惫，正在【具体动作】，目光看向【任务对象】，不看镜头，不摆英雄姿势。

------

## 6.7 成像缺陷模板

> 保留由拍摄条件自然产生的【轻微高ISO颗粒／自动白平衡偏移／屏幕反光／边缘轻度畸变／走动中的局部虚焦／强光区域溢出】，缺陷只出现在合理区域，不添加统一复古滤镜和全画面人为噪点。

------

## 6.8 拍摄屏幕模板

> 手机近距离拍摄【电脑／仪器／遥控器】屏幕，屏幕存在轻微透视倾斜、亮度压过周围环境、局部反光或摩尔纹，设备边框、操作人员手部和周围桌面进入画面，界面信息清楚但不是完美平面截图。

------

## 6.9 异常融合模板

> 异常位于【现实空间位置】，受到现场【光源】照射，被【人物／设备／门框／环境结构】部分遮挡，与【地面／墙面／水面／积雪】产生真实接触，并留下【阴影、反射、压痕、湿痕、积雪扰动或热成像结果】，不使用独立霓虹描边。

------

## 6.10 巨物奇观模板

> 巨物无法被镜头完整容纳，部分结构超出画面，以【人物、车辆、建筑、树木或道路】提供尺度参照，远处细节受到空气透视、天气和拍摄距离影响，避免把巨物完整、清晰、居中地展示成海报。

------

## 6.11 负面约束模板

> 非海报，非电影剧照，非科幻概念艺术，非摄影棚摆拍，非英雄站姿，非模特脸，非完美对称构图，非大光圈人像虚化，非统一青橙调色，非无来源戏剧光，非夸张体积光，非霓虹边缘光，非全画面锐化，非故意低清装真，非空洞背景，非异常贴图。

------

# 7. 《AI伪纪实连续图片创作的真实感设计底座》

## 一、核心定义

AI伪纪实图片不是把AI画面做旧，也不是把奇幻内容改成手机摄影。

它的本质是：

> **为一个不可能事件，建立一套可以成立的现实记录系统。**

真实感由四部分共同组成：

1. 拍摄行为可信；
2. 现实环境可信；
3. 异常物理关系可信；
4. 连续证据链可信。

------

## 二、每张图必须具备的七项信息

生成每张图前，必须内部确认：

1. **影像来源**：什么设备或媒介；
2. **拍摄者**：谁在记录；
3. **拍摄动机**：为什么此刻拍；
4. **机位位置**：拍摄者实际站在哪里；
5. **人物任务**：画面中的人正在做什么；
6. **现场光源**：光从哪里来；
7. **新增证据**：这张图比上一张多告诉了什么。

缺失其中三项以上，画面通常会退化成展示图。

------

## 三、整组图片的基础结构

### 第一阶段：建立可信世界

- 人物身份；
- 普通环境；
- 工作或生活流程；
- 主要道具；
- 人物关系；
- 正常状态。

### 第二阶段：产生微小异常

- 小型错误；
- 远处轮廓；
- 设备读数；
- 不符合常理的痕迹；
- 不确定证据。

### 第三阶段：主动求证

- 更换设备；
- 靠近现场；
- 对照记录；
- 请求同伴确认；
- 发现不同证据相互吻合。

### 第四阶段：风险升级

- 异常开始影响行动；
- 环境发生变化；
- 人物被迫追踪或撤离；
- 拍摄条件变差；
- 画面更局促、更不完整。

### 第五阶段：视觉兑现

- 展示此前承诺的核心异常；
- 规模可以明显扩大；
- 但保留人物、设备或空间边界；
- 不脱离此前建立的摄影系统。

------

## 四、真实感硬规则

1. 每张图必须存在合理的摄影机位置。
2. 大多数人物必须在做事。
3. 异常第一次出现时不要完整展示。
4. 环境普通信息必须多于异常信息。
5. 光源必须能够解释。
6. 异常必须受同一光线和空间关系约束。
7. 每张图只使用少量、因果明确的成像缺陷。
8. 相邻图片至少增加一个新事实。
9. 连续锚点不能全部更换。
10. 高潮不能完全变成海报或概念艺术。
11. 画面可以清楚，但不能处处完美。
12. 画面可以有情绪，但情绪必须来自现场条件。

------

## 五、允许自由变化的部分

真实感底座不限制：

- 恐怖、神话、历史、科幻或温情题材；
- 晴天、夜晚、室内或户外；
- 手机、监控、航拍、档案或专业设备；
- 普通人物、历史人物、神话生物或巨型结构；
- 克制异常或宏大奇观；
- 明亮、温暖、幽默或浪漫氛围。

需要固定的不是题材，而是：

> **摄影机、现实环境和异常之间的因果关系。**

------

## 六、视觉回报保护规则

不能为了逼真，把所有异常都藏在黑暗、远处和模糊中。

前段可以克制，结尾必须给出回报。

最合理的方式是：

> **异常逐渐变得更清楚、更接近、更完整，但摄影机仍然保留现实限制。**

清楚不等于海报。

壮观不等于概念图。

真实的奇观往往是：

- 装不进画面；
- 被遮挡一部分；
- 明暗失衡；
- 摄影者来不及调整；
- 近景和远景同时存在；
- 人物显得极其渺小；
- 画面仍保留现场的杂乱和不完美。

------

## 七、最终终检标准

每张图生成后，依次检查：

1. 谁拍的？
2. 为什么拍？
3. 拍摄者站得下吗？
4. 人物正在做事吗？
5. 光源存在吗？
6. 背景像被真实使用过吗？
7. 异常和环境发生关系了吗？
8. 异常是否过于居中和完整？
9. 成像缺陷是否有现实原因？
10. 这张图是否增加了新证据？
11. 人物、衣服和道具是否与前图连续？
12. 去掉剧情说明后，它仍像一张真实记录吗？

只要其中四项明显不成立，就需要重新设计，而不是继续增加“写实、8K、电影级、超真实”等形容词。

这条南极作品最值得提炼的最终方法，不是“南极＋冰墙＋地下文明”，而是：

> **先用普通记录建立信任，再让异常通过一条不断升级的现实证据链进入画面；最后交付足够大的视觉奇观，同时不让摄影机从现实世界中消失。**









当前提供的资料实际是**一个单作品样本**：以海洋专业研究生团队乘船调查海底异常为入口，文件本身明确标注为虚构、由 AI 制作。
我实际读取到 **28 张嵌入图片**，其中开头两张几乎相同。因此，下面所说的“稳定共性”，主要指这组连续画面中反复出现、并且具备跨题材迁移价值的机制，而不是多作者样本的统计结论。

# 1. 总结判断

这组作品的真实感，核心并不来自“照片足够低清”，也不只是因为用了研究船、声呐、潜水员等专业元素。

它真正有效的地方是：

> **先建立一个完整、合理、可追溯的影像证据链，再让异常逐步进入这套证据链。**

整组图片不是直接展示“海底发现巨型异常物”，而是按照现实调查的记录路径推进：

**登船记录 → 日常舱室 → 设备准备 → 数据监测 → 声呐异常 → 人员复核 → ROV下水 → 水下影像 → 潜水确认 → 巨物局部出现。**

每一种画面都在回答三个问题：

1. 这是谁拍的；
2. 为什么此刻要拍；
3. 这张图比上一张多证明了什么。

所以，它看起来更像一次调查过程中留下的手机照片、屏幕翻拍和潜水影像，而不是作者专门设计出来给观众欣赏的“飞碟概念图”。

可以把它概括成一个公式：

> **伪纪实真实感 = 影像来源成立 × 拍摄动机成立 × 现实过程成立 × 物理关系成立 × 连续证据成立。**

任何一项明显为零，再高清也会显假。

## A. 这组作品稳定存在、后续必须继承的底层方法

### 1. 现实过程先于异常奇观

前半段花了大量画面建立船、人员、设备和调查流程。异常并不急着出现。

这种“延迟异常”很重要。现实世界被建立得越具体，后面的不可能内容越容易被接受。

### 2. 人物始终在完成任务

人物搬箱子、接线、看图、记笔记、投放设备、整理潜水装备。

他们的动作首先有工作目的，其次才承担叙事功能。画面不是“一个研究员站在设备旁边”，而是“研究员正在处理某根线、核对某项数据”。

### 3. 异常通过多种证据源交叉确认

异常不是只出现一次：

- 声呐图上出现形状；
- 人员指向屏幕；
- 不同放大级别再次确认；
- ROV画面出现海床痕迹；
- 潜水员沿痕迹进入裂隙；
- 最终照见巨大结构。

这种交叉确认，会让观众产生“这不是一张怪图，而是一件被逐步查实的事”。

### 4. 镜头受到现场条件限制

狭窄舱室只能从门口拍，甲板操作只能站在侧后方拍，水下只能跟着潜水员和安全绳移动。

机位不是为了构图漂亮，而是被墙、门、栏杆、设备和人员位置限制。这正是现实摄影常有的状态。

### 5. 异常本身保持低调

海底巨物没有霓虹灯、能量环、魔法烟雾或夸张光束。它主要依靠：

- 黑暗中的轮廓；
- 潜水灯照亮的局部表面；
- 人物和设备提供的尺度；
- 泥沙、岩壁和遮挡；
- 无法看全的体量。

异常越像一个真实存在但暂时无法理解的物体，越不容易变成廉价特效。

## B. 只在部分画面出现、可选择使用的技巧

这些方法有效，但不应成为每个题材的固定动作：

- **镜面自拍**：适合建立第一人称身份，但容易打断工作流程。
- **人物看镜头的装备照**：适合任务出发前留档，使用过多会变成角色定妆照。
- **屏幕参数和时间码**：能增强证据感，但数据必须自洽。
- **长时间水下低照度跟拍**：适合深海、洞穴、夜间等题材，不适合温情或明亮奇观。
- **牵引绳作为视觉引导线**：本作非常有效，但属于潜水环境特有技巧。
- **阴天灰调**：降低戏剧化，但不能把“阴天”误当成所有伪纪实题材的必需品。

# 3. 十大真实感设计规律

## 规律一：先确定影像从哪里来，再设计画面内容

**为什么有效**

现实照片首先是某种设备在某个位置拍出来的结果。AI 图则容易先想“我要一个怎样漂亮的画面”，最后才补一句“手机拍摄”。

**后续使用方式**

每张提示词开头先写清：

> 影像来源 + 拍摄者身份 + 拍摄位置 + 拍摄原因。

例如：

> 同组工作人员使用普通工作手机主摄，在控制舱门口顺手记录设备调试过程。

而不是只写：

> 真实手机摄影风格的研究员操作设备。

------

## 规律二：拍摄者必须是事件空间中的真实角色

**为什么有效**

摄影机一旦没有存在理由，观众会本能感觉这是“导演机位”。

本作中的镜头大多可以推断出拍摄者是同行成员：他站在队伍后方、舱门口、甲板边缘或另一名潜水员身后。

**后续使用方式**

在分镜设计阶段，为每张图加一项内部检查：

> 这张图是谁拍的？他当时站在哪里？为什么没有去做别的事？

无法回答，就应重新设计机位。

------

## 规律三：记录“动作进行中”，不要记录“人物已经摆好”

**为什么有效**

真实工作记录里，人物往往背对镜头、低头、弯腰、手被设备遮挡，姿态并不舒展。

摆拍图则常让人物站直、完整露出脸和工具，所有信息都朝向观众。

**后续使用方式**

避免写：

> 研究员手持仪器站在甲板上，严肃地注视远方。

改成：

> 研究员背对镜头弯腰整理湿滑甲板上的线缆，一只手扶住设备接口，另一名年长工作人员站在画面边缘检查连接情况。

------

## 规律四：正常世界需要大量“与剧情无关但与生活有关”的细节

**为什么有效**

真实空间不是为故事搭建的。它会存在喝了一半的水、纸杯、插线板、旧标签、折痕、污渍和暂时放错位置的物品。

本作船舱内的水瓶、记录纸、充电线、旧控制柜和杂乱桌面，比“海洋研究船”这一标签本身更能建立真实感。

**后续使用方式**

每个场景至少加入三类普通细节：

1. 使用痕迹；
2. 临时放置物；
3. 与主剧情无关的功能设施。

但不要故意把空间弄得极端脏乱。

------

## 规律五：让现场光源决定画面，而不是让情绪决定光源

**为什么有效**

本作的亮度关系非常朴素：

- 甲板由阴天天光照亮；
- 舱内由顶灯和窗口共同照明；
- 屏幕附近略亮；
- 水下只有潜水灯照到的地方清楚。

情绪来自“看不清什么”，而不是凭空添加蓝色轮廓光。

**后续使用方式**

提示词中先写光源位置，再写视觉结果：

> 冷白顶灯从正上方照亮桌面，窗口自然光明显更亮，人物背部略暗，舱室角落曝光不足。

不要只写：

> 阴森压抑的电影感光影。

------

## 规律六：异常最好先以影响、痕迹或数据出现

**为什么有效**

直接展示异常本体，观众只会判断“这个怪物画得像不像”。

先展示异常造成的痕迹，观众会进入求证状态：

- 仪器为何出现空洞；
- 海底为什么有规则压痕；
- 安全绳为什么延伸进裂缝；
- 光束尽头到底是什么。

**后续使用方式**

异常出现可以采用四级递进：

1. 数据不对；
2. 环境留下痕迹；
3. 人或设备与异常发生互动；
4. 本体局部被确认。

不是每个题材都必须四级齐全，但不要毫无准备地完整亮相。

------

## 规律七：异常必须同时满足五种物理关系

一个异常元素要融入现实，至少需要处理：

1. **尺度关系**：旁边有什么可比较；
2. **遮挡关系**：是否被墙、人物、泥沙或雾气部分遮挡；
3. **光照关系**：现场光如何落到它上面；
4. **接触关系**：它如何压住、碰到或改变周围环境；
5. **介质关系**：雨、水、尘埃、烟雾、玻璃是否同时作用于它。

本作水下巨物之所以比发光飞碟可信，是因为潜水灯只照亮它的一段表面，潜水员和设备提供了尺度，黑暗隐藏了整体。

------

## 规律八：连续性依靠“重复锚点”，推进依靠“新增变量”

**为什么有效**

完全不重复，整组图会像不同项目拼在一起；完全重复，又会像同一张图换角度。

本作重复了：

- 同一艘船；
- 同一组人物；
- 白色和米色外套；
- 同一控制舱；
- 同一显示器；
- 同一批设备。

但行动从准备、操作、分析逐步变化。

**后续使用方式**

每张图保留至少两个上一张的连续锚点，同时改变至少两个变量：

- 动作；
- 证据；
- 空间位置；
- 拍摄媒介；
- 风险状态；
- 人物关系。

------

## 规律九：媒介切换必须由剧情行为触发

**为什么有效**

本作经历了：

- 岸上手机记录；
- 船舱手机记录；
- 声呐屏幕翻拍；
- ROV监控画面；
- 水下同伴跟拍。

媒介变了，但每次变化都有任务原因：设备被放下、ROV开始工作、人员下水。

**后续使用方式**

不要为了视觉丰富，随机插入监控、航拍或夜视。

媒介切换必须对应一个现实动作：

> 打开监控、放飞无人机、调取旧录像、启动内窥镜、进入水下、收到他人手机文件。

------

## 规律十：高潮可以更清楚，但不能突然失去记录属性

**为什么有效**

真实感不等于永远含糊。高潮必须给观众视觉回报。

本作最后让巨大结构进入潜水灯范围，但依然保持：

- 局部照明；
- 人物背影；
- 设备遮挡；
- 水下悬浮物；
- 无法看清整体边界。

**后续使用方式**

高潮可以清楚地证明异常是什么，但最好只清楚一个决定性特征：

- 一只巨手的关节；
- 古代军阵的旗号；
- 巨型建筑上的门窗；
- 飞行器的规则舱壁；
- 神话生物真实的皮肤与呼吸。

做到“证据清楚，整体仍受现场条件限制”，而不是退回海报式全景。

# 4. 五大假感来源

## 第一类：画面在“向观众展示”，而不是在“被现场记录”

包括：

- 海报感；
- 概念图感；
- 电影剧照感。

典型症状是异常处于正中央，人物站在最佳观看位置，环境自动让开，光线也负责强调主体。

这种画面可能很好看，但观众会立即意识到“有人在设计”。

------

## 第二类：人物在表演身份，而不是完成事情

包括：

- 摆拍感；
- 演员感。

常见表现：

- 所有人都看镜头；
- 表情统一惊恐；
- 工具只是拿在手里，没有真实操作；
- 衣服像刚从服装组领取；
- 人物姿态舒展得像品牌广告。

真实人物的注意力应该在设备、同伴、危险或任务上，而不是在镜头上。

------

## 第三类：把成像缺陷当成真实性滤镜

包括：

- 过度精修感；
- 滤镜感；
- 故意脏乱低清装真；
- 随机噪点和模糊；
- 无来源戏剧光。

真实成像缺陷应当有原因。

例如：

- 人在走动，所以轻微拖影；
- 窗外太亮，所以局部过曝；
- 水下距离较远，所以对比度下降；
- 手机靠近屏幕，所以出现轻微反光。

不是在整张图上统一加一层“复古真实滤镜”。

------

## 第四类：异常像单独贴在真实背景上

包括：

- 异常特效廉价化；
- 背景空洞；
- 只靠发光、烟雾和颜色区分异常。

最常见的问题是：

> 真实街道 + 一个表面特别光滑、特别亮、完全不受环境影响的怪东西。

异常没有被遮挡，不改变地面，不接收现场光，旁边人物也没有合理互动，自然会像后期贴图。

------

## 第五类：单张可能真实，整组却没有事件连续性

包括：

- 镜头不成立；
- 人物和空间漂移；
- 连续分镜重复；
- 每张都像独立封面。

观众需要感受到时间确实经过、人物确实移动、信息确实增加。

否则连续图片只是“同一概念的二十个变体”。

## 《这类内容最容易翻车的假感来源清单》

1. 异常永远居中，占据画面最佳位置；
2. 人物完整正面站立，手持道具介绍身份；
3. 所有人同时做出相同惊恐表情；
4. 普通现场出现无来源轮廓光；
5. 过度蓝橙调色或统一青灰滤镜；
6. 用重颗粒、重压缩、失焦掩盖生成问题；
7. 背景没有杂物、磨损和功能结构；
8. 道具像摆设，线缆、接口和握持方式不成立；
9. 异常表面比周围环境清晰几个等级；
10. 异常不产生阴影、反射、遮挡或环境影响；
11. 摄影机位于墙内、半空、危险物正前方等不可能位置；
12. 每张都使用电影式广角大全景；
13. 相邻图片只改变人物头部方向或镜头远近；
14. 屏幕数据、时间、地点、设备型号前后矛盾；
15. 高潮为了“震撼”突然变成精修宣传海报。

# 5. 对标作品真实感方法库

## 5.1 影像来源方法

| 来源                  | 真实感优势                   | 最容易翻车的风险               | 可直接采用的约束                                   |
| --------------------- | ---------------------------- | ------------------------------ | -------------------------------------------------- |
| 同行手机主摄          | 最接近日常记录，空间关系直观 | 把“手机感”写成重噪点和低清     | 自动模式、自然锐度、轻微广角、不过度虚化           |
| 工作过程照片          | 拍摄动机明确，人物自然       | 变成职业宣传照                 | 人物忙于操作，拍摄者从工作通道或门口记录           |
| 设备屏幕翻拍          | 带有证据和求证属性           | UI造假、参数矛盾、屏幕过于完美 | 保留屏幕边框、桌面和操作者，不只生成纯界面         |
| ROV、内窥镜、监控画面 | 受设备限制，天然不像海报     | 所有画面都加时间码，故意装真   | 只保留与设备功能有关的参数和成像限制               |
| 同伴潜水或运动相机    | 身体参与感强，危险距离可信   | 机位自由得像水下电影摄影车     | 前景出现手套、仪表、绳索或设备边缘，证明摄影者存在 |
| 自拍、镜面照          | 快速建立第一人称身份         | 过于像社交平台人设照           | 只在身份建立或出发前留档时使用一次                 |

## 5.2 拍摄者逻辑方法

可直接作为创作约束：

> 每张画面必须能明确说明拍摄者身份、所处位置、拍摄动机和与主体的距离。

常用动机只有几类：

- 日常留档；
- 工作汇报；
- 记录操作过程；
- 向同伴展示异常；
- 为后续求证留下证据；
- 在危险中被动拍到；
- 调取既有设备录像。

最假拍摄逻辑包括：

- 危险已经迫在眉睫，人物却站着拍漂亮全景；
- 只有主角进入封闭空间，却出现第三人称远景；
- 摄影机始终比所有人提前到达最佳位置；
- 拍摄者在每个空间都拥有电影级稳定器和灯光；
- 水下、火灾、坍塌环境中镜头仍然完美平稳、清晰、洁净。

## 5.3 镜头方法

### 建立正常现实

优先使用：

- 环境中景；
- 人物背影进入空间；
- 门口或通道后的观察视角；
- 普通平视高度；
- 环境比人物占比更大。

### 发现异常

优先使用：

- 肩后看屏幕；
- 人物手指指向某处；
- 设备旁侧近景；
- 人物转头向拍摄者确认；
- 异常只占画面较小区域。

### 证据确认

优先使用：

- 局部证据近景；
- 屏幕、记录表、痕迹和实体之间交叉切换；
- 保留手、尺子、仪器边框等尺度参照；
- 一张明确证据配一张人物反应，而不是连续六张反应脸。

### 高潮兑现

优先使用：

- 人物或设备作为前景尺度；
- 异常局部进入真实光源；
- 画面有遮挡，但核心特征清楚；
- 通过距离、材质和环境影响表现体量。

最容易产生海报感的镜头：

- 超低机位仰拍人物与巨物；
- 人物站在画面正中央，异常在背后完整展开；
- 完美左右对称；
- 巨物与人物形成标准三角构图；
- 大面积体积光精准照向主体；
- 所有东西都处于最佳焦点与最佳曝光。

## 5.4 人物方法

直接约束为：

> 人物应当像被工作和生活塑造出来的人，而不是为故事选出的演员。

具体做法：

- 面部存在轻微不对称、疲惫、肤色差异；
- 年龄层不要全部相同；
- 服装允许旧、皱、尺码略不合适；
- 鞋底、裤脚、袖口与环境发生关系；
- 双手始终承担真实动作；
- 表情以专注、疑惑、犹豫、交流为主；
- 大部分画面不要求完整露出脸。

“普通但不无聊”的关键不是把人物做丑，而是给他：

- 明确职业行为；
- 稳定服装锚点；
- 独特但不夸张的小习惯；
- 与同伴不同的任务分工；
- 可识别的工具和姿态。

## 5.5 环境方法

每个真实空间至少应同时具备：

### 功能结构

门、窗、插座、控制柜、管道、栏杆、排水口、储物区。

### 使用痕迹

磨损、折痕、水渍、油渍、胶带残留、标签褪色、金属氧化。

### 临时物品

水瓶、纸杯、包、记录本、充电线、手套、未收好的线缆。

### 空间死角

柜子后方、桌下、门边、暗角和被设备挡住的区域。

环境最容易显假的情况：

- 墙面和地面过于崭新；
- 所有物品摆放等距；
- 空间只出现剧情必需品；
- 背景大面积空白；
- 设备重复、结构无功能；
- 过度堆杂物，像刻意制作的“脏乱布景”。

## 5.6 光线方法

最有效的真实光线策略：

> 使用一到两个现实主光源，允许它们产生不均匀、并不完美的照明结果。

可用组合：

- 窗外自然光 + 室内顶灯；
- 路灯 + 店铺灯；
- 手电 + 远处微弱环境光；
- 显示器 + 顶灯；
- 火光 + 清晨自然光；
- 潜水灯 + 水中微弱散射光。

让画面有情绪但不油腻的方法：

- 情绪来自亮暗范围，而非彩色滤镜；
- 让光只照亮故事当前能确认的区域；
- 保留一些普通、没有戏剧性的亮区；
- 不要把所有阴影压成纯黑；
- 不要给人物添加无来源的脸部补光。

## 5.7 异常融合方法

异常进入画面前，先完成六项设计：

1. 它在空间中的准确位置；
2. 它与人物的距离；
3. 它被什么遮挡；
4. 哪种现场光照到它；
5. 它如何改变周围介质；
6. 人或设备如何与它发生真实互动。

不同题材的处理：

### 神话

不要只做“神兽发光”。

让它踩进泥地、压弯树木、呼吸形成水汽、皮毛被雨水打湿，村民从现实距离拍摄。

### 历史

不要把古人拍成影视剧组。

通过现代道路、监控、巡护手机、测绘设备或普通居民视角，让历史内容真实进入当代空间。

### 巨物

避免完整全景居中展示。

利用建筑、车辆、人物、云层、雾霾和大气透视建立尺度，只露出局部结构。

### 温情反差

异常不必阴暗。

可以使用普通家庭手机、自然窗光、生活杂物和不完美抓拍，让不可思议的事像家庭相册的一部分。

### 抽象或带梗题材

越离谱的内容，媒介越应冷静。

使用固定监控、会议记录、物业工作照、普通聊天截图或路人远距离拍摄，减少视觉上的主动搞笑。

## 5.8 连续分镜防重复方法

使用“锚点—变量”机制。

### 每张图保留

- 一个稳定人物锚点；
- 一个环境锚点；
- 一个道具或媒介锚点。

### 每张图至少新增一种

- 新行为；
- 新证据；
- 新空间；
- 新关系；
- 新拍摄媒介；
- 新危险；
- 新视觉尺度。

更实用的相邻图片检查：

> 相邻两张如果只改变了机位，没有改变事件信息，其中一张通常可以删除。

### 本作值得升级的部分

这组样本也存在明显的可优化点：

- 开头两张几乎重复，不能同时承担有效推进；
- 声呐屏幕阶段连续多张处于相近空间和机位，证据在增加，但视觉变化不足；
- 水下前半段多次重复“摄影者跟在潜水员后面”的构图；
- 部分屏幕时间、深度和任务背景需要严格统一，否则专业观众容易察觉矛盾；
- 最终巨物采用局部显露，真实感较好，但视觉回报略弱。

更好的升级方式不是把巨物完整照亮，而是：

> 最终清楚展示一个足以改变认知的结构细节，同时继续隐藏整体。

# 6. 可直接复用的真实性写法模板

下面的内容可以直接嵌入后续生图提示词。

## 6.1 影像来源模板

```text
真实的[影像来源]记录画面，由[拍摄者身份]使用[具体但普通的设备类型]拍摄。拍摄者当时位于[现实可到达的位置]，因为需要[留档、汇报、求证、记录操作或跟随同伴]而拍下这一画面。画面应像设备自动模式产生的结果，而不是经过专业布光和构图的宣传照片。
```

## 6.2 手机工作记录模板

```text
普通工作手机主摄随手记录，自动曝光和自动白平衡，轻微广角透视。拍摄者站在[门口、通道、人物侧后方或设备旁]，没有刻意寻找最佳构图。主体正在完成具体工作，没有面向镜头摆姿势，画面边缘允许出现门框、衣袖、栏杆或设备遮挡。
```

## 6.3 拍摄者机位模板

```text
摄影机高度接近普通成年人视线或胸口高度，机位受现场墙体、栏杆、桌面和工作人员位置限制。主体并未处于画面正中央，部分身体或工具被前景遮挡，构图略有偏移，但关键行为仍然清楚。
```

## 6.4 人物普通感模板

```text
人物具有真实普通人的面部比例和轻微不对称，肤质自然，发型简单，存在轻微疲惫和长期工作的痕迹，不像演员或模特。服装合身程度普通，有自然褶皱、使用痕迹和局部污渍。人物注意力集中在任务、设备或同伴身上，而不是镜头。
```

## 6.5 人物动作模板

```text
人物双手正在完成明确动作：[插接线缆、翻看记录、扶住设备、检查接口、搬动物品、照亮目标]。身体姿态由工作行为自然形成，允许弯腰、侧身、遮脸或背对镜头，不采用英雄站姿和展示性动作。
```

## 6.6 环境细节模板

```text
场景是长期真实使用的[工作、生活或公共空间]。背景保留必要的功能结构，并自然出现少量与剧情无关的普通物件，如记录本、水瓶、充电线、纸杯、工具袋、旧标签和临时放置的衣物。材质存在轻微磨损、灰尘、水渍或金属氧化，但环境仍然正常使用，不做废墟化和刻意脏乱处理。
```

## 6.7 自然光源模板

```text
所有照明均来自现场实际存在的光源：[顶灯、窗外自然光、路灯、屏幕、手电或火光]。光线分布不完全均匀，靠近光源的位置较亮，远处和遮挡区域自然变暗。人物不额外接受摄影棚补光，不出现无来源轮廓光和夸张体积光。
```

## 6.8 普通设备成像模板

```text
呈现[设备类型]自动模式的真实成像结果：局部高光略亮，暗部细节有限，边缘存在轻微广角变形，远处对比度自然下降。清晰度足以辨认关键证据，但不进行商业摄影式锐化、肤质精修和全画面完美曝光。
```

## 6.9 屏幕翻拍模板

```text
由手机近距离拍摄正在运行的设备显示器，保留显示器边框、键盘、连接线和操作者的手。屏幕信息属于真实工作界面，参数、时间、比例和设备功能前后一致。屏幕允许存在轻微反光、亮度不均和拍摄角度变形，不生成悬浮式科幻UI。
```

## 6.10 水下影像模板

```text
由同行潜水员的普通水下运动相机或头戴设备记录。前景可见部分手套、仪表、绳索或设备边缘，证明摄影者真实存在。照明主要来自潜水灯，光束范围外迅速变暗；水中悬浮颗粒、距离导致的对比度下降和局部色彩损失符合真实水下成像。
```

## 6.11 异常融合模板

```text
异常内容真实位于该空间中，而不是叠加在背景上。它接受同一现场光线，受到[人物、建筑、泥沙、雾气、玻璃或水体]的遮挡，并与地面、墙体或周围物体发生明确接触。异常表面的清晰度、色温和颗粒状态与同距离的现实物体一致。
```

## 6.12 巨物局部显露模板

```text
巨型异常主体并未完整出现在画面中，只由现场光源照亮一处决定性结构。使用人物、车辆、建筑、树木或设备提供尺度参照。主体远端被天气、黑暗、建筑遮挡或大气介质隐藏，避免完整居中展示和概念设定图式构图。
```

## 6.13 连续组图约束模板

```text
延续上一张中的人物外貌、服装、道具、天气、空间结构和光线方向。保留至少两个连续锚点，同时新增明确的动作、证据、空间位置或风险变化。不得只更换镜头角度而重复上一张信息。
```

## 6.14 “不要油腻”的负面约束模板

```text
不要海报式构图，不要英雄站姿，不要演员式夸张表情，不要全员看镜头，不要电影级蓝橙调色，不要无来源轮廓光，不要大面积体积雾，不要异常主体自带廉价霓虹光，不要商业摄影级肤质精修，不要夸张浅景深，不要完美左右对称，不要故意添加重噪点、VHS损坏和随机模糊，不要让背景空洞或只出现剧情必需物。
```

# 7. 《AI伪纪实连续图片创作的真实感设计底座》

## 一、核心目标

不是把画面做旧、做暗、做模糊，而是让观众相信：

> **在这个事件发生时，确实可能有人以这种方式留下这张影像。**

真实感服务于奇观，不负责消灭奇观。

------

## 二、四层真实性

### 1. 来源真实性

每张图明确属于一种现实影像系统：

- 手机；
- 普通相机；
- 监控；
- 无人机；
- 行车记录仪；
- 工作设备；
- 内窥镜；
- 水下相机；
- 视频截帧。

不得只写“纪实风格”，却不说明图像怎样产生。

### 2. 行为真实性

人物必须有现实目标：

- 去哪里；
- 做什么；
- 为什么停下来；
- 为什么拍摄；
- 为什么靠近异常；
- 为什么没有立刻逃跑。

人物行为必须比构图需要更优先。

### 3. 物理真实性

所有异常均服从：

- 光；
- 距离；
- 尺度；
- 遮挡；
- 材质；
- 接触；
- 环境介质。

题材可以不现实，物理表现不能随意。

### 4. 连续真实性

整组图片必须共享：

- 时间进程；
- 稳定人物；
- 稳定空间；
- 稳定道具；
- 稳定天气；
- 稳定损伤和状态变化。

每张图都应成为上一张的结果和下一张的原因。

------

## 三、十二条底层规则

1. **先写影像来源，再写主体。**
2. **先确定谁拍，再确定机位。**
3. **先设计人物行动，再设计人物姿态。**
4. **正常现实必须在异常之前成立。**
5. **异常优先通过痕迹、数据和影响进入。**
6. **人物、环境和异常使用同一套光线。**
7. **空间中保留与剧情无关的普通信息。**
8. **人物可以普通，但必须有明确任务和识别锚点。**
9. **相邻图片保留连续锚点，同时新增有效变量。**
10. **媒介切换必须对应现实行为。**
11. **成像缺陷只在有设备或环境原因时出现。**
12. **高潮必须兑现，但仍由现场摄影条件约束。**

------

## 四、真实感与视觉回报的平衡规则

不应因为追求真实而规定：

- 异常永远只能很小；
- 巨物永远不能看清；
- 画面永远必须昏暗；
- 所有镜头都必须手持；
- 所有人都必须背对镜头；
- 所有环境都必须破旧；
- 所有高潮都只能依靠想象。

更合理的原则是：

> **允许观众看清决定性证据，不允许摄影机突然变成全知导演。**

明亮题材可以使用阳光；宏大题材可以使用航拍；温情题材可以使用漂亮窗光；神话题材可以展示巨物。

但这些画面仍然需要一个成立的影像来源和拍摄位置。

------

## 五、连续图片的最低合格标准

每张图生成前检查：

1. 谁拍的？
2. 为什么拍？
3. 摄影机真实存在于哪里？
4. 人物正在做什么？
5. 光从哪里来？
6. 环境里有哪些正常使用痕迹？
7. 异常与现实发生了哪些物理关系？
8. 与上一张相比，新增了什么？
9. 哪些元素必须保持不变？
10. 这张图是在记录事件，还是在向观众展示设定？

其中三项无法明确回答，画面通常就会出现明显 AI 感。

------

## 六、最终创作原则

这套底座最重要的一句话是：

> **不要让异常负责制造全部吸引力，要让“异常竟然被一套普通影像系统真实记录下来”本身成为吸引力。**

真正高级的伪纪实，不是把不可能内容画得像电影，而是让它看起来像某个普通人、某台普通设备，在一个完全合理的时刻，意外留下了证据。











先说明样本范围：目前提供的是一部完整对标作品。我从文档中提取并逐张检查了其中的 **23 张连续图片**。作品明确注明“纯属虚构，基于AI制作”，题材标签涉及日本、樱花、河神、龙和水怪。

因此，下面所说的“稳定共性”，首先指这部作品内部反复成立的强规律；其中具有普适性的部分，可以直接作为后续创作底座。等补充更多作者和题材后，还可以进一步验证哪些属于跨账号共性。

# 1. 总结判断

这组图片的真实感，最核心并不来自“画质像手机”，也不来自低清、黑暗或恐怖滤镜，而来自四件事：

> **一个可以被追责的摄影机，一条连续发生的现实因果链，一个在异常出现前就已经独立存在的普通世界，以及让异常服从同一套光线、空间、材质和物理关系的融合方式。**

其中最关键的设计，是它建立了一个长期成立的“隐形第四人”。

开头合照明确共有四名舍友；进入旅途后，画面中经常只出现三人，因此观众会自然理解：第四个人一直拿着手机跟在后面拍。之后的机场、出租车、旅馆、岔路、神社、仪式和木船，都可以从这个人的真实位置拍到。到了船上，画面底部甚至出现拍摄者自己的腿，彻底确认摄影机不是无所不在的上帝视角。

所以，这组图不是在向观众“展示一个故事”，而是在模拟：

> **某个人本来只想记录旅行，后来不得不继续记录一件越来越不对劲的事情。**

这就是它比普通AI电影剧照更真的根本原因。

## 影像来源感：最常用的5种来源

### 1. 普通手机旅行照片

**优势：**
观众天然接受随手构图、普通人物、景点环境和轻微瑕疵。非常适合建立正常世界。

**风险：**
过度强调“游客照片”，容易让每张都变成朋友站好后的纪念照。

### 2. 行走中的手机跟拍或视频截帧

**优势：**
背影、遮挡、运动、偏离中心都能自然成立，非常适合发现异常和追踪行动。

**风险：**
每张都强行模糊、歪斜，会变成刻意模仿偷拍。

### 3. 手电辅助的求证记录

**优势：**
摄影动机非常明确：人物需要看清物体，也需要留下证据。光线和视线会自然集中。

**风险：**
圆形光斑过于标准、周围全黑，容易变成恐怖游戏截图。

### 4. 低照度现场视频截帧

**优势：**
曝光波动、暗部缺失、人物运动和局部高光溢出，都可以解释高潮中的不完美。

**风险：**
把低照度误写成“全画面低清、重噪点、严重压缩”，反而像滤镜。

### 5. 临时改变方向的竖屏记录

作品绝大多数为4:3横向，夜间进山时突然出现一张竖向画面。

**优势：**
像人在紧张状态下掏出手机后没有重新调整方向，形成真实的媒介行为变化。

**风险：**
无缘无故频繁横竖切换，会破坏影像系统的一致性。

# 3. 稳定共性与个体技巧

## A. 后续必须继承的底层共性

### 1. 摄影机必须“有户口”

每张图都应当回答：

- 谁在拍；
- 为什么此刻要拍；
- 摄影者站在哪里；
- 他与被摄者是什么关系；
- 这个位置是否真的容得下一个人。

这比写“手机摄影感”重要得多。

### 2. 异常前必须存在完整的正常世界

真实感不是由异常本身建立，而是由异常侵入之前的普通生活建立。

飞机、行李、道路、住宿、天气、同伴关系、衣服和行动习惯，都是后面异常可信度的信用储备。

### 3. 人物始终在做事

人物不是站在那里“表现紧张”，而是在：

- 看导航；
- 搬行李；
- 指路；
- 跨过绳索；
- 开门；
- 照明；
- 伸手触碰；
- 转身；
- 下跪；
- 抓住船沿。

动作比表情更可信。

### 4. 光线必须来自现场

每次照明变化都对应环境变化：

白天自然光 → 林中散射光 → 门外逆光 → 手电 → 黄昏 → 灯笼 → 湖面微光。

情绪来自光源更换，而不是统一套电影滤镜。

### 5. 异常必须留下现实后果

陶罐不是“出现了”，而是被触碰、打碎并流出液体；老人不是“神秘登场”，而是看见破损、下跪、处理后果；怪物不是背景装饰，而是掀起水花、影响船体和人物动作。

### 6. 相邻图片既要连续，又要发生状态变化

稳定的是人物、服装、地点和光线方向；变化的是动作、信息、距离或危险程度。

### 7. 高潮要牺牲部分构图控制

摄影者越接近危险，画面越不应当像精心设计的海报。

可以降低完整性，但不能降低关键事件的可理解性。

------

## B. 只需按题材选择的局部技巧

以下设计在这部作品里有效，但不应被机械复制：

- 四人旅行、第四人拍摄；
- 飞机自拍开场；
- 禁止进入标识；
- 废弃神社；
- 陶罐和黑色液体；
- 老人或祭司角色；
- 人体符文；
- 森林、灯笼和夜湖；
- 最后才出现怪物；
- 突然切换竖屏；
- 恐怖化暗角。

它们是题材外壳，不是真实感本体。

真正应继承的是：**任何题材都要找到自己的拍摄者、正常世界、物理证据和因果升级。**

# 4. 十大真实感设计规律

## 规律一：先写“摄影机履历”，再写画面

### 规律

任何提示词在描述主体前，先确定：

> 谁，用什么设备，在什么位置，因为什么原因，留下了这张影像。

### 为什么有效

AI图最常见的问题不是材质不真，而是摄影机根本不成立。
摄影机一旦没有位置和目的，画面就会自动滑向海报、剧照和概念设计。

### 后续怎么用

为每张分镜增加一条内部说明：

> 摄影者是同行者，站在主体身后一米处，因为要记录他们跨过警戒绳而举起手机。

这条不一定全部写入成图，但必须先在分镜阶段成立。

------

## 规律二：先积累现实信用，再消费异常

### 规律

异常越大，前面需要建立的普通现实越完整。

### 为什么有效

观众不会因为怪物细节多而相信怪物；他们会因为前面那些无聊但熟悉的东西都对，暂时愿意相信怪物也被拍到了。

### 后续怎么用

在异常出现前，至少建立：

- 人物关系；
- 时间和地点；
- 正常任务；
- 固定服装和随身物；
- 环境运行状态；
- 一两个无关剧情的生活细节。

不必永远用8张正常图，但应有足够的“正常世界预算”。

------

## 规律三：生成“拍摄结果”，而不是“设计画面”

### 规律

提示词应描述设备最终拍到了什么，而不是要求一幅完美视觉作品。

### 为什么有效

“电影级构图、震撼光影、史诗氛围、极致细节”都在强调创作者意图；真实记录强调的是设备和现场条件共同形成的结果。

### 后续怎么用

少写：

> 震撼、史诗、视觉中心、完美构图、强烈冲击。

多写：

> 自动曝光优先保住天空，人物面部稍暗；画面右侧被同行者肩膀遮住一部分；手机来不及重新对焦。

------

## 规律四：人物要执行任务，不要演情绪

### 规律

用动作表达情绪，不用表演式姿态表达情绪。

### 为什么有效

真实人在异常现场通常会看物体、找出口、扶同伴、打电话、后退，而不是面朝摄影机做标准惊恐表情。

### 后续怎么用

把“人物非常震惊”改成：

> 他停止伸手，肩膀后缩，脚仍停在原位，视线落在刚裂开的容器上，没有看向镜头。

------

## 规律五：环境中必须存在“不为剧情服务”的东西

### 规律

每个环境至少保留三类普通残留：

- 使用痕迹；
- 临时杂物；
- 空间管理痕迹。

### 为什么有效

概念图中的所有物体都围绕主题服务；现实空间里，大量东西与当前事件无关。

### 后续怎么用

神社不能只有神像和符文，还要有：

- 潮湿木板；
- 被风吹歪的纸张；
- 旧扫帚；
- 不同程度的苔藓；
- 门轴磨损；
- 塑料桶或维护用品。

但不要把“真实”误写成无节制堆垃圾。

------

## 规律六：光源单纯，成像结果复杂

### 规律

现场光源不必很多，但其结果要不均匀。

### 为什么有效

真实照明往往造成：

- 一部分过亮；
- 一部分看不清；
- 不同材质反光强度不同；
- 人物肤色受环境色温影响；
- 远处信息自然丢失。

摄影棚光则倾向于把所有主体均匀照明。

### 后续怎么用

明确一个主光源，最多再加一个合理辅光：

> 主要由手电照明，入口处残余冷天光作为极弱辅光；陶罐正面偏亮，桌下和房间角落保留真实暗部。

------

## 规律七：异常必须同时通过四项融合检查

异常元素必须拥有：

1. **尺度关系**：与人、门、车辆、建筑或地面形成明确尺寸参照。
2. **光线关系**：接受现场光并产生相应明暗。
3. **遮挡关系**：被前景、烟尘、水花、门框或人物部分遮住。
4. **互动关系**：压弯、打湿、挡住、反射、破坏或引发人物动作。

缺一两项还可能成立；四项全无，就会像贴图。

------

## 规律八：连续性采用“三固定，一变化”

### 规律

相邻画面至少固定三项：

- 人物身份；
- 服装与道具；
- 空间和光线方向；
- 摄影者位置关系。

同时至少变化一项：

- 新动作；
- 新证据；
- 新空间；
- 新危险；
- 新拍摄目的。

### 为什么有效

只有变化没有固定，会像独立图片合集；只有固定没有变化，会像重复生成。

------

## 规律九：重复机位只有在“状态变化”时才有价值

作品中陶罐段落连续使用相近机位：

> 看见陶罐 → 伸手触碰 → 陶罐碎裂。

这种重复反而增强真实感，因为它像同一段视频里的连续截帧。

无效重复则是：

> 同一个人站在同一个地方，只是头部角度稍有变化。

### 后续怎么用

需要连续动作时，可以保留机位；但必须让物体状态、人物身体位置或因果结果发生明显变化。

------

## 规律十：高潮可以不完美，但必须仍有证据价值

### 规律

高潮不是“最漂亮的一张”，而是“最难拍但最值得留下的一张”。

### 为什么有效

事件真正压过摄影者时，通常会出现：

- 主体不完整；
- 水花或烟尘遮挡；
- 构图偏离；
- 对焦落后；
- 局部高光溢出；
- 人物进入画面边缘。

### 后续怎么用

建议高潮保持：

- 关键事件约70%可读；
- 约30%被动作、遮挡或成像限制破坏。

不能完全模糊到观众看不懂，也不应清楚到像怪物定妆照。

------

# 5. 五大致命假感来源

## 1. 摄影机无来源

画面可能很漂亮，但无法解释谁站在那里拍。

典型表现：

- 危险中心上方俯拍；
- 所有人都在画面里；
- 封闭空间里出现超远景；
- 逃跑时仍有稳定环绕镜头；
- 无人操控却出现航拍。

这会直接暴露“作者在展示画面”。

------

## 2. 人物与环境都在等待剧情发生

人物站好、环境被清空、所有道具都面向镜头。

结果像：

- 影视布景；
- 主题乐园；
- 宣传海报；
- 密室逃脱场景。

真实世界不会为了异常自动整理背景。

------

## 3. 异常没有进入现实物理系统

怪物很清楚，但：

- 不挡光；
- 没有接触阴影；
- 没压动水面；
- 不影响树木、尘土和人物；
- 材质与现场分辨率不同；
- 身体边缘过于完整。

这就是典型“怪东西加真实背景”。

------

## 4. 用力制造“电影感”

无来源逆光、青橙调色、精致轮廓光、超浅景深、大片雾气、每个人都被照得很好看，会把影像从记录推向表演。

真实感需要情绪，但情绪应从事件和现场光源里长出来。

------

## 5. 连续图片没有因果记忆

人物衣服变化、天气倒退、道具消失、门的位置改变、摄影者忽远忽近，或者每张都重新建立一次场景。

即使单张很真，整组也会像AI图片合集。

------

## 《这类内容最容易翻车的假感来源清单》

| 假感类型       | 典型症状                                   | 修正方向                             |
| -------------- | ------------------------------------------ | ------------------------------------ |
| 海报感         | 主体居中、留标题区、姿势完整、元素均匀排布 | 让构图服从拍摄位置和行动             |
| 摆拍感         | 人物站成一排、同时看镜头、动作暂停         | 让人物继续完成具体任务               |
| 演员感         | 精致脸、统一身材、夸张表情、服装像造型     | 普通面孔、轻微不对称、职业或生活磨损 |
| 概念图感       | 只有主题符号，没有生活信息                 | 增加无剧情功能的空间残留             |
| 电影剧照感     | 摄影机永远处于最佳位置                     | 限制摄影者身体位置和移动能力         |
| 过度精修感     | 皮肤、衣服、地面和金属全部干净锐利         | 保留不同材质的自然差异与局部瑕疵     |
| 故意脏乱低清   | 全局模糊、重颗粒、污渍、水印叠满           | 只添加由现场条件造成的2—3种缺陷      |
| 滤镜感         | 整组统一偏绿、偏黄、暗角严重               | 让色彩随光源和地点自然变化           |
| 无来源戏剧光   | 主体有轮廓光，环境却无对应光源             | 明确光源位置、颜色和衰减             |
| 异常特效廉价化 | 发光眼睛、浓雾、能量粒子、完整怪物         | 使用重量、遮挡、接触和环境反馈       |
| 背景空洞       | 主体之外全是模糊墙面或空地                 | 设置真实空间层次和普通物件           |
| 镜头不成立     | 无人能站的位置、镜头穿墙、所有人均入镜     | 画出摄影者站位和可见范围             |
| 连续分镜重复   | 同场景同机位同动作，只换表情               | 每张新增行动、证据或危险状态         |

# 6. 对标作品真实感方法库

## 一、影像来源方法

### 创作约束

每组连续图片先选择一个主影像系统，其他媒介只能在剧情动机成立时加入。

常见组合：

- 游客手机照片 → 手机视频截帧；
- 工作手机记录 → 证据特写；
- 固定监控 → 工作人员补拍；
- 无人机巡查 → 地面手机记录；
- 家庭相册 → 临时通话截图；
- 新闻采访 → 路人偷拍视频。

### 直接规则

> 同一组图片中，设备的画幅、清晰度、色彩处理和镜头习惯应大体连续；媒介切换必须对应拍摄者、地点或记录目的的变化。

------

## 二、拍摄者逻辑方法

### 创作约束

每张图写一句不超过30字的摄影者说明：

> 同行者落后两步，为记录朋友进入岔路而举起手机。

### 必查项目

- 摄影者有没有空闲的手；
- 他是否真的会在此刻拍；
- 他的视线是否会被挡住；
- 他与主体距离是否合理；
- 上一张到下一张，他能否移动到新位置；
- 危险发生后，他为何没有丢下设备。

最后一项不必每次解释，但行为不能明显违背求生本能。

------

## 三、镜头方法

### 建立正常现实

适合：

- 普通平视中远景；
- 同行自拍；
- 车辆后排视角；
- 人物背影进入空间；
- 环境中人物占比较小。

避免一开始就使用强低机位和极端广角。

### 发现异常

适合：

- 肩后视角；
- 门外或门内侧拍；
- 人物停下后摄影者从后方探看；
- 前景被肩膀、门框、树枝部分遮挡；
- 主体不完全位于中心。

### 证据确认

适合：

- 手机靠近物体后的近景；
- 手、工具或尺子同时入镜；
- 手电热点落在证据上；
- 保留少量周围环境，说明证据位置。

不要把证据拍成纯白背景产品图。

### 高潮兑现

适合：

- 摄影者原有机位被事件打乱；
- 主体部分越出画面；
- 前景人物突然遮挡；
- 水花、烟尘、碎片形成自然遮蔽；
- 对焦和曝光稍有滞后。

------

## 四、人物方法

### 可直接作为创作约束

> 人物应具备普通、可识别、可连续追踪的外观，而不是模特化外观。身份主要由固定发型、外套、鞋子、背包和工具建立，不依赖完美脸部复现。

人物真实感由三层组成：

1. **基础普通感**：自然肤质、轻微面部不对称、普通身材。
2. **身份残留**：衣物褶皱、鞋面灰尘、背包使用痕迹、工具拿法。
3. **行动状态**：重心、视线、手部位置与当前任务一致。

### “普通但不无聊”的方法

不要靠长相制造区分，靠以下组合区分：

- 一人总穿浅色帽衫；
- 一人戴眼镜并负责导航；
- 一人穿绿色外套、行动更冒进；
- 一人始终位于镜头后。

普通人物只要行为关系明确，就不会无聊。

------

## 五、环境方法

### 每个场景至少设计四层

1. **空间骨架**：门、窗、道路、墙、台阶、车辆。
2. **使用物件**：杯子、箱子、工具、行李、清洁用品。
3. **时间痕迹**：磨损、褪色、灰尘、潮湿、锈迹、落叶。
4. **无关信息**：停车车辆、电线、塑料袋、普通游客、花盆、公告。

### 约束表达

> 背景不能只由与剧情有关的符号构成；至少保留三项不参与情节、但符合空间用途的普通物件。

------

## 六、光线方法

### 基础公式

> 一个明确主光源＋一个可选环境辅光＋自然衰减＋材质差异。

例如：

- 室内顶灯＋窗外阴天；
- 路灯＋商铺漏光；
- 手电＋门口残余天光；
- 火光＋黎明环境光；
- 监控红外补光＋远处应急灯。

### 创作约束

- 不要把人物面部单独补亮；
- 允许局部高光过曝；
- 允许暗部失去少量细节；
- 不同表面反光不能一致；
- 混合色温应来自不同真实光源；
- 不用浓雾替代空间层次。

------

## 七、异常融合方法

### 五步融合流程

#### 第一步：先给异常安排现实位置

它在哪里落地、依附、悬停、穿过或被发现？

#### 第二步：建立尺寸参照

附近必须有：

- 人；
- 门窗；
- 车辆；
- 树；
- 道路标线；
- 工具；
- 建筑构件。

#### 第三步：接受现场光

异常不能拥有独立于环境的“高级打光”，除非它本身就是光源。

#### 第四步：加入遮挡

让异常被现实世界切割：

- 门框挡住一部分；
- 水花遮住轮廓；
- 树冠挡住身体；
- 人物前景遮挡下半部；
- 烟尘影响清晰度。

#### 第五步：产生物理后果

例如：

- 巨物压弯护栏；
- 古代军队踩起现代道路灰尘；
- 神话生物在积水中留下反射；
- 时间裂缝使附近玻璃产生局部折射；
- 温情奇迹让物件轻微位移，而不是全场发光。

### 核心约束

> 异常的可信度主要由它如何影响普通物体决定，而不是由异常本身的细节数量决定。

------

## 八、连续分镜防重复方法

相邻两张图片至少改变以下一项，最好改变两项：

- 人物行为；
- 新出现的证据；
- 空间深度；
- 摄影者与主体距离；
- 光线状态；
- 异常程度；
- 人物之间的关系；
- 拍摄目的。

同时至少保留两至三项连续锚点：

- 固定人物；
- 固定服装；
- 固定道具；
- 固定环境方向；
- 固定光源；
- 固定摄影者位置逻辑。

### 有效重复

- 同机位，物体状态改变；
- 同空间，人物位置改变；
- 同动作路线，目的地逐渐显露；
- 同一异常，从远景到证据近景；
- 同一证据，被人物验证或破坏。

### 无效重复

- 只换机位，没有新信息；
- 只换表情，没有新动作；
- 同一异常连续完整展示；
- 每张都重新介绍人物和环境；
- 为追求变化突然改变时间、天气和镜头风格。

------

# 7. 可直接复用的真实性写法模板

以下模板可以直接嵌入后续生图提示词。方括号内替换为具体内容。

## 1. 影像来源模板

```text
这是一张由[拍摄者身份]使用[普通手机主摄/工作手机/固定监控/消费级无人机/普通数码相机]，在[具体行动情境]中为了[旅行记录/工作留档/现场求证/向同伴说明/紧急记录]留下的真实影像。画面应像设备实际拍出的结果，不是宣传照、概念图或电影剧照。
```

## 2. 拍摄者位置模板

```text
摄影者位于[主体身后一至两步/车辆后排左侧/门框内侧/走廊转角/船尾低处]，镜头高度约为[胸口/肩部/坐姿视线]，只能看到该位置真实可见的范围。摄影者与主体是[同行者/同事/家属/现场工作人员]，此刻拍摄是为了[具体原因]。
```

## 3. 自然跟拍机位模板

```text
普通平视跟拍，人物以背面或侧后方进入画面，主体不必正中，画面边缘允许被同行者肩膀、门框、座椅或现场物件自然遮挡。人物继续完成当前动作，不停下来面向镜头摆姿势。
```

## 4. 求证近景模板

```text
手机为了看清[证据]临时靠近拍摄，画面同时保留[手、工具、地面、桌沿或附近参照物]，说明证据所在位置和尺寸。焦点主要落在证据上，周围环境仍可辨认，不做白底产品特写。
```

## 5. 普通人物模板

```text
人物是普通真实的[年龄与身份]，面部有自然毛孔、轻微不对称和疲惫痕迹，不像演员或模特。发型未经精心造型，身材正常，服装符合实际天气与行动需求，衣物存在自然褶皱、局部磨损和轻微污迹。
```

## 6. 行动状态模板

```text
人物正在[具体动作]，视线落在[当前关注对象]，身体重心和手部位置符合动作过程。情绪通过停顿、后退、抓握、转身或视线变化体现，不使用夸张惊恐表情，不集体看向镜头。
```

## 7. 环境细节模板

```text
场景是一个长期被真实使用的[空间类型]。除剧情核心物体外，自然保留[三至五项普通细节]，包括使用痕迹、临时杂物、维护设施和材质磨损。背景不空，不刻意脏乱，也不为剧情专门布置。
```

## 8. 现场光源模板

```text
画面只由[主要真实光源]照明，并受到[可选环境辅光]轻微影响。靠近光源的位置局部偏亮，远处自然变暗，不对人物单独补光。不同材质呈现真实反光差异，允许少量高光溢出和暗部细节损失。
```

## 9. 手机成像模板

```text
普通手机自动模式成像，整体保持可读清晰度和较深景深；根据现场条件只保留两至三项自然成像现象：[轻微运动模糊/自动曝光波动/边缘广角变形/低照度暗部噪点/局部高光溢出/自动白平衡轻微偏移]。不要全局模糊，不故意做旧。
```

## 10. 视频截帧模板

```text
像从一段真实手机视频中截取的单帧：人物动作处于进行中，姿态不完整，构图略晚于事件，局部存在合理运动模糊，但关键人物、动作和异常仍能辨认。
```

## 11. 异常融合模板

```text
异常物体真实处于[空间位置]，尺寸通过[人物/门窗/车辆/树木/道路]建立参照。它接受与现场一致的光线，产生符合方向的阴影和反射，并被[前景物体]部分遮挡。它同时对环境造成[压痕、水花、尘土、破损、反射、重量或人物接触]等可见影响，不像后期贴入背景。
```

## 12. 巨物或奇观模板

```text
巨型异常并非完整居中展示，而是从普通人的可达位置被局部拍到。部分身体被建筑、树冠、云层或地形遮挡，远处细节受到真实空气透视影响；附近车辆、道路和建筑承担尺寸参照，环境光与异常表面的明暗方向一致。
```

## 13. 高潮失控模板

```text
事件突然发生，摄影者仍处于此前建立的位置，来不及寻找最佳构图。画面略有倾斜和动作模糊，前景人物或现场碎片遮住部分主体，曝光出现短暂波动；但关键事件保持足够清楚，像危险发生时意外留下的证据，而不是怪物展示海报。
```

## 14. 通用负面约束模板

```text
不要宣传海报构图，不要人物正中凝视镜头，不要演员式夸张表演，不要摄影棚轮廓光，不要无来源逆光，不要青橙电影调色，不要全局浅景深，不要磨皮塑料皮肤，不要通体发光的异常，不要浓雾和粒子特效堆叠，不要把怪物完整正面展示，不要空洞背景，不要故意添加重噪点、VHS损坏、水印或低清滤镜，不要让相邻分镜只换角度而没有新信息。
```

使用时不要把所有成像缺陷一次性叠上。
每张图选择 **两到三项由现场条件真正导致的特征**，通常比“噪点、模糊、暗角、色散、压缩全部加入”更真实。

# 8. 《AI伪纪实连续图片创作的真实感设计底座》

这套底座不规定故事类型，只规定一个不可能事件如何被真实世界的摄影机记录下来。

## 第一层：现实锚点

每个故事首先固定：

- 时间；
- 地点；
- 人物关系；
- 正常任务；
- 固定服装；
- 固定道具；
- 初始天气和光线；
- 正常环境运行状态。

异常不能取代这些信息，只能进入这些信息。

------

## 第二层：摄影机责任

每张图都要有一个明确的摄影机答案：

> 谁拍、为何拍、站在哪里、离主体多远、能拍见什么。

不允许为了视觉效果突然获得不可能的机位。

可以切换摄影者或媒介，但必须让剧情先提供切换理由。

------

## 第三层：普通世界密度

每个场景都应包含：

- 一项空间结构；
- 一项使用痕迹；
- 一项无关剧情的普通物件；
- 一项时间或天气影响；
- 一项人物正在处理的现实事务。

普通世界越具体，异常越不需要过度解释。

------

## 第四层：光学一致性

每张图明确：

1. 主光源是什么；
2. 光从哪个方向来；
3. 哪些区域会过亮；
4. 哪些区域会失去细节；
5. 设备会如何自动处理；
6. 异常是否接受同样的光。

真实感不是全画面平均清楚，而是明暗损失符合现场条件。

------

## 第五层：异常落地

任何异常必须通过五个问题：

- 它具体在哪里；
- 它有多大；
- 什么东西挡住它；
- 什么光照到它；
- 它改变了什么普通物体。

异常既可以非常宏大，也可以非常清楚；不必为了真实永远藏起来。
但即使进行完整视觉兑现，也必须保留尺度、光线、接触和环境反馈。

------

## 第六层：连续因果

每张图必须继承上一张的至少两项信息，并新增至少一项不可替代的信息。

可新增：

- 新动作；
- 新证据；
- 新位置；
- 新损坏；
- 新人物关系；
- 新危险；
- 新光线阶段；
- 新拍摄目的。

删掉任何一张后，如果故事和视觉理解毫无损失，那张图大概率只是重复。

------

## 第七层：人物行动

人物应当遵循：

> 先处理现实问题，再表达情绪；先看异常，再看镜头；先保护自己，再保持构图。

不同题材可以拥有不同程度的表演性，但伪纪实中的情绪最好通过动作、距离和重心表达。

------

## 第八层：设备节制

设备质感的作用是解释画面，而不是装饰画面。

手机不必永远低清；监控不必永远绿色；无人机不必永远高空大全景；夜景不必永远重噪点。

成像特征必须由以下因素决定：

- 光照；
- 距离；
- 移动速度；
- 镜头焦段；
- 拍摄者状态；
- 设备自动处理。

------

## 第九层：视觉回报保护

真实感不能成为不展示高潮的借口。

最终关键画面仍应做到：

- 核心事件一眼可理解；
- 异常规模或性质得到兑现；
- 人物与异常处于同一空间；
- 环境反馈足够明显；
- 构图保留少量失控感。

可以把异常完整度提高，但不要把摄影机变成不存在的电影摄影机。

------

## 第十层：生成前八问

每张图片生成前，快速检查：

1. 谁在拍？
2. 为什么现在拍？
3. 他真的能站在那里吗？
4. 现场主要由什么照亮？
5. 背景中有哪些与剧情无关的普通东西？
6. 这一张相较上一张新增了什么？
7. 异常如何影响了真实环境？
8. 这张图是在记录事件，还是在展示设计？

只要第1、3、6、7、8题答不清楚，即使图片精度很高，也很容易显假。

------

## 最终底层公式

可以把整套方法压缩成一句后续创作总约束：

> **先建立一个独立运转的普通世界，再安排一个有身份、有位置、有拍摄动机的人进入其中；让异常在同一套空间、光线、尺度、材质和因果中逐步发生；连续图片保持人物与环境记忆，每张新增真实行动或证据；最终视觉回报可以强烈，但必须仍像现场的人勉强拍到，而不是创作者专门摆给观众看的。**

这套作品最值得继承的并不是“樱花、神社、黑夜和水怪”，而是：

> **摄影机始终属于故事世界，异常始终欠现实世界一个物理解释。**















# 1. 总结判断

当前附件实际是一部单一作品，而不是多部作品合集。它明确标注为AI制作，题材涉及“八尺大人、机器人、恐怖”等元素；正文由编号1至25的连续画面构成。   

这组图的真实感，**最核心并不来自画面低清、手机滤镜或“做旧”，而是来自一条完整的现实证据链：**

> **普通人的生活先成立——摄影机的存在大体合理——异常先以背景小信息出现——人物和环境对异常产生现实反应——最后才给出近距离奇观回报。**

它没有一开始就展示“怪物有多吓人”，而是让异常依次进入大巴座位、院墙、窗户、乡间小路和废弃厂房等可信空间；并通过遮挡、尺度参照、现场光源、人物动作和连续位置变化，让观众产生“这个东西真的在现场”的判断。

换句话说，这组作品不是把异常**展示给观众**，而是把异常包装成了一个普通人不断拍到、确认、追踪和逼近的对象。

需要说明的是：目前只有一个作品样本。下面所说的“稳定共性”，主要指这25张图内部反复成立的机制；它们具有较强迁移价值，但还不能直接等同于所有对标作者的普遍规律。

## A. 本作内部稳定存在、后续应重点继承的共性

### 1. 先花足够画面建立正常现实

前段先出现洗漱、收拾行李、坐大巴、进家门、看电脑、喝水等普通行为。异常不是作品的第一层信息，而是侵入一个已经成立的生活。

### 2. 异常经常位于“次视觉中心”

怪女人第一次出现时虽然醒目，但仍被大巴座椅和乘客包围；之后只露出院墙上方的帽子和头部，或者出现在窗外。这种“需要观众自己注意到”的设计，比直接怼脸更像真实记录。

### 3. 画面允许不完美

半张脸被裁掉、座椅挡住人物、行李箱拉杆进入前景、主人公背对镜头、手电只照亮一部分地面，这些都属于现实拍摄经常发生的“不理想结果”。

### 4. 异常遵守光线、空间和材质规则

黑衣女人没有廉价的冷光、红眼或黑雾。机械身体暴露后，也延续了现场的水渍、锈蚀、泥污和手电反光。

### 5. 相邻画面不仅换机位，还改变人物行动

看见、回头、探查、拿武器、出门、保持距离、逼近、攻击、查看残骸、进入厂房——动作链使照片像连续时间中的节点。

------

## B. 只在部分画面出现、可选择使用的技巧

- 镜前自拍作为身份入口；
- 大巴、公交等公共交通中的异常初见；
- 隔墙只露出头部的尺度暗示；
- 黄昏到夜晚的时间压迫；
- 手电作为移动光源；
- 雨后湿地面强化空间反射；
- 攻击后由生物恐怖转为机械恐怖；
- 最后一张用“数量突然增加”兑现世界观。

这些方法有效，但不应成为每个题材的固定配方。温情题材不一定需要手电与雨夜，宏大奇观也不一定需要废弃厂房；真正要继承的是它们背后的摄影和证据逻辑。

# 3. 十大真实感设计规律

## 规律一：先确定影像为什么存在，再决定画面拍什么

**为什么有效：**
 观众会下意识判断：谁拍的？为什么此刻还在拍？相机放在哪里？

**后续用法：**
 每张图生成前写一句内部备注：

> 拍摄者是【谁】，因为【什么原因】拍下这张，设备位于【真实位置】。

答不出来，就不要直接生成。

------

## 规律二：正常现实必须比异常更具体

**为什么有效：**
 “一个农村老宅”很像设定；但“沙发罩、旧日历、落地扇、保温杯、鞋架、家族合影和不匹配的家具”像真实家庭。

**后续用法：**
 每个主要场景至少设置：

- 2个空间结构锚点；
- 3—6个普通物件；
- 1—2种使用痕迹；
- 1个具有地区或年代特征但不夸张的细节。

异常只占其中一部分。

------

## 规律三：人物要在做事，不要在表达状态

**为什么有效：**
 “惊恐地站着”是演员表演；“一边洗杯子一边回头看窗外”是行为被异常打断。

**后续用法：**

少写：

> 人物非常震惊，恐惧地望向怪物。

多写：

> 人物手中仍拿着未洗完的杯子，身体先转向窗户，另一只手停在水龙头旁，动作被突然打断。

------

## 规律四：真实记录的构图首先服务于行动，而非审美完整

**为什么有效：**
 现实拍摄者通常没有时间寻找完美构图。

**后续用法：**

允许：

- 主体偏在一边；
- 前景挡住局部；
- 人物被门框切边；
- 背景杂物进入画面；
- 地平线略有倾斜；
- 关键异常只占画面较小区域。

但不能每张都故意歪斜、模糊，否则会变成“装随拍”。

------

## 规律五：异常要先被现实遮挡，再被现实确认

**为什么有效：**
 遮挡让异常具有空间位置；确认则让观众知道它不是后期贴图。

**后续用法：**

异常出现至少包含两种关系：

- 被门框、墙、树枝、座椅遮挡；
- 在地面留下接触阴影；
- 反射在玻璃或积水中；
- 被人物手电照亮；
- 与家具、建筑形成明确尺度参照；
- 改变周围人物的视线与动作。

------

## 规律六：设备缺陷应由场景自然产生

**为什么有效：**
 夜间拍摄才出现高ISO噪点，快速转身才产生运动模糊，窗外很亮才导致室内欠曝。这种缺陷有因果。

**后续用法：**

不要统一添加“颗粒、模糊、噪点”。

应写成：

> 手机自动曝光优先保证窗外，高亮天空轻微过曝，室内人物面部略暗。

或：

> 拍摄者快速转身，人物手臂和画面边缘存在轻微运动拖影，静止背景仍可辨认。

------

## 规律七：光线只能来自现场能够解释的光源

**为什么有效：**
 现实光源通常不均匀、不完美，还会制造混合色温和局部死角。

**后续用法：**

先列光源，再写效果：

> 左侧旧壁灯提供暖白光，远处路灯偏冷，手电只照亮道路中央；人物背部较暗，不增加无来源补光。

------

## 规律八：连续图片要推进证据等级

**为什么有效：**
 同一异常反复出现并不必然重复，只要每次增加新的可验证信息。

**后续用法：**

可采用五级证据：

1. **疑似**：背景出现不确定轮廓；
2. **复现**：换地点再次出现；
3. **尺度确认**：与建筑、人物产生明确对照；
4. **物理互动**：移动、遮挡、受光、留下痕迹；
5. **本质揭示**：内部结构、来源、群体或规则出现。

------

## 规律九：高潮的奇观越大，前面的摄影越要克制

**为什么有效：**
 如果前20张都像电影海报，最后再出现工厂里的机械巨人，只会继续像概念图；前面越普通，最后越震撼。

**后续用法：**

高潮可以宏大，但仍保留至少三个现实锚点：

- 手电或现场光；
- 人类尺度参照；
- 可辨认的建筑或设备；
- 明确的地面接触；
- 前景遮挡或拍摄者手部。

------

## 规律十：真实感不是消灭美感，而是隐藏设计痕迹

**为什么有效：**
 高质量画面并不会自动显假。真正显假的是所有东西都像为了观众被安排好。

**后续用法：**

可以保留：

- 明确视觉焦点；
- 情绪化色温；
- 宏大尺度；
- 强烈最终回报。

但要把这些建立在：

- 合理机位；
- 现场光源；
- 空间遮挡；
- 行动动机；
- 设备成像结果之上。

------

# 4. 五大假感来源

## 第一类：画面明显在“展示”，不是在“记录”

包括：

- 海报式正面居中；
- 怪物完整全身站在画面中央；
- 人物和异常同时面向镜头；
- 每个关键物件都无遮挡地展示；
- 背景被主动清空。

用户会立刻意识到：“这是作者希望我看见的一张图”，而不是“拍摄者当时碰巧拍到了这些”。

------

## 第二类：人物像演员或模特

包括：

- AI标准帅哥美女脸；
- 磨皮、锐利眼神、完美下颌线；
- 衣服完全无褶皱、无磨损；
- 手永远自然垂下；
- 惊恐表情过度；
- 人物站着等待摄影师拍摄；
- 工作人员服装像影视制服或角色皮肤。

真实人物的关键不是“做丑”，而是具有普通比例、轻微不对称、动作任务和生活状态。

------

## 第三类：无摄影机来源的电影剧照感

包括：

- 主角独自在房间，却有多个完美肩后镜头；
- 主角奔跑时相机提前等在终点；
- 怪物攻击时摄影者正好站在最佳侧面；
- 每次异常出现都有完整照明；
- 大量稳定低机位仰拍或环绕式机位。

本作本身也存在这一弱点：部分外出追踪和攻击画面虽然在成像上像手机视频帧，但摄影者身份没有完全交代。它靠粗糙构图和连续动作掩盖了问题，却不是不可改进。

------

## 第四类：过度“AI美术化”

包括：

- 奶油皮肤；
- 极端HDR；
- 全局高锐化；
- 统一青橙色调；
- 过度浅景深；
- 浓雾、体积光、飘尘同时出现；
- 每块湿地面都像镜子；
- 所有锈迹都高度漂亮；
- 夜景暗而不脏、亮而不溢出。

画面可能很精致，却不像任何普通设备自动拍出的结果。

------

## 第五类：异常没有进入现实物理系统

包括：

- 异常自带发光描边；
- 边缘比背景更锐利；
- 没有接触阴影；
- 没有被任何东西遮挡；
- 不受现场色温影响；
- 大小无法与空间对照；
- 人物不看它，环境也不受影响；
- 怪物只是放在真实背景上的主体贴图。

------

## 《这类内容最容易翻车的假感来源清单》

1. 海报感；
2. 摆拍感；
3. 演员感；
4. 概念图感；
5. 电影剧照感；
6. 过度精修感；
7. 故意脏乱、低清装真；
8. 统一滤镜感；
9. 无来源戏剧光；
10. 异常发光、浓雾、黑气等廉价特效；
11. 背景空洞，只剩剧情道具；
12. 摄影机无法出现在那个位置；
13. 人物动作只表达情绪，不执行任务；
14. 异常缺少遮挡、阴影和尺度参照；
15. 同一场景连续换角度，没有新增信息；
16. 中文文字、标牌和工具结构明显错误；
17. 人物脸、服装、房间结构在相邻图中漂移；
18. 每张画面都同样暗、同样脏、同样紧张。

| ---------------- | -------------------------------- | ---------------------------- | -------------------------- |
| 普通手机主摄照片 | 日常建立、人物行动、现场证据     | 最接近日常经验               | 不能每张都像精心摆拍       |
| 手机视频截帧     | 奔跑、转身、争执、异常移动       | 可自然容纳运动模糊和构图失误 | 过度模糊会看不清信息       |
| 镜子自拍或自拍   | 建立主人公身份                   | 相机来源完全成立             | 适合少量使用               |
| 第一人称手部记录 | 开抽屉、检查物品、照射痕迹       | 拍摄动机和身体位置直接成立   | 手部错误容易暴露AI         |
| 固定监控或门铃   | 无人在场、证明异常自行活动       | 客观记录属性强               | 不要用电影式景深和自由机位 |
| 工作设备记录     | 检测仪、无人机、内窥镜、执法记录 | 自带证据属性                 | 不要只贴一个UI假装专业     |
| 他人跟拍         | 主角行动、追踪、救援             | 可以保留人物全身和环境       | 必须明确同行者是谁         |

### 可直接作为创作约束

> 每组图片开始前建立“影像来源表”。任何无法说明拍摄设备、拍摄者和保留原因的画面，都必须修改机位或更换影像来源。

------

## 5.2 拍摄者逻辑方法

将画面分为三类：

### 顺手记录

旅行、工作、回家、聚会、展示环境。

画面可以松散，异常通常不在中心。

### 主动求证

放大、回头、靠近、拍门牌、拍痕迹、拍窗外。

画面开始更明确地指向异常。

### 危险中残留记录

逃跑、追赶、跌倒、照明、攻击后的检查。

构图不完整，亮度不稳定，但关键信息仍能辨认。

### 创作约束

> 不允许所有画面都处于“作者主动展示异常”的状态。正常记录、求证记录和危险残留记录应交替出现。

------

## 5.3 镜头方法

### 建立正常现实

- 门口向室内拍；
- 坐在交通工具座位旁拍；
- 房间角落或走廊入口；
- 普通胸口至眼睛高度；
- 中景或环境全景；
- 深景深。

### 发现异常

- 异常位于背景；
- 隔着玻璃、门缝、座椅或墙体；
- 主体与异常不同时清晰；
- 拍摄者像临时回头；
- 不要马上给正面特写。

### 证据确认

- 局部近景；
- 第一人称手电照射；
- 带有尺子、建筑、人物或工具作为尺度；
- 展示材质、接触点、痕迹或反射；
- 允许自动对焦略微偏移。

### 高潮兑现

- 先给人类视角进入空间；
- 再给关键奇观；
- 奇观画面中保留门框、手电、人物或设备；
- 不要直接变成无人的大全景概念图。

------

## 5.4 人物方法

### 可直接执行的约束

- 面孔普通，不使用明星或网红审美；
- 允许轻微面部不对称和肤质；
- 发型有生活状态，不做影棚造型；
- 衣服与身份和天气匹配；
- 服装有自然褶皱、汗迹、灰尘或使用痕迹；
- 动作由当前任务决定；
- 手中尽量有正在使用的东西；
- 视线看向行为目标，不看镜头；
- 每张只表现一个明确动作阶段。

### “普通但不无聊”的方法

不是把人物设计得毫无特点，而是给他一个可持续识别的现实特征：

- 固定发型或体态；
- 固定常用衣服；
- 固定背包、手电、杯子或工具；
- 固定动作习惯；
- 稍有个性但不夸张的生活环境。

------

## 5.5 环境方法

### 四层环境结构

1. **空间骨架**：门窗、走廊、墙体、楼梯、家具位置；
2. **功能物件**：这个空间实际用来做什么；
3. **使用痕迹**：磨损、灰尘、水迹、线缆、摆放习惯；
4. **偶然杂物**：与剧情无关、但生活中会出现的东西。

### 约束表达

> 背景不能只是为异常服务。即使删除异常，画面仍应像一个真实家庭、车厢、办公室、街道或厂房。

------

## 5.6 光线方法

### 有效策略

- 白天：窗外自然光和室内阴影不完全平衡；
- 阴天：色彩低饱和但仍有环境细节；
- 黄昏：自然蓝光逐渐取代室内光；
- 夜间：手电、路灯、壁灯分别照亮不同区域；
- 室内：顶灯、台灯、屏幕形成轻微混合色温；
- 火光：只影响附近物体，不把整个场景染橙。

### 创作约束

> 先写光源位置、颜色和照射范围，再写情绪。禁止先写“电影感、压迫感、恐怖光影”，再凭空安排光。

------

## 5.7 异常融合方法

### 六个必须检查的关系

1. **尺度关系**：它到底多大；
2. **遮挡关系**：谁在前，谁在后；
3. **接触关系**：站、坐、压、挂还是漂浮；
4. **光线关系**：它受什么光；
5. **材质关系**：湿、干、锈、灰尘是否与环境一致；
6. **反应关系**：人物、动物、设备或环境是否回应它。

### 不同异常的适配方式

- **神话人物**：像真实的人或生物站在现实空间，而不是自带神光；
- **历史军队**：先通过远处队列、尘土、脚印、马匹反应证明存在；
- **巨物**：必须与建筑、云层、地形和空气透视发生关系；
- **怪物**：部分遮挡通常比完整展示更可信；
- **抽象情绪**：通过现实物体的异常排列、影子、反射和行为表现；
- **温情奇迹**：用普通光线和人物克制反应，避免广告式暖光；
- **机械奇观**：保留重量、连接方式、油污、磨损和运作痕迹。

------

## 5.8 连续分镜防重复方法

相邻两张至少变化两项：

- 人物动作；
- 异常状态；
- 空间位置；
- 证据等级；
- 时间或光线；
- 拍摄者距离；
- 影像来源；
- 风险程度；
- 新道具；
- 环境后果。

### 有效重复

同一扇窗重复出现，但：

- 第一次只有轮廓；
- 第二次人物发现；
- 第三次天色变暗；
- 第四次异常位置改变。

这种重复建立空间连续性。

### 无效重复

同一人物、同一窗户、同一异常、同一动作，只改变镜头焦段和左右位置。

# 6. 可直接复用的真实性写法模板

## 6.1 影像来源模板

```
9:16竖屏，来自【拍摄者身份】在【拍摄原因】下，用【普通设备】留下的【手机照片/手机视频截帧/监控画面/工作记录】。画面首先像真实记录，不像宣传照、电影剧照或概念设定图。
```

------

## 6.2 拍摄者逻辑模板

```
摄影机位于【拍摄者实际能够站立或放置设备的位置】，距离主体约【合理距离】。拍摄者正在【走动/回头/躲在门后/检查物体/用手电寻找】，因此构图并不完美，但关键内容可以辨认。
```

------

## 6.3 镜头机位模板

```
普通人眼睛至胸口高度，轻微广角，非低机位英雄仰拍。主体位于画面【左侧/右侧/中后景】，被【门框、座椅、窗帘、人物肩膀、树枝】自然遮挡一部分；画面边缘保留无关前景，像临时拍到。
```

------

## 6.4 环境模板

```
真实使用中的【场所类型】，保留明确的空间结构。环境中自然出现【3—6件普通功能物件】，并有【磨损、水迹、线缆、摆放不整齐、材质老化】等长期使用痕迹。杂物有生活逻辑，不要统一做旧，不要布景感。
```

------

## 6.5 人物普通感模板

```
【年龄与身份】的普通人物，面部比例自然，轻微不对称，真实肤质，不像演员或模特。发型和服装处于日常使用状态。人物正在【具体动作】，视线看向行为目标，不看镜头，不摆姿势，不夸张表演。
```

------

## 6.6 现场光源模板

```
画面只由现场已有的【窗光/顶灯/路灯/台灯/屏幕/手电/火光】照明。主光来自【方向】，只能照亮【范围】；其余区域自然欠曝或存在光线死角。保留轻微混合色温，不增加无来源轮廓光和影棚补光。
```

------

## 6.7 成像结果模板

```
普通设备自动模式的成像结果：深景深，自动白平衡略有偏差，高亮区域轻微溢出，暗部保留适量噪点。因【拍摄者移动/主体移动/低照度】产生局部轻微运动模糊，但不是全画面故意低清。
```

------

## 6.8 第一人称证据模板

```
第一人称近距离记录，画面下方或边缘自然出现拍摄者的【手、手电、工具、衣袖】。镜头对准【证据对象】，同时保留其与地面、家具或建筑的连接关系，不做孤立产品特写。
```

------

## 6.9 异常融合模板

```
异常对象位于真实空间中的明确位置，与【建筑/人物/车辆/家具】形成可判断的尺度关系。它被【现实物体】部分遮挡，受同一现场光照，拥有接触阴影、材质反光和地面重量感。异常不自发光，不带独立滤镜，不像后期贴图。
```

------

## 6.10 巨物与奇观模板

```
奇观通过普通人的实际观察位置呈现，画面保留近处的【人物、门框、车辆、建筑、道路】作为尺度锚点。远处物体具有符合距离的空气透视、对比度下降和局部遮挡；它对云层、地面、植被或周围人群产生可见影响。
```

------

## 6.11 不要油腻的负面约束模板

```
不要海报式正面居中，不要人物与异常同时面向镜头，不要英雄姿势，不要演员式惊恐表情，不要网红脸和奶油皮，不要极浅景深，不要全局HDR，不要统一青橙调色，不要大片体积雾，不要发光眼睛、黑气、魔法粒子，不要无来源轮廓光，不要为了装真故意全画面模糊、脏污或严重噪点。
```

------

## 6.12 连续性约束模板

```
严格继承前一张的【人物面孔、发型、服装、道具、空间结构、家具位置、异常外形】。本张只改变【人物动作、异常位置、时间光线、证据等级】。不得重新设计房间，不得随意更换门窗、墙体和主要家具。
```

# 7. 《AI伪纪实连续图片创作的真实感设计底座》

## 一、底层定义

AI伪纪实不是“把AI图做得像手机照片”，而是：

> **为一个不可能事件建立可信的影像来源、空间关系、时间过程和证据链。**

清晰、宏大、漂亮都不是禁区。真正需要避免的是让观众看见作者的安排，而不是看见事件本身。

------

## 二、八项固定底座

### 1. 每张图必须有来源

明确：

- 谁拍；
- 用什么拍；
- 为什么拍；
- 相机能否在这里；
- 画面为什么被留下。

### 2. 每个场景必须先作为现实空间成立

场景不能只是“乡村”“医院”“长城”“废墟”等题材标签，而要具有：

- 功能；
- 使用者；
- 普通物件；
- 时间痕迹；
- 空间结构。

### 3. 人物以行动为中心

人物的真实性来自：

- 正在完成任务；
- 动作被异常打断；
- 使用道具；
- 注意力有明确去向。

不是来自刻意做丑，也不是来自持续恐惧表演。

### 4. 异常必须进入现实物理系统

任何异常都必须回答：

- 多大；
- 在哪里；
- 被什么挡住；
- 如何受光；
- 如何接触地面；
- 如何影响周围。

### 5. 光线来自现场，情绪来自光线的后果

不直接要求“电影感、恐怖感、神圣感”。

而是设计：

- 光源；
- 方向；
- 距离；
- 色温；
- 照射范围；
- 暗部损失。

情绪自然产生。

### 6. 成像缺陷必须有因果

- 低照度导致噪点；
- 快速移动导致拖影；
- 强窗光导致室内欠曝；
- 数码变焦导致细节下降；
- 镜头沾水导致局部炫光。

不要把缺陷当滤镜套餐。

### 7. 连续性靠锚点，变化靠事件

固定锚点：

- 人物外形；
- 核心服装；
- 关键道具；
- 门窗和家具；
- 异常造型；
- 时间方向。

变化内容：

- 动作；
- 距离；
   -位置；
- 风险；
- 光线；
- 证据。

### 8. 最终视觉回报可以大胆，但必须被现实锚定

高潮不必为了逼真而缩小。

可以出现：

- 巨型神明；
- 古代军队；
- 机械城市；
- 天空异象；
- 大规模历史复现；
- 温情奇迹；
- 抽象物理现象。

但至少保留：

- 人类尺度；
- 真实拍摄位置；
- 现场光源；
- 环境影响；
- 物理遮挡；
- 成像限制。

------

## 三、推荐的整组真实感流程

### 阶段1：现实建立

用2—4张证明人物、地点和拍摄媒介存在。

### 阶段2：异常误入

异常小、远、被遮挡，不立刻解释。

### 阶段3：主动求证

人物靠近、回头、拍细节、换位置，摄影行为发生变化。

### 阶段4：现实反馈

异常影响光线、物体、设备、动物、人物或空间。

### 阶段5：风险升级

机位开始不稳定，照明和动作更受限制。

### 阶段6：证据兑现

给出观众一直等待的清楚证据。

### 阶段7：世界扩大

最后一到两张可以揭示更大规模、来源或规则，但仍从真实观察位置呈现。

------

## 四、不同题材的开放适配

| 题材      | 应重点保留的真实感策略                     | 可自由放大的部分             |
| --------- | ------------------------------------------ | ---------------------------- |
| 恐怖悬疑  | 背景发现、遮挡、低照度来源、逐级求证       | 异常形态和最终反转           |
| 历史/神话 | 当代观察者、地形尺度、材料与天气、群众反应 | 军阵、神话生物、历史事件规模 |
| 温情反差  | 普通家庭环境、克制表情、自然暖光、生活动作 | 奇迹的情感回报               |
| 抽象/带梗 | 现实物件和社会行为的准确性                 | 异常规则和荒诞组合           |
| 宏大奇观  | 人类尺度、空气透视、环境影响、设备视角     | 巨物、天空、城市级变化       |
| 职业记录  | 工具、流程、工作机位、专业动作             | 不可能事件如何打断流程       |

------

## 五、最终审核标准

一组图生成后，不先问“够不够震撼”，先逐张检查：

1. 相机为什么在这里？
2. 谁按下了快门？
3. 人物正在做什么？
4. 删除异常后，环境是否仍像真实世界？
5. 异常是否受现场光照？
6. 是否有尺度、遮挡和接触关系？
7. 成像缺陷是否有现实原因？
8. 相邻两张新增了什么？
9. 人物、服装、道具和空间是否稳定？
10. 高潮是否仍保留普通人的观察位置？

只要这十项大部分成立，画面即使清晰、漂亮、规模宏大，也仍然可以像真实拍摄记录；反过来，即使画面昏暗、模糊、充满噪点，只要摄影机不存在、人物在摆拍、异常没有物理关系，它依然会是一张很假的AI图。



















# 0. 样本范围说明

当前收到的是一件完整对标作品：以“同学雪山徒步、发现洞穴”为现实入口，叠加“双瞳、成仙、龙、羽化”等超现实内容，作品自身也明确标注为虚构。

我从文档中提取出 **10张图片，按构图去重后约8个有效镜头**。因此，下面所说的“稳定共性”，首先指这组连续图片内部反复成立的规律；其中哪些能成为跨作品共性，还需要后续更多对标样本继续验证。

# 1. 总结判断

这组作品的真实感，最核心的来源不是“画得足够逼真”，而是它建立了一条完整的、符合普通人行为习惯的**影像记录链**：

> 同学自拍留念 → 跟拍徒步 → 有人指向异常 → 靠近求证 → 进入洞穴 → 用手机和手电记录壁画 → 继续深入 → 拍到最终奇观。

用户看到的不是作者专门设计给观众看的八幅画，而像是某位同行者手机相册里留下的八次记录。

因此可以把它的真实感公式概括为：

> **真实感＝可信影像来源 × 合理拍摄动机 × 连续证据链 × 现实物理融合。**
> 清晰度、噪点、景深和滤镜都只是次级变量。

尤其重要的是：画面里的异常从未孤立地“展示”给观众，而是始终被人物发现、指认、照亮、测量、遮挡和拍摄。异常不是一件贴在背景上的奇观，而是一件被现场人员共同经历的东西。

# 3. 十大真实感设计规律

## 规律一：先确定“这批图从哪里来”，再设计画面

### 为什么有效

真实照片天然属于某种系统：朋友相册、工作手机、监控、无人机、行车记录仪、新闻采访或调查档案。

当影像来源明确后，比例、机位、清晰度、拍摄距离、光线处理都会自动获得边界。没有来源的“写实画面”，即使人物和材质再逼真，也容易成为概念图。

### 后续怎么用

创作前先写一句：

> 这组图片是由谁、使用什么设备、在什么过程中留下的？

本作的答案接近：

> 一名同行学生使用普通手机，在雪山徒步和洞穴探索过程中断续拍摄。

这句话比“超写实、8K、电影级摄影”重要得多。

------

## 规律二：每张图都必须有一个现实中的拍摄理由

本作的拍摄动机呈递进关系：

- 开始时为了旅行留念；
- 徒步时为了记录行程；
- 发现洞口时为了告诉其他人；
- 靠近后为了求证；
- 看见壁画后为了保存证据；
- 看见龙骨后因为事件已经不可思议。

这让拍摄行为随着异常升级，而不是主角无论生死都在机械拍照。

### 后续怎么用

为每张图补全一句隐藏问题：

> “拍摄者为什么会在这一秒拿出设备？”

无法回答，就不要设计这张图。

------

## 规律三：正常世界不是铺垫废图，而是信用资产

第一张自拍里有景区建筑、普通游客、雪地步道、登山杖、杂乱队形和日常服装。这些信息没有直接推进异常，却告诉用户：

> 这是一个和普通旅游照片完全兼容的世界。

后面出现洞穴壁画和巨型龙骨时，用户会把前面建立的信用继续借给异常。

### 后续怎么用

异常出现前，至少建立三种正常锚点：

1. 人物正常身份；
2. 场景正常用途；
3. 当天正在进行的正常活动。

但不必机械规定必须有三张“无事发生”的图片。一张信息丰富的正常照片也能完成多项任务。

------

## 规律四：摄影机必须与人物处在现实社会关系中

本作镜头始终像来自“同行朋友”，因此可以：

- 站在队尾跟拍；
- 靠近同伴肩后拍摄；
- 在其他人举手机时同时记录；
- 被前景人物挡住一部分视线。

它不是隐形的神，也不是电影摄制组。

### 后续怎么用

拍摄者可以是朋友、同事、路人、记者、救援人员或自动设备，但必须明确：

- 他能不能到达这个位置；
- 他为什么没有参与当前动作；
- 主体是否知道自己正在被拍；
- 他与主体的距离是否合理。

------

## 规律五：人物要“正在做事”，不能“正在成为画面主体”

本作除自拍外，人物大多：

- 背对镜头走路；
- 指向洞穴；
- 观察墙面；
- 举手机拍摄；
- 用手电寻找细节；
- 分散站立而非排队合影。

这让人物的注意力停留在事件上，而不是摄像机上。

### 后续怎么用

人物动作优先使用动词：

> 走、看、指、扶、蹲、搬、照、记录、回头确认。

少使用状态化表达：

> 威严站立、神情坚定、凝视远方、形成完美构图。

------

## 规律六：异常必须拥有现实世界中的“物理关系”

本作的洞穴、壁画和龙骨拥有四种重要关系：

- **尺度关系**：旁边一直有人；
- **遮挡关系**：洞口、黑暗、人物和岩壁会挡住异常；
- **光照关系**：异常只能被手电照亮一部分；
- **空间关系**：从远处发现，到洞口，再到通道和内厅。

这比单纯提高怪物纹理精度更能制造可信度。

### 后续怎么用

任何异常至少要回答：

- 它踩在哪里或附着在哪里？
- 它挡住了什么，又被什么挡住？
- 它受哪个现场光源照明？
- 人如何绕行、靠近、触摸或回避它？
- 哪个普通物体能证明它有多大？

------

## 规律七：真实设备的局限，比人工添加“脏感”更重要

本作并不依赖严重噪点、故障条纹或模糊滤镜。

它真正有效的是：

- 雪地较亮，天空细节有限；
- 洞内大面积黑色无法恢复；
- 手电照到的区域明显比周围亮；
- 近处人物会遮挡主体；
- 画面清楚，但没有商业精修感。

### 后续怎么用

不要先写“低清、噪点、模糊”。

先写设备如何处理现场：

> 自动曝光优先照顾雪地，因此人物面部略暗。
> 手机无法同时保留洞口外雪地和洞内暗部。
> 手电形成小面积亮斑，周围岩壁迅速掉入黑暗。

------

## 规律八：相邻图片要改变“事件状态”，不只是改变角度

本作有效的推进链是：

> 行走 → 停下 → 指认 → 抵达 → 进入 → 观察壁画 → 发现内部入口 → 看见最终遗迹。

真正变化的是人物与异常的关系。

### 后续怎么用

相邻图片至少改变以下一项：

- 空间位置；
- 人物动作；
- 可见证据；
- 风险等级；
- 拍摄目的；
- 光线条件；
- 媒介来源。

仅仅“左侧机位换右侧机位”，不构成推进。

------

## 规律九：高潮可以更强，但不能撤销前面建立的纪录片规则

本作最后的龙骨画面明显比前面更接近奇观构图：

- 巨大龙头占据前景；
- 中央人形遗骸被明显照亮；
- 视角稍高；
- 巨物结构比较完整。

它依然没有彻底出戏，是因为人物、手机、手电和洞穴黑暗仍然存在。

但这张也是整组最接近概念图的一张：中央遗骸的光源略显刻意，龙骨排列过于完整，拍摄者为何站在较高位置也没有充分交代。

### 后续怎么用

高潮画面至少保留三项纪录锚点：

1. 合理拍摄位置；
2. 普通人物或常规物体的尺度参照；
3. 可追溯的现场光源；
4. 局部遮挡；
5. 延续前图的服装、道具或环境。

视觉回报可以升级，记录逻辑不能消失。

------

## 规律十：连续性依靠“识别锚点”，不必每张都强求清晰正脸

本作最稳定的人物锚点是：

- 粉色外套、米色针织帽、棕色背包；
- 白色外套、黑色背包、眼镜；
- 深色外套、绿色背包；
- 登山杖和固定配色。

即使人物背对镜头，用户仍能完成身份匹配。

### 后续怎么用

每个主要人物保留两到三个高辨识锚点：

> 外套色块＋背包形状＋帽子或工具。

不要只依赖脸，因为真实记录里大量镜头根本看不清脸。

同时避免本作出现的重复问题：首尾自拍完全复用，前两张也近似重复。除非剧情明确需要“前后照片对比”，否则不要把同一图片反复当新分镜。

------

# 4. 五大假感来源

## 第一类：展示性构图压倒记录逻辑

包括：

- 海报感；
- 概念图感；
- 游戏原画感；
- 电影剧照感；
- 所有元素朝向观众；
- 怪物与人物完美分列画面两侧。

问题不在于构图好看，而在于摄影机明显只为观众服务，不属于事件现场。

------

## 第二类：人物在表演，而不是在经历

包括：

- 演员脸和模特脸；
- 所有人皮肤、五官和身材高度统一；
- 集体望向镜头；
- 每个人都有清晰表情；
- 危险发生时仍保持漂亮站姿；
- 职业人物像穿制服拍宣传片。

真实人物通常只有少数人在看镜头，其余人各自处理现场。

------

## 第三类：成像过度设计

包括：

- 过度精修；
- 无来源电影光；
- 大面积蓝橙调色；
- 人物始终被轮廓光勾边；
- 过度浅景深；
- 每张都有漂亮雾气、镜头光晕；
- 为了装真而统一增加重噪点、脏镜头和故障线。

“画质很差”和“真实拍摄”不是一回事。故意低清同样是一种明显设计痕迹。

------

## 第四类：异常与现场没有物理连接

包括：

- 异常单独发光；
- 怪物像贴在背景上；
- 巨物没有投影、压痕、积雪或尘土；
- 人物完全不受它影响；
- 环境没有任何遮挡；
- 尺度没有参照；
- 所有细节都同时清晰可见。

高级异常不是“更漂亮的怪物”，而是更完整的现场物理关系。

------

## 第五类：连续图片只保持外观，没有保持事件

包括：

- 同一场景不断换机位；
- 人物每张重新排队；
- 服装稳定，但动作没有因果；
- 场景从远景突然跳到内部，没有路径过渡；
- 前图的小洞口，下一图突然变成完全不同结构的大门；
- 高潮换成另一套画风；
- 直接重复使用同一张图。

本作中“远处小洞—巨大洞口”的空间跳跃，以及首尾自拍重复，就是后续创作最值得修正的两点。

------

## 《这类内容最容易翻车的假感来源清单》

| 假感来源       | 典型表现                         | 修正方向                           |
| -------------- | -------------------------------- | ---------------------------------- |
| 海报感         | 主体居中、全员正面、异常完整展示 | 改为现场机位、局部遮挡、非完美取景 |
| 摆拍感         | 人物停下来供镜头观看             | 让人物执行具体动作                 |
| 演员感         | 统一精致脸、干净妆发、戏剧表情   | 使用普通面孔、疲态和个体差异       |
| 概念图感       | 场景只表达一个宏大概念           | 增加使用痕迹和现实功能             |
| 电影剧照感     | 摄影机总在最佳机位               | 限制在拍摄者能到达的位置           |
| 过度精修感     | 皮肤、材质、光线都无瑕           | 保留自动曝光和现场不均匀性         |
| 故意脏乱低清   | 全画面重颗粒、模糊、污渍         | 只保留由条件造成的局部缺陷         |
| 滤镜感         | 全组统一青灰、蓝橙或复古色       | 让白平衡由现场光源决定             |
| 无来源戏剧光   | 异常被完美照亮，光源看不见       | 明确窗、灯、手机、火、车灯或日光   |
| 异常特效廉价化 | 发光轮廓、浓雾、粒子、闪电       | 转向材质、尺度、遮挡和环境互动     |
| 背景空洞       | 只有主体和一块干净背景           | 增加空间用途、杂物和非剧情人物     |
| 镜头不成立     | 无人能站到的高空或贴脸机位       | 解释拍摄平台、距离和动机           |
| 连续分镜重复   | 同场景换角度、同动作循环         | 每张增加新的空间或证据信息         |

# 5. 对标作品真实感方法库

## 5.1 影像来源方法

| 来源类型               | 真实感优势                                 | 最容易翻车的风险                         |
| ---------------------- | ------------------------------------------ | ---------------------------------------- |
| 普通手机照片/相册      | 最接近日常分享，自拍、随手拍、求证照都合理 | 每张都像专业摄影；景深过浅；镜头始终完美 |
| 手机视频截帧           | 能容纳走动、突发、模糊和自动曝光变化       | 人工添加运动模糊；每帧都像动作电影       |
| 监控/固定摄像头        | 机位稳定、非主动拍摄，异常更像意外闯入     | 监控恰好覆盖所有关键位置；异常总在正中央 |
| 工作记录设备           | 拍摄动机强，可使用航拍、热成像、检测设备   | 伪造复杂UI，设备参数和现场行为不匹配     |
| 路人、新闻或多来源记录 | 能形成交叉证据，扩大事件规模               | 媒介切换太频繁，角色与设备身份不清       |

### 可直接作为创作约束

> 整组图片首先归属于一种主要影像来源。只有剧情发生明确阶段变化时，才允许切换媒介；每次切换必须带来新的观察能力，而不是单纯换视觉风格。

------

## 5.2 拍摄者逻辑方法

### 五种可用拍摄者

| 拍摄者               | 合理拍摄内容                               |
| -------------------- | ------------------------------------------ |
| 事件参与者           | 行程、朋友、突然发现、现场求证             |
| 同行但不直接操作的人 | 他人工作过程、救援过程、探索过程           |
| 偶然旁观者           | 突发事件、公共奇观、混乱现场               |
| 专业记录者           | 调查、检测、取证、新闻、文保或工程         |
| 自动设备             | 固定区域、预设航线、长期监控或无人值守记录 |

### 强制约束

每张图必须明确：

> 谁在拍；站在哪里；为什么拍；主体是否知道；拍摄完成后他下一步要做什么。

### 最假拍摄逻辑

- 主角独自一人，却连续拥有第三人称全身照片；
- 所有人都在画面里，却没有自拍装置；
- 危险正在逼近，摄影者仍绕到最佳角度；
- 摄影者能够瞬间跨越封闭空间；
- 每个关键时刻都恰好有设备对准；
- 摄像机比人物先知道异常藏在哪里。

------

## 5.3 镜头方法

| 叙事功能     | 最适合的镜头                                       | 应避免                     |
| ------------ | -------------------------------------------------- | -------------------------- |
| 建立正常现实 | 普通自拍、环境中远景、队尾跟拍、工作空间广角       | 史诗大全景、低机位英雄照   |
| 发现异常     | 肩后视角、人物指向、远处局部异常、被遮挡的视线     | 异常正面完整亮相           |
| 靠近求证     | 行走中跟拍、门外观察、侧后机位、前景遮挡           | 突然切到异常内部的完美视角 |
| 证据确认     | 手机近拍、手电照明特写、人物与证据同框             | 纯产品展示式特写           |
| 风险升级     | 更窄空间、更近距离、更困难的曝光条件               | 仅靠倾斜画面和红色滤镜     |
| 高潮兑现     | 有尺度参照的广角、受限视野中的巨物、可解释的高机位 | 怪物海报、对称祭坛式构图   |

### 机位约束表达

> 镜头高度、距离和遮挡应由拍摄者当时的身体位置决定；允许人物背部、门框、车辆、桌角或设备占据前景，不主动清空视线。

------

## 5.4 人物方法

### 稳定规律

- 普通面孔，不追求精致五官；
- 年龄和体型存在差异；
- 服装首先符合天气、工作和活动；
- 动作由任务驱动；
- 大部分人物不看镜头；
- 允许被裁切、背对、遮挡；
- 每人保留两三个身份锚点；
- 同组人物不使用同一套脸型、发型和姿态。

### “普通但不无聊”的方法

普通不等于没有辨识度。辨识度可以来自：

- 一件颜色明确的外套；
- 有使用痕迹的工具；
- 特定背包或帽子；
- 习惯性动作；
- 与他人的位置关系；
- 角色正在负责的任务。

------

## 5.5 环境方法

### 最有效的环境细节

- 与空间用途有关的普通设施；
- 非剧情人物或车辆；
- 地面不均匀的水、雪、灰、泥或磨损；
- 线缆、箱子、包装、路牌、工具等功能性杂物；
- 被长期使用后形成的局部污渍和变色；
- 光照不到的死角；
- 门框、护栏、台阶和墙体厚度；
- 不为主体让路的背景元素。

### 强制约束

> 环境必须表现出“在故事开始前已经被人使用了一段时间”，而不是刚为这次事件搭建完成。

### 常见假背景

- 空间面积很大，但几乎没有物品；
- 所有杂物都在强调剧情；
- 地面、墙壁和家具具有同样的新旧程度；
- 场景异常整洁，或反过来全部均匀破败；
- 远景没有任何生活、工作或交通痕迹。

------

## 5.6 光线方法

### 最有效的真实光线策略

1. **单一主现场光源**
   阴天、顶灯、窗光、路灯、车灯或手电。
2. **有限照明范围**
   手电只照亮局部，路灯只照亮一段地面。
3. **允许曝光取舍**
   外面亮时室内黑，火焰清楚时周围人物可能偏暗。
4. **轻微混合色温**
   顶灯偏冷，台灯偏暖；路灯与店内灯不同。
5. **人物不被单独照顾**
   脸可能处在半暗、顶光或屏幕反光中。

### 会破坏伪纪实的“电影光”

- 没有来源的背光；
- 每个人都有独立轮廓光；
- 大面积体积雾；
- 蓝色月光和橙色火光恰好均衡；
- 黑暗空间里的巨物被完整柔和照亮；
- 所有重要信息都处在最漂亮的亮度范围。

### 有情绪但不油腻

情绪应来自：

> 现场光源的变化、人物距离、照明范围和信息显露程度。

而不是统一套一层“悬疑青灰滤镜”。

------

## 5.7 异常融合方法

### 最重要的七条原则

1. 异常与环境共用同一透视；
2. 异常与现场共用同一光源；
3. 异常被现实物体部分遮挡；
4. 异常对地面、空气或附近物体产生影响；
5. 异常拥有普通物体作为尺度参照；
6. 人物以合理方式观察或处理异常；
7. 异常只呈现当前设备能够拍到的部分。

### 廉价异常处理

- 独立彩色发光；
- 完整正面悬浮；
- 周围持续冒浓雾；
- 只增加触手、红眼和粒子；
- 怪物与地面接触位置模糊；
- 异常极清晰，环境反而模糊；
- 人物像看不见它；
- 巨物没有重量感和环境反馈。

### 不同题材的融合方向

| 题材      | 更适合的真实感策略                           |
| --------- | -------------------------------------------- |
| 恐怖悬疑  | 局部可见、间接证据、固定视角、受限照明       |
| 历史/神话 | 现代目击者视角、旧物材质、自然风化、现实尺度 |
| 温情反差  | 日常明亮空间、普通动作、小范围异常、自然反应 |
| 抽象/带梗 | 把抽象概念变成可占据空间、可被路人处理的事件 |
| 宏大奇观  | 远距离观察、天气和空气透视、车辆或建筑作尺度 |
| 职业记录  | 流程、工具、检查动作和设备能力边界           |

------

## 5.8 连续分镜防重复方法

### 六种最有效的变化

1. **距离变化**：远处发现→接近→局部确认；
2. **空间变化**：室外→门口→通道→核心区域；
3. **动作变化**：行走→停下→检查→处理→撤离；
4. **证据变化**：模糊迹象→可疑结构→明确物证；
5. **关系变化**：人物不知道→怀疑→确认→受影响；
6. **媒介变化**：普通手机→监控回看→无人机或检测图，但必须有必要性。

### 有效重复

- 同一位置前后状态对比；
- 同一人物动作发生实质变化；
- 同一物体被不同证据重新解释；
- 同一照片在结尾被放大，暴露此前未注意的细节。

### 无效重复

- 同一张图重新裁切；
- 相同动作仅换角度；
- 人物每张都围着异常站一圈；
- 连续三张都是手电照墙；
- 远景、中景、近景呈现完全相同的信息。

------

## 5.9 稳定共性与可选技巧

### A. 后续应固定继承的底层共性

- 先确定影像来源；
- 每张有拍摄理由；
- 正常世界先建立信用；
- 机位属于现场中的某个人或设备；
- 人物执行任务而非展示；
- 环境拥有独立生活和使用痕迹；
- 光源可以追溯；
- 异常具有尺度、遮挡、材质和互动；
- 连续图片形成证据链；
- 高潮仍保留纪录锚点。

### B. 可按题材选择的局部技巧

- 低照度噪点；
- 数码变焦；
- 监控时间码；
- 无人机俯拍；
- 运动模糊；
- 雨雪、雾气；
- 玻璃反射；
- 多媒介交叉记录；
- 极端高低机位；
- 设备UI；
- 故意失焦或画面损坏。

这些技巧不是越多越真。只有当设备、天气和拍摄过程真的会产生它们时，才应该使用。

------

# 6. 可直接复用的真实性写法模板

## 6.1 影像来源模板

```text
[设备或媒介]在[时间、地点]留下的普通现场记录。

拍摄者是[具体身份]，当时正在[正在进行的现实行动]，
拍摄这张画面的原因是[留念、报告、求证、记录异常、保存证据]。

画面属于真实事件过程中断续留下的影像，
不是宣传照，不是电影剧照，不是第三人称全知视角。
```

------

## 6.2 镜头与机位模板

```text
镜头位于[拍摄者实际能够站立的位置]，
高度约为[眼平、胸口、腰部、固定设备高度]，
距离主体约[具体距离关系]。

采用[普通广角、手机主摄、轻微数码变焦、固定监控视角]。
主体不必严格居中，允许前景出现[肩膀、背包、门框、车辆、设备]的自然遮挡，
边缘人物可以被裁切，构图像当场迅速完成，而不是事先排练。
```

------

## 6.3 人物普通感模板

```text
人物具有普通真实面孔和自然个体差异，
不使用演员式精致五官，不统一身材和发型。

服装首先符合[天气、职业、活动和经济条件]，
带有轻微使用折痕和自然磨损，但保持正常干净程度。

人物正在[具体动作]，
注意力集中在现场任务或异常上，
大多数人不看镜头，不摆英雄姿势，不集体展示表情。
```

------

## 6.4 环境模板

```text
场景是一处真实使用中的[空间类型]，
保留与其用途相关的普通设施、杂物和长期使用痕迹。

地面、墙壁和器材的新旧程度不完全一致，
存在自然磨损、局部污渍、光线死角和非剧情性物件。

背景不能空旷，也不能把所有细节都设计成剧情提示；
空间应表现为在事件发生前就已经正常运作。
```

------

## 6.5 自然光源模板

```text
主要光源来自现场原本存在的[阴天、窗户、顶灯、路灯、车灯、手电、屏幕、火焰]。

光照分布不均匀，人物和异常不会被摄影棚式单独补光。
自动曝光优先照顾[最亮区域]，
因此[暗部略压黑、高光轻微溢出、面部局部偏暗]。

不同现场光源允许形成轻微色温差，
但不做统一蓝橙调色，不增加无来源轮廓光。
```

------

## 6.6 成像结果模板

```text
画面清晰度符合普通消费级设备自动模式，
保留有限的动态范围、轻微白平衡偏差和正常压缩痕迹。

低照度区域可以出现细小噪点和细节损失，
快速移动区域可以有轻微拖影，
但不要全画面统一模糊、重颗粒、脏镜头或故障条纹。

真实感来自设备对现场条件的自然反应，而不是故意做旧。
```

------

## 6.7 异常融合模板

```text
异常内容真实占据现场空间，与环境共用同一透视、光源和空气条件。

它被[人物、门框、岩石、车辆、家具、烟尘]部分遮挡，
并与地面或附近物体产生[压痕、积雪、灰尘、反射、阴影、破损、位移]。

异常尺度由[人物、门、车辆、建筑、工具]自然对照。
表面材质受到现场环境影响，具有相应的潮湿、风化、尘土、积雪或磨损。

异常不单独发光，不像后期贴图，
只呈现当前拍摄位置和设备真正能够记录到的部分。
```

------

## 6.8 发现异常模板

```text
异常首次出现时只占画面较小区域，
拍摄者并未提前精准对准它。

人物先通过回头、停步、指向、靠近或举起设备表达发现过程，
画面同时保留大量正常环境，
让异常像意外进入现实照片，而不是专门登场。
```

------

## 6.9 高潮兑现模板

```text
画面提供明确视觉回报，但仍属于同一记录系统。

保留至少三项现实锚点：
合理拍摄位置、普通人物尺度、现场光源、局部遮挡、连续服装道具、环境互动。

奇观可以更大、更清楚，但不采用海报式完整正面展示，
不取消黑暗、距离、天气和设备能力带来的限制。
```

------

## 6.10 通用负面约束模板

```text
不要海报式居中英雄构图；
不要电影宣传照和游戏概念图质感；
不要所有人物同时看镜头；
不要统一精致演员脸；
不要摄影棚补光和无来源轮廓光；
不要过度浅景深、蓝橙调色、浓雾、光晕和粒子特效；
不要异常物体独立发光或悬浮贴图；
不要背景空洞或过度整洁；
不要故意低清、重噪点、重滤镜和伪监控故障；
不要让摄影机出现在现实中无法到达的位置；
不要连续使用相同机位和相同动作；
不要为了展示异常而清空所有前景遮挡。
```

# 7. 《AI伪纪实连续图片创作的真实感设计底座》

## 一、核心定义

AI伪纪实图片不是“把虚构内容画得像照片”。

它是：

> **先建立一套真实影像生产条件，再让虚构事件在这些条件下被偶然记录、逐渐求证并最终兑现。**

------

## 二、四层真实感结构

### 第一层：来源真实

整组图片必须属于某个现实影像系统。

明确：

- 设备；
- 拍摄者；
- 使用场景；
- 保存和传播方式。

------

### 第二层：行为真实

摄影者和人物的行为必须符合当时处境。

明确：

- 为什么拍；
- 为什么站在这里；
- 人物正在做什么；
- 拍完后将采取什么行动。

------

### 第三层：物理真实

人物、环境和异常必须共享同一个空间。

统一处理：

- 透视；
- 光照；
- 尺度；
- 遮挡；
- 接触；
- 材质；
- 天气；
- 空气和地面反馈。

------

### 第四层：连续真实

整组图片必须像一段事件留下的证据，而不是同题材图片合集。

保持：

- 人物身份锚点；
- 服装和工具；
- 时间和天气；
- 空间路线；
- 异常状态；
- 风险和拍摄动机的递进。

------

## 三、十二条固定底线

1. 每组图先写清影像来源。
2. 每张图都能回答“为什么会被拍下”。
3. 正常世界必须拥有足够普通细节。
4. 摄影机不得成为全知视角。
5. 人物优先做事，不优先展示脸。
6. 环境不得只是主体背景板。
7. 光源必须可以追溯。
8. 成像缺陷必须由设备和条件产生。
9. 异常必须拥有尺度、遮挡和接触关系。
10. 相邻图片必须增加新的事件信息。
11. 高潮允许升级，但必须保留纪录锚点。
12. 不用低清、滤镜和脏感替代真正的现场逻辑。

------

## 四、允许自由变化的部分

真实感底座不限制：

- 题材；
- 异常规模；
- 情绪；
- 色彩；
- 时代；
- 城市或自然环境；
- 使用设备；
- 画面是否明亮；
- 是否出现宏大奇观；
- 是否采用温情、荒诞或浪漫表达。

真正不能放弃的，只是：

> 摄影机为什么存在，以及异常怎样存在于这个摄影机所处的现实中。

------

## 五、视觉回报保护原则

不能因为追求真实，就永远只拍模糊角落和局部证据。

推荐采用：

> **前期严格受限，中期逐步确认，高潮有限放开。**

高潮阶段可以：

- 扩大景别；
- 提高异常可见度；
- 使用航拍或高位；
- 展示更大规模；
- 给出清楚结果。

但必须保留至少三项：

- 拍摄动机；
- 人物或建筑尺度；
- 现场光源；
- 环境遮挡；
- 空气透视；
- 前后连续锚点。

这样既不会把奇观压没，也不会突然变成海报。

------

## 六、逐张审核问题

每张图生成前，用这八个问题检查：

| 审核问题                         | 不成立时的处理                 |
| -------------------------------- | ------------------------------ |
| 谁在拍？                         | 补充明确拍摄者或改用自动设备   |
| 为什么现在拍？                   | 增加留念、求证、记录或报告动机 |
| 摄影者能站在这里吗？             | 调整机位或交代平台             |
| 人物在做什么？                   | 用具体任务替代摆姿势           |
| 光从哪里来？                     | 添加真实光源或降低可见范围     |
| 异常怎样接触现场？               | 补充遮挡、阴影、压痕和材质反馈 |
| 本张比上一张新增了什么？         | 改变空间、动作、证据或风险     |
| 去掉异常后，场景还像真实空间吗？ | 增加独立环境用途和普通细节     |

最终判断标准不是：

> “这张图够不够漂亮？”

而是：

> **“它是否像某个真实的人，在这件不可能事件中，确实有理由拍下的一张照片？”**

这就是这组对标作品最值得继承的底层能力。
