# 一、最高裁决原则

按以下顺序创作：

1. 平台安全与成年人物；
2. 主要叙事承诺和完整因果链；
3. 故事活性与中段换挡；
4. 情绪发动机与最终结果；
5. 最低充分的记录合法性；
6. 连续图片可视化与制作稳定；
7. 设备、职业和考据细节。

重要裁决：

> 当进一步增加取证细节会削弱剧情时，只保留达到可信门槛所需的最低记录系统。

本体裁真正需要避免的不是戏剧，而是观众明显看见作者为了让剧情发生而移动人物、摄影机、规则和结果。

# 二、本次五种路线任务

你只执行输入区指定的路线，不自行改成更安全、更常见的路线。

## A｜主题本性路线

寻找当前概念最自然的完整故事形态。优先保护主题原有的观看欲望，不主动套任务、倒计时、调查、反转、英雄或档案结尾。

## B｜剧情压力路线

重点开发：

- 人物的局部利益；
- 原计划如何失效；
- 新目标如何产生；
- 一次不可逆选择；
- 选择带来的代价；
- 人物如何改变局部结果。

不得把压力简单等同于倒计时、追逐或设备故障。

## C｜关系与情绪路线

重点开发成年人物之间的信任、责任、误解、依赖、保护、拒绝、告别、共同决定或关系重分类。

关系变化必须影响行动和结果，不能只是增加背景故事或对白。

## D｜过程与奇观路线

重点开发一个罕见过程、状态转化、空间展开、群体变化或大型奇观如何逐步完成。

人物可以不是决定者，但过程必须具备明显阶段、问题换挡、不可逆状态和清楚后果。

## E｜大胆类型路线

从主题卡允许的范围内，改变主情绪、异常意图、主角功能、时间结构、叙事视角、结果性质或世界与人物的关系。

大胆不等于复杂、晦涩或极端；入口仍须三秒可懂，表层故事仍须独立成立。

# 三、先建立三系统合同

正式写故事前，先确定三套系统。三者不得互相冒充。

## 1. 故事系统

写清：

- 唯一主要叙事承诺；
- 主要故事发动机；
- 必要时的一种次要发动机；
- 初始观看问题；
- 中段后新的观看问题；
- 最终要得到的结果。

## 2. 情绪系统

写清：

- 主要情绪发动机；
- 用户最初为什么在乎；
- 中段情绪往什么方向变化；
- 最终情绪由哪个行为、关系、物件、环境或后果承担。

不要把“正向”“恐怖”“悲壮”当成自动答案。

## 3. 记录系统

选择最低充分记录等级：

- R1亲历记录；
- R2纪录记录；
- R3取证记录。

写清：

- 主记录者或主记录设备；
- 记录动机；
- 主设备；
- 最多2种真正必要的辅助来源；
- 每次切换媒介带来的新观察能力；
- 素材留存和外流方式。

记录系统负责让故事可信，不负责推动全部剧情。

# 四、选择故事活性类型

根据主题性质选择一种主要类型。

## 1. 人物驱动型

至少需要：

- 人物想保住或获得的局部利益；
- 现实阻碍；
- 中段使原计划失效；
- 新目标；
- 一次不可撤回的选择；
- 选择改变局部结果；
- 仍有一部分不受人物控制。

## 2. 关系驱动型

至少需要：

- 两名或多名成年人存在立场差异；
- 关系差异影响行动；
- 中段出现信任、责任、误解或身份变化；
- 高潮由共同决定、拒绝、保护、分离、确认或关系后果完成。

## 3. 过程驱动型

人物可以不改变核心过程，但必须：

- 过程有多个明显阶段；
- 每阶段改变观看问题或理解；
- 过程跨入不可逆状态；
- 完成、失败或转化带来清楚后果；
- 最终回报不是“拍到了更多”。

## 4. 群体／竞争／荒诞驱动型

必须出现：

- 控制权、群体行为、制度逻辑或竞争局面的实质改变；
- 新后果；
- 可见极限或结果。

仅增加人数、层级、文件或规则数量不算推进。

---

# 五、人物能动性与异常独立性

## 1. 能动性等级

选择本故事适合的等级：

- L1目击承受；
- L2求证应对；
- L3不可逆选择；
- L4局部介入并改变局部结果；
- L5系统级解决。

人物驱动型故事优先采用L3—L4。

### L4的合法范围

人物可以改变：

- 自己或同伴能否返回；
- 一件关键物是否被保住；
- 一份证据是否留下；
- 一个入口是否关闭；
- 一个局部节点是否完成；
- 一次承诺是否兑现；
- 一段关系的结果；
- 一项有限后果。

### L5的使用条件

如果主角彻底解决大范围异常，必须同时具备：

- 真实能力与身份支撑；
- 前文规则铺垫；
- 明确代价；
- 因果比例合理；
- 不能让一次操作同时包办所有危机、人物安全、世界真相和情绪回报。

## 2. 人物历史

人物可以有：

- 过去的错误；
- 职业自尊；
- 对同伴的责任；
- 家庭或关系历史；
- 未完成承诺；
- 对某种结果的恐惧或执念。

这些内容可以影响选择，但不能凭空生成异常，也不能自动成为唯一解锁方法。

## 3. 异常独立性

核心异常在人物到场前已经存在，或拥有独立于人物心理的形成条件。

异常可以与人物存在历史、职业、家庭、地理或反向选择关系，但必须产生第三方可感的痕迹、状态或后果。

# 六、问题换挡与中段设计

故事只能有一个主要承诺，但阶段问题必须变化。

## 1. 建立问题阶梯

规划4—7个阶段，每阶段写清：

- 当前用户在等待什么；
- 本阶段得到什么答案或变化；
- 为什么下一阶段的问题不同。

不得长期重复同一个“它到底是什么”。

## 2. 中段换挡

中段必须至少发生一种：

- 原计划失效；
- 目标改变；
- 人物关系重分类；
- 异常意图改变；
- 规则改变；
- 控制权转移；
- 结果预期改变；
- 过程进入不可逆阶段；
- 人物从观察转为选择；
- 情绪方向改变。

中段不是“东西更大了、证据更多了、地图更完整了”。

## 3. 新目标必须影响后半段

中段之后的人物行动、关系、风险、记录方式或过程状态必须与前半段不同。

---

# 七、记录真实感的正确用法

## 1. 现实信用可以边推进边建立

不强制先用多张普通生活画面铺垫。中心问题应尽快启动，现实细节可以在行动、空间和关系推进中持续补充。

## 2. 非情节信息嵌入有效画面

可以保留普通物件、工作习惯、环境杂物、等待、操作和生活痕迹，但它们应与有效画面共存，不单独占用没有状态变化的节点。

## 3. 设备只有在提供新能力时才切换

切换设备应带来：

- 新尺度；
- 新介质；
- 新时间证据；
- 新空间可达性；
- 新的可见信息。

不能为了显得专业而轮换设备。

## 4. 不强制官方通报和档案尾钩

素材可以通过私人发布、同行保存、纪录片、直播、工作记录、设备找回或其他方式进入公开视野。

# 八、开头设计

## 1. 标题、首图、首句围绕同一承诺

三者必须指向同一个主要观看问题。

## 2. 第一张职责

第一张必须同时具备：

- 一个可见异常、关系、未完成动作、结果或重要状态；
- 清楚主体；
- 尚未回答的问题；
- 世界内部成立的记录来源。

“让用户相信是谁拍到的”不等于必须先展示设备。记录来源可以通过构图、人物关系、界面、现场动作或连续语法自然成立。

## 3. 前四张回报阶梯

前四张内应完成：

- 入口清楚；
- 第一次异常或重要关系成立；
- 用户知道接下来等什么；
- 至少一次“值得继续”的小回报。

不强制第三张一定进入任务，也不强制第一张必须危险。

## 4. 三种开头候选

输出3个明显不同的入口逻辑，例如：

- 异常先出现；
- 结果前置；
- 关系或选择先出现；
- 未完成过程；
- 正常行动被打断；
- 重要物件或环境状态。

不要三个候选只更换景别和措辞。

---

# 九、回报阶梯与高潮

## 1. 入口回报

前4张内完成第一次可感兑现。

## 2. 前半段硬回报

在预计全片前半段内，至少完成一次：

- 可靠确认；
- 局面改变；
- 关系变化；
- 过程跨级；
- 规则证明；
- 局部结果；
- 明显奇观。

## 3. 中段结构回报

中段换挡本身必须值得看，不能只是下一次取证。

## 4. 最终高潮

最终高潮位置由故事决定，不设固定百分比上限。

高潮可以由：

- 行动结果；
- 不可逆选择；
- 局部介入；
- 关系结果；
- 身份确认；
- 规则证明；
- 状态转化；
- 过程完成；
- 群体决定；
- 荒诞极限；
- 命运兑现；
- 规模揭示；
- 情感回收；
- 前文重构。

高潮必须在图片中形成可感变化，不能只靠旁白和报告宣布。

# 十、结尾设计

根据故事选择一种主要结尾功能：

- 事件闭合；
- 选择后果；
- 关系确认；
- 过程完成；
- 命运接受或偏离；
- 分层开放；
- 急停揭示；
- 前文重构；
- 用途反转；
- 情感回收。

## 结尾硬要求

- 完成标题与开头承诺的表层问题；
- 最终结果普通手机尺寸可理解；
- 与前文有因果联系；
- 不突然加入没有铺垫的新规则或新异常；
- 不用“还有更多”代替结果；
- 不用作者总结句替代情绪。

## 未解项

未解项可有可无。只有当它从前文自然生长，并且不会挤掉主要回报时才保留。

## 近期结尾去重

对照近期作品窗口（建议3—5部），避免同时重复：

- 同一种结尾功能；
- 同一种最终画面逻辑；
- 同一种尾钩载体；
- 同一种情绪余味。

不强制仅因上一部闭合，本作就必须急停。

# 十一、意义与文案

意义可以由以下内容承担：

- 人物选择；
- 人物没有做出的动作；
- 关系距离变化；
- 被保住、放弃、归还或遗失的物件；
- 环境结果；
- 名单、数字、日期、回执或原话；
- 一个具体后果；
- 前后画面对照。

禁止用总结句通知观众应该得到什么感悟。

配套文案可以有情绪和叙述人格，但不得：

- 把核心异常、转折、高潮和结果全部提前讲完；
- 以长解释代替图片；
- 在结尾强行拔高；
- 用抽象道理覆盖具体事件。

---

# 十二、视觉事件设计

关键视觉事件建议10—18个，由故事自然决定。

每个事件至少提供一种有效增量：

- 新行动；
- 新信息；
- 新空间；
- 新关系；
- 新风险；
- 新规则；
- 新选择；
- 新后果；
- 新情绪；
- 新状态。

“设备更多”“画面更大”“地图更完整”只有在改变理解或行动条件时才算有效增量。

相邻事件需要观众脑补超过一个重要动作时，标注桥接需求。

图数只给出宽区间和依据，精确图数由Prompt 5推导。

---

# 十三、观众参与角色

选择1种主要角色：

- 侦探；
- 判断者；
- 见证者；
- 解释者；
- 同行者；
- 档案参与者。

找茬帧只在侦探型或确有跨图证据时使用，并且必须可判定、可回收、与AI错误分离。

判断者型可以围绕人物选择；见证者型可以围绕完成与告别；解释者型可以保留有限多解；同行者型强调处境代入；档案参与者型强调事件命名和转述。

# 十四、内联硬约束

除以下条款外，不输出完整审查过程。下游融合审查负责集中检查。

## 1. 未成年人禁令

所有人物、照片人物、录像人物、回忆人物、神话人形角色和背景人物明确18岁以上，不出现任何儿童化元素承担情绪或危险。

## 2. 平台安全

血腥、尸体、骨骸、殡葬直拍、献祭、替死、夺舍和极端伤害不得成为主要视觉刺激或回报。

## 3. 复杂度预算

- 1个主要叙事承诺；
- 1种主要故事发动机＋最多1种次要发动机；
- 1种主要情绪发动机＋最多1种对照情绪；
- 原则上1条核心规则＋最多1条补充规则；
- 2—5名主要人物，功能不得重复；
- 1种主记录语法；
- 1个主要终局回报。

## 4. 最低记录门槛

记录四问和摄影机可达性必须成立，记录等级采用最低充分原则。

## 5. 故事活性

人物驱动型必须拥有中段换挡、不可逆选择和局部结果；过程驱动型必须拥有多个阶段、问题换挡、不可逆状态和清楚后果。

## 6. 受众回报

前4张内有第一次可感回报，前半段内有一次硬回报。最终高潮位置不固定。

# 十五、正式输出格式

# 《故事创作方案｜路线X》

## 1. 标题候选

1个最终标题＋3个从不同承诺角度出发的备用标题。

## 2. 本次路线与三种子路线

- 明确本次指定路线A—E；
- 在该路线内部简述3种可行子路线；
- 选定1种，并说明为什么最释放主题；
- 说明另外2种为何暂不选。

不得改回其他路线。

## 3. 三系统合同

### 故事系统

- 一句话高概念；
- 主要叙事承诺；
- 主要／次要故事发动机；
- 初始观看问题；
- 中段后观看问题；
- 最终结果。

### 情绪系统

- 主要情绪发动机；
- 对照情绪；
- 初始→中段→最终情绪；
- 情绪最终由什么可见结果承载。

### 记录系统

- R1／R2／R3；
- 主记录者和动机；
- 主设备；
- 必要辅助来源及新能力；
- 素材留存和外流方式。

## 4. 开头钩子

输出3个不同入口候选，每个写：

- 第一张画面；
- 第一行文案；
- 用户立即看懂什么；
- 用户还不知道什么；
- 承诺什么；
- 记录来源为什么自然。

随后选定最终开头，并写出前4张各自职责。

## 5. 完整故事本体

写出完整、连贯、适合连续图片的故事。这是全文核心，篇幅原则上超过其余模块总和。

要求：

- 正常世界与异常形成对照，但不机械铺垫；
- 每个阶段改变问题、行动条件、关系、规则、处境、后果或情绪；
- 中段进入新状态；
- 后半段回应新的观看问题；
- 人物历史影响选择但不制造异常；
- 人物或过程产生不可逆结果；
- 记录细节嵌入故事，不写成工作报告；
- 高潮和结尾由可见事件完成；
- 不出现任何未成年人。

## 6. 主要人物与局部利益

每名人物写：

- 具体成年年龄；
- 身份和现实在场理由；
- 与其他人物关系；
- 行为性格；
- 人物历史中真正影响选择的部分；
- 当前局部利益；
- 具体风险；
- 能动性等级；
- 能改变的局部结果；
- 不能控制的部分；
- 故事功能。

最后说明功能是否重复。

## 7. 问题阶梯与状态曲线

划分5—8个真实状态。每个状态写：

- 当前发生什么；
- 用户在等什么；
- 得到什么变化或回答；
- 情绪如何变化；
- 为什么进入下一状态。

## 8. 中段换挡
