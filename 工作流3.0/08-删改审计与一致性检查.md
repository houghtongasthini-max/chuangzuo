# 工作流3.0｜删改审计与一致性检查

## 一、本次改造性质

本次不是在2.1末尾追加补丁，而是围绕同一套跨文件合同完成重写。

五个核心文件相较2.1均缩短：

| 文件 | 3.0相对2.1字符变化 |
|---|---:|
| Prompt 3 | 约 -18% |
| 融合审查-选题 | 约 -6% |
| Prompt 4 | 约 -8% |
| 融合审查-故事 | 约 -19% |
| Prompt 5 | 约 -34% |

压缩主要来自删除重复门禁、固定模板、具体案例、过度设备说明和相互重叠的检查。

---

## 二、已删除或替换的核心冲突

### 1. 记录合法性既是恒定轴又参与高低评分

**旧风险**：模型会为了得高分不断增加设备、档案、时间码和取证流程。

**3.0处理**：记录合法性只做“通过／改造／不通过”；通过后按故事潜力评分。

### 2. 当代现实入口与题材开放冲突

**旧风险**：历史、未来、奇幻和私人叙事被迫套当代工作人员入口。

**3.0处理**：改为“世界内部成立的记录入口”，不限定时代和职业。

### 3. 正情绪恒定轴与情绪开放冲突

**旧风险**：创作端被迫把所有故事导向荣耀、感动或治愈，同时反模板条款又禁止强行拔高。

**3.0处理**：删除固定正情绪轴，改为主情绪明确、情绪有变轨、不得长期无回报压抑。

### 4. 22—28张选题恒定轴与故事图数推导冲突

**旧风险**：简单故事被拉长，大型故事被压缩。

**3.0处理**：图数完全移交Prompt 5，根据状态事件和桥接动态推导。

### 5. Prompt 4证据链路线与多模型分化目标冲突

**旧风险**：五个模型都把同一主题写成更完整的求证记录。

**3.0处理**：改成A—E五种定向路线，分别承担主题本性、剧情压力、关系情绪、过程奇观和大胆类型。

### 6. “主角无处置权”与故事性冲突

**旧风险**：主角只能观察、拍摄、上传，人物删除后故事仍成立。

**3.0处理**：改为L1—L5能动性阶梯，默认鼓励不可逆选择和局部结果权，系统级解决严格论证。

### 7. 异常独立性与人物厚度冲突

**旧风险**：为了避免心理化异常，把人物过去、责任和关系也一并删除。

**3.0处理**：允许人物历史影响选择；只禁止人物心理凭空生成异常或成为唯一超自然钥匙。

### 8. 强制双落点与结尾多样性冲突

**旧风险**：每部作品都寻找档案编号、时间差、历史重复或更大未解项。

**3.0处理**：未解项改为可选；结尾只强制完成表层承诺和可见情绪结果。

### 9. 高潮固定百分比与多级回报冲突

**旧风险**：为了提前高潮压缩前段因果，或把中段规模揭示误当最终高潮。

**3.0处理**：改用入口回报、前半段硬回报、中段换挡和最终回报四级阶梯；最终高潮位置由故事决定。

### 10. 部件融合与完整因果冲突

**旧风险**：各取最强钩子、中段、高潮、结尾，形成证据、规则和尾钩过载。

**3.0处理**：完整骨架优先，最多移植2个小部件；五份均弱直接重写第六路线。

### 11. Prompt 5故事冻结与“可画但无戏”冲突

**旧风险**：只要能生图就继续执行，无法退回结构平淡的故事。

**3.0处理**：增加故事活性退回条件，覆盖无问题换挡、无局部结果、高潮依赖报告和记录过建。

## 三、额外修正的旧版问题

### 1. 五份方案却写“其余五份供体化”

3.0不再使用该句，统一为5份完整骨架比较，选1份后最多参考其他4份中的2个小部件。

### 2. 上一部结尾类型硬性相反

旧规则容易造成机械轮换。

3.0改为比较近期作品窗口，只有“结尾功能＋最终画面＋情绪余味”同时重复时才修改。

### 3. 找茬帧被当成默认互动方式

3.0改为六种观众角色，找茬只服务侦探型作品。

### 4. 文案只能在极短钩子和文学重述之间二选一

3.0允许稀疏亲历、过程记录、人格化叙述、档案节选等多种形式；共同底线是不代替图片讲完故事。

### 5. 除首图外禁止正脸

3.0改为两种面部策略。参考图稳定、情绪高潮需要时允许1—2张受控特写；其余项目继续使用背影、侧脸和远景保证连续性。

### 6. 物件链强制1—2条

3.0改为0—2条；没有真正改变故事的物件时，使用空间、关系、动作、路线或环境状态作为承接锚点。

### 7. 封面双帧强制

3.0改为按平台和故事决定，避免所有开头固定重复一张近似图。

### 8. “宁可多三张”导致图数膨胀

3.0改为：清楚优先，但删除无信息、无担忧、无空间、无关系和无情绪增量的图。

### 9. 事件词和档案式命名强制化风险

3.0保留为发布资产，但只在故事天然适合时使用。

## 四、跨文件一致性结果

### 1. 三系统术语

Prompt 3、Prompt 4、两份融合审查和Prompt 5统一使用：

- 故事系统；
- 情绪系统；
- 记录系统。

记录系统不计入故事发动机数量。

### 2. 记录等级

五个核心文件统一使用R1／R2／R3，并统一执行最低充分原则。

### 3. 人物能动性

Prompt 3负责标注潜力，Prompt 4负责创作落实，融合审查负责比例审查，Prompt 5负责视觉化，不再前后互相否定。

### 4. 中段换挡

选题阶段提供可能，故事阶段选定，融合阶段审查，视觉阶段冻结并落实。

### 5. 结尾

所有文件统一：表层承诺必须完成；深层未解项可有可无；不得突然新增尾钩。

### 6. 图数

Prompt 3、融合选题和Prompt 4不规定固定图数；Prompt 4只给宽区间；Prompt 5最终推导。

### 7. 路线数量

统一为A—E五种路线；融合审查接收5份方案；不存在“其余五份”的数量错误。

### 8. 输出字段传递

Prompt 4终稿17模块与融合审查-故事最终输出完全对应；Prompt 5输入字段覆盖所有冻结的故事功能。

## 五、具体案例锚定检查

已对3.0目录执行关键词扫描：

- 未写入任何已发布作品名称；
- 未写入任何具体角色姓名；
- 未把某篇作品的标志性结尾、数字、物件或台词作为范例；
- 未把某一题材当作默认标准答案；
- 提示词中的说明全部采用方向、功能和抽象结构表达。

保留的少量内容类型词仅用于说明发动机、情绪、记录等级和观众角色，不构成具体剧情示范。

## 六、仍需通过运行验证的风险

### 1. 五路线成本增加

标准模式需要5次Prompt 4运行。可在低成本预筛时使用A＋B＋C三路快速模式；过程或奇观主题可将C替换为D。正式高潜力主题仍建议五路并跑。

### 2. 局部结果权可能再次任务化

融合审查已加入反模板检查：过程、群体、荒诞和关系故事不强制人物执行外部任务。

### 3. 非恐惧题材可能入口变弱

3.0要求非恐惧题材明确情绪发动机，并在前4张提供可感回报。后续需用CTR与浏览比例分别验证入口和故事。

### 4. 情绪路线可能重新心理化

允许人物历史不等于允许异常由心理生成。异常独立性仍保留为门禁和故事审查项。

### 5. 记录等级可能被模型自行升级

两个融合审查和Prompt 5都包含“能否降低一档”的反向问题，默认可降则降。

---

## 七、建议的首次验证

1. 使用一张已经跑过、记录入口天然成立但旧版故事偏平的主题卡；
2. 按A—E运行3.0 Prompt 4；
3. 先执行离线回归测试，不立即发布；
4. 只有五路线在发动机、中段、局部结果和结尾功能上真正分化，才进入融合；
5. 首批发布建议分别测试：敬畏或文化、关系或选择、轻悬疑或微恐三种方向；
6. 入口、故事、情绪、参与和平台指标分层记录，不用单一播放量判断工作流。
