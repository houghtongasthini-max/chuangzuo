# 数据反馈记录

> **用途**:保存观众评论、数据表现、平台信号等外部反馈,作为复盘统计环节的输入,用于改进整个创作流程。
>
> **使用原则**:
> 1. 只记录事实:反馈来源、原话/现象、对应作品。归因和改进方向单独成字段,不与事实混写。
> 2. 每条反馈标注初步归因层:**选题层(prompt3)/ 故事层(prompt4)/ 视觉层(prompt5)/ 成图层(生图执行)/ 平台层(审核与流量)**。
> 3. 单条反馈不直接修改提示词——由复盘统计环节汇总多条同向反馈后,再决定是否落实为 prompt 条款,并记录"改了什么、验证结果如何"。
> 4. 状态流转:`待处理 → 已归因 → 已改进(写明改动) → 已验证(写明下一部作品的数据表现)`。

## FB-001 | 2026-07-26 | 7.25下《深海光缆》| 分镜前后联系性不足

- **来源**:观众评论
- **反馈内容**:分镜设计得不够完全,成图后有些地方看不懂图片之间的前后联系。
- **初步归因层**:视觉层(prompt5)为主,成图层为辅
- **初步归因分析**:
  1. 深海题材全片处于暗色调封闭环境,相邻图构图相似、状态变化小(机械臂微操作、电量百分比变化),观众难以识别"这张和上一张相比发生了什么"。
  2. prompt5 的逐张格式有"本张新增视觉信息"和"下一张观看动力",但**没有"与上一张的视觉承接锚点"**——即每张图里应保留一个观众能认出的上一张元素(同一物件、同一位置、动作的起点与终点),用于建立前后连接。
  3. 高潮段"适配环掉落→重新夹起"这类连续微动作被拆到多张图,生图模型无法保证动作连贯,观众看到的是几张相似的黑暗画面。
  4. 引导词(成图提示词.md 中的机制)本该用于兜底难懂的图,可能在这些暗场微操作图上用量不足。
- **候选改进方向**(待复盘环节确认后落实):
  - prompt5 逐张格式增加一项"**与上一张的承接锚点**":写明本张画面中哪个元素直接延续上一张(物件/位置/动作状态),生图提示词中显式描述该元素。
  - prompt5 分镜自检增加一条:相邻两张若场景、色调、景别均相同,必须至少改变一项大尺度可见要素(机位方向/景别跨级/新物体入画)。
  - 暗色调题材增加"可辨识度检查":手机尺寸下相邻图能否一眼区分。
  - 连续微动作(掉落→抓回)压缩为"动作起点 + 动作结果"两张,不拆中间态;中间态交给解说文案。
  - 难懂图强制配引导词,引导词明确指出前后关系(如"它又把接头捡了回来")。
- **改进落实(2026-07-26)**:候选方向已全部条款化写入 `工作流2.0\prompt5.md`(全片道具链/双向自检/微动作起点+结果/暗场高对比光源与可辨识度/引导词预算档位);数据佐证见 FB-003(深海评论率 0.02%、分享率 0.02%,"看得完、说不出"成立)。
- **状态**:已改进,待下一部作品验证

## FB-002 | 2026-07-26 | 7.23《长城》| 观众希望多做同类题材

- **来源**:观众评论
- **反馈内容**:很喜欢长城这种题材,希望多做一点。
- **初步归因层**:选题层(prompt3)——题材需求信号
- **初步归因分析**:
  1. 与账号数据一致:长城是流量最大爆款,深海光缆(同为"替前人完成未竟之事+家国/文明传承"骨架)数据回升,证明"宏大正向+国民符号+传承情绪"是本账号已验证的高表现方向。
  2. **注意风险**:观众要的是"题材/情绪方向"(家国、历史、宏大、传承),不是"结构复制"。长城与深海光缆结构指纹已高度重合(异常→求证→善意反转→倒计时→替前人完成→点亮→文字回执),同一结构第三次使用有套路暴露风险。满足此需求的正确方式是:**保留题材与情绪,轮换结构轴**(反转方向/结尾类型/高潮动作/余味类型至少换两个)。
  3. 决策记录:账号主决定**不将此反馈写死进 prompt3**,而是作为复盘数据输入,由每轮复盘动态判断题材配比。
- **候选改进方向**(待复盘环节确认后落实):
  - 在下一轮选题时,通过 prompt3 的"材料输入区"传入本条反馈(作为账号数据的一部分),提高历史/家国/传承方向在"主力 50%"中的占比。
  - 候选题材池(同情绪、不同符号):大运河、敦煌、故宫文物、京张铁路、丝绸之路驿站、灯塔/航标、老邮路、三线建设遗址、黄河渡口、卫星测控站。
  - 结构轮换要求:下一部同方向作品,结尾不用"文字回执",反转不用"敌意变善意",至少一项高潮动作类型与前两部不同。
- **改进落实(2026-07-26)**:已通过机制落地——工作流2.0 的探索保底(3 个立即开发中≥1 个已验证方向)、复盘统计prompt 的系列豁免标注、prompt4-创作版的结尾类型强制轮换、使用说明的排期对称规则(已验证方向连续 2 部后第 3 部强制新方向)。
- **状态**:已改进,待系列第二部验证
