# Gate A｜市场承诺放行卡 v0.2

## 一、唯一职责

判断：

> 哪个承诺值得继续投入完整故事和视觉测试。

AI负责结构化比较；人工拥有最终冠军权。

Gate A无权补写故事、融合部件、增加人物成长、增加规则或补意义。

## 二、三种结论

- PASS：通过全部硬门，进入冠军故事骨架；
- REVISE：只有1—2个局部问题，可修改标题、封面、前三张、高潮或末图后重审；
- KILL：淘汰或退回M3。

需要修改3个以上核心部件时，直接KILL，不靠扩写修复。

## 三、硬门

任何一项失败，不能PASS。

### H0｜承诺欲望底线

剥离记录外壳、设备、档案、真实性包装和主题意义后，用户是否仍在等待一个具体的：

- 可见画面；
- 动作结果；
- 状态改变；
- 空间后果；
- 或关系结果？

如果只能回答“等更多证据证明它是真的”“等测量或归档完成”“等解释更完整”，不得PASS。H0不能被总分覆盖。

### H1｜平台与安全
- 关键人物明确成年；
- 标题、封面和前三张无高风险直拍；
- 敏感内容有安全表达路径；
- 不依赖未成年人、尸体、血腥、献祭或极端伤害完成吸引。

### H2｜三位一体承诺
标题方向、封面关系和第一行是否指向同一主要问题或结果？

### H3｜封面＋前三张兑现
封面视为第0张。封面＋前三张是否：
- 证明标题不是空话；
- 至少提供一次新的可见回报；
- 给出下一步自然动力？

封面已证明核心异常时，前三张可以建立人物、因果和行动，不要求重复同一奇观。

### H4｜有效中段
中段是否改变用户等待的问题、人物下一步、对象身份或用途、空间尺度、关系、风险或结果预期？

单纯更大、更近、更怪、设备更多或证据更完整不算。

### H5a｜高潮和末图可见
高潮与末图是否手机端可读、可以生成？

### H5b｜高潮和末图值得等待
是否真正改变理解、处境、关系、空间或世界状态，而不只是完成测量、归档、上传或再次确认？

### H6｜社会转述
一句话是否包含发生了什么变化＋最后得到什么结果？结果可以保留未解原因，不要求解释全部来源。

### H7｜最低记录成立
能否用一句话解释谁或什么留下影像，不需复杂取证系统？

### H8｜作品级复制
比较核心异常、人物关系、主要行动链、中段功能、高潮动作、最终结果。多数高度重合时KILL；只共享机制或类型结构不得误杀。

### H9｜内容线一致
是否完成M0指定任务，而非同时承担稳定、增长和实验？

### H10｜制作预算
是否在M0预算内？核心视觉失败时有无简化路径？

## 四、轻量比较

硬门通过后，0／1／2比较：

| 维度 | 判断问题 |
|---|---|
| C1 三秒理解 | 是否立即知道发生了什么、等什么？ |
| C2 点击张力 | 是否有强而具体的不可能关系？ |
| C3 早期证明 | 封面＋前三张是否迅速兑现？ |
| C4 继续动力 | 中段是否产生新等待理由？ |
| C5 结果价值 | 高潮和末图是否值得等待？ |
| C6 视觉可读 | 核心信息是否手机端可生成与识别？ |
| C7 市场与个性 | 是否使用成熟需求又有实质差异？ |
| C8 制作效率 | 同等价值下是否更少人物、规则、设备和难图？ |

## 五、最低放行线

- C1、C2、C4、C5均不得为0；
- C2、C4、C5至少两项为2；
- 总分原则上不低于11／16；
- H0失败时总分无效；
- M0已批准L预算时，C8只用于同等承诺下排序，不能仅因项目较大否决。

## 六、停止规则

一旦一个原型：
- 通过全部硬门；
- 没有致命问题；
- 承诺清楚；
- 预算可接受；
- 相比其他原型无明显结构短板；

即可锁定冠军并停止。

不得继续加入第二规则、第二中段、人物过去、额外牺牲、档案尾钩或主题总结。
