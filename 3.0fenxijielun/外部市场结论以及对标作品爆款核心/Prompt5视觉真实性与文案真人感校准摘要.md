# Prompt 5视觉真实性与文案真人感校准摘要

## 一、真实感的判断顺序

1. 谁在拍、摄影机为何在这里；
2. 人物动作是否符合普通人的身体逻辑；
3. 环境是否有使用痕迹、天气影响和连续后果；
4. 异常是否真实接触地面、物件、光线和人物；
5. 成像是否符合具体设备、距离、光照和运动；
6. 构图和画质是否服务信息，而不是展示摄影能力。

低清、噪点和时间戳不是默认真实感。

## 二、三档视觉语法

### W1｜粗粝亲历

手机、行车记录、同行拍摄。允许轻微偏斜、遮挡、自动曝光波动、对焦迟疑和不完整取景。适合旅行、日常空间、私人关系和近身异常。

### W2｜工作纪录

工作手机、固定监控、无人机、任务相机。画面较稳定，但保留操作痕迹、设备限制和普通现场光。适合职业、探索、历史文化和大型过程。

### W3｜档案复原

旧胶片、旧相机、回收存储、受损视频、多源资料。每种介质拥有稳定且不同的成像特征。适合真伪求证、时间错位和身份重分类。

只选故事需要的最低档，不把更精致等同于更真实。

## 三、受控不完美预算

每组画面允许部分帧自然出现：

- 主体轻微偏离中心；
- 前景遮挡；
- 高光溢出或暗部信息不全；
- 运动造成的轻微模糊；
- 自动对焦短暂落在错误平面；
- 镜头距离不理想；
- 普通人的犹豫、停顿、重心不稳和非表演性动作。

核心异常、高潮和结尾必须清楚，不能用“纪录感”掩盖信息失败。

## 四、人物策略

- 隐藏正脸不是统一硬规则；
- 悬疑与规模型作品可多用背影、侧脸、远景；
- 关系与情绪型作品允许少量自然近景和正脸；
- 人物参考图只保证识别，不把每张人物做成同一姿势、同一神态和同一光线；
- 服装、道具和伤损连续，但褶皱、湿度、污渍和穿着状态随事件变化。

## 五、单张提示词压缩顺序

每张只优先写：

1. 主记录媒介；
2. 主体与动作；
3. 第一眼事实；
4. 异常与环境接触；
5. 必要连续锚点；
6. 现场光与成像结果。

删除重复的“真实、纪实、电影感、高清、专业”等抽象形容词。真实感由可见事实推导。

## 六、文案真人感

每篇先明确：谁在讲、何时讲、他当时知道多少、为什么会讲。

文案应：

- 使用具体动作、物件、时间和误判；
- 允许信息缺口、犹豫和修正；
- 让句长和语气有自然波动；
- 只解释图片无法承担的最小信息；
- 把情绪交给人物行为、物件和结果。

文案应删除：

- “事情要从……说起”；
- “他终于明白／原来这一切”；
- 连续的标准转折句；
- 每段都总结上一段；
- 过度完整的规则说明；
- 结尾人生感悟和作者判词；
- 把下一张的核心画面提前说完。

## 七、图文关系

每张图允许“一个主要新增事实＋若干现实杂讯”，不要求画面只有一个信息。图片应提供文案没有说出的观察，文案不能把图片降为插图。
