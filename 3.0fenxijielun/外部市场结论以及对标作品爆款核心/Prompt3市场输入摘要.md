# Prompt 3市场输入摘要

> 本摘要用于起号期选题研发。它只提供市场事实、当前假设和实验边界，不提供具体爆款剧情，不要求模型模仿任何单篇作品。

## 一、事实级输入

1. 当前账号已验证：可信记录入口可以增强点击与代入，但真实感不能替代故事推进。
2. 已验证的高表现作品具有：熟悉坐标、可见异常、阶段问题变化、清楚结果和一句话转述。
3. 账号存在“评论区进入高、实际留言低”的表达缺口；作品需要赋予观众明确但不机械的参与角色。
4. 文案大部分用户只看折叠线以上，因此标题、封面和首行必须独立完成入口承诺。
5. 平台对血腥、尸骨、殡葬和伤害直拍高度敏感；安全门禁独立于故事价值判断。
6. 当前样本不能证明观众只喜欢微恐，也不能证明温情、家国、浪漫或社会寓言天然有效。

## 二、跨作者稳定需求假设

优先研发同时满足以下条件的主题：

- 一个无需解释即可进入的现实、文化或生活坐标；
- 一个可以画在封面上的“不可能关系”；
- 一个明确的中心等待问题；
- 至少两次性质不同的问题换挡；
- 一个视觉可见、可懂、可转述的最终结果；
- 记录来源世界内部成立；
- 非恐惧题材拥有能够替代威胁的强情绪发动机。

## 三、起号期选题权重

通过安全与记录门槛后，按以下顺序排序：

1. 标题与封面传播效率；
2. 中前段持续观看发动机；
3. 最终回报；
4. 一句话转述；
5. 情绪余味与关注理由；
6. 制作可行性；
7. 与近期作品的结构距离；
8. 纯创新度。

创新度不得压过理解和观看欲望。

## 四、三条选题线

- **稳定线**：成熟悬念、未知、身份重分类、现实陌生化。
- **增长线**：成熟入口＋敬畏、文化、关系、温情、浪漫或命运变轨。
- **实验线**：弱化恐惧，直接测试非恐惧情绪产品。

输出时必须标注主题属于哪条线及其验证假设。

## 五、禁止性偏差

- 不因近期高表现作品而复制其具体场景、角色、道具、数字、结尾句或完整结构；
- 不因创作者个人偏好给某类题材无证据加分；
- 不为追求结构距离排斥成熟需求；
- 不把“题材陌生”误当创新；
- 不把多设备、多档案、多规则误当可信度或故事潜力；
- 不提前把主题写成完整剧本。
