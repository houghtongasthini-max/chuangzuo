# 一、统一标记

- **【你决定】**：需要你填写或选择。
- **【默认】**：已经替你设定；没有特殊情况不要修改。
- **【AI判断】**：由当前工作流模块依据故事和生产条件决定。
- **【结果回填】**：复制上一阶段已经确认的输出。
- **【实际材料】**：需要你提供真实图片、数据或文件，AI不能代填。
- **【临时路由】**：只用于当前返回、T2门控或裁决，不作为长期交接对象。
- **【裁决锁】**：记录已经由你决定过的T2变量，防止后续重复触发或失败方案回流。

# 最少决策总览

## 开始一篇作品时，你只需要回答

3. 最不想出现什么；
4. 有没有必须使用的素材。

## 进入故事阶段时，你只需要回答

1. 选择哪张承诺卡；
2. 最必须保留什么；
3. 最不能改成什么。

## 独立审查阶段

- 你只需要把冠军承诺卡、02最终故事和锁定内容放进新的独立会话；
- `RETURN 01`或`RETURN 02`由03提出，你保留最终否决权；
- `POSSIBLE T2`由你决定是否运行；
- `TRIGGER T2`默认运行，你可以明确拒绝并承担风险。

## T2阶段

你只需要选择：

1. 采用原冠军；
2. 采用挑战者；
3. 两者都不满意。
