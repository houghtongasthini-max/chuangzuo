# 《替死影衣》（中式民俗水库空棺事件）

- **创作日期**：2026-07-25
- **工作流版本**：Workflow v1.0
- **发布状态**：已发布 / 已完成首轮数据复盘
- **本轮实验目标**：探索中式民俗伦理、父子代际选择与物理载体（水库、空棺）的结合。
- **最终结果**：完成包含“遗骨消失、空棺归位”等物理凭证链的剧情与分镜设计。
