# 《替死影衣》（中式民俗水库空棺事件）

- **创作日期**：2026-07-25
- **工作流版本**：Workflow v1.0
- **发布状态**：已完成 / 已发布
- **本轮实验目标**：探索中式民俗伦理、父子代际牺牲与具体物象载体（水库、空棺）。
- **最终结果**：情感表达饱满，建立了明确的物理凭证链（遗骨消失、空棺归位）。
- **主要问题**：规则条目较多，高潮段落视觉元素密集易导致生图混乱（文件 1.md 装载了图19后的后续分镜草稿）。
- **对工作流产生的影响**：提出了“规则必须有实物载体”及“必须有不可撤回具体动作”两条核心原则。
