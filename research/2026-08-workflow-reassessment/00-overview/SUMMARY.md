# 核心结论摘要

## 1. 样本

- `full-archive`未发现；从`main`与70次提交历史恢复59个作品快照，去重后53篇。
- 作者分布：鼠鼠15、Zayn 15、L-Ruins 14、怪诞收容局6、浮光纪事3。
- 53篇均识别正文、封面、连续图片顺序、MP3和互动数据；1篇含4段MP4。

## 2. 市场机制

跨作者最稳定的不是“微恐”，而是：

> 熟悉坐标中的不可能关系＋可信记录入口＋阶段问题变化＋可见、可懂、可转述的结果。

微恐是高效率入口和风险发动机，但高表现样本也大量包含敬畏、亲情、浪漫、温情、历史文化和悲伤。

## 3. 怪诞收容局

- 长城：全漏斗最健康，证明悬疑入口、历史文化、悲壮和局部行动可以共存。
- 零号线：CTR成立，主要死于中段重复探索与完整心理疗愈。
- 替死影衣：平台分发先死，不能据此否定亲情题材。
- 深海光缆：看得进、看得完、说不出；一次操作解决了任务、关系、世界和危机。
- 天气预报：可视规则强，但议题与论证先于市场事件。
- 旧手机：温情装置有潜力，但标题和正文过早说破意义，且数据采集过早。

## 4. 当前核心差距

不是创意不足，而是：

- 太早决定作品要表达什么；
- 太努力把每个故事写完整；
- 文案过度解释因果、规则和意义；
- 每张图被设计得像影视剧照；
- 给观众留下的发现、判断、转述和补充空间太少。

## 5. 最优定位

> 以可信记录进入现实，用低门槛悬念推动不可能事件，在中后段转向敬畏、历史文化、成年关系、温情、责任、浪漫或命运，并交付一个清楚可见、值得转述的结果。

## 6. 起号期比例

前10篇建议：

- 稳定流量线6篇；
- 风格增长线3篇；
- 边界实验线1篇。

微恐主要作为入口、压力或转折，不作为所有作品的最终目的。

保留三系统、最低充分记录、能动性阶梯、完整骨架融合和视觉退回；重点继续减法：

1. 起号市场合同前置；
2. 标准模式由五路线改为三路线，五路线仅用于深研；
3. Prompt 3缩字段，提高标题封面和前半段权重；
4. Prompt 4先做12节拍梗概，再扩写胜出路线；
5. 完整文案从Prompt 4拆出；
6. 融合增加“充分即停止”和“纪录缺口保护”；
7. Prompt 5采用W1/W2/W3分档、短提示词和受控不完美；
8. 发布包装独立测试。
