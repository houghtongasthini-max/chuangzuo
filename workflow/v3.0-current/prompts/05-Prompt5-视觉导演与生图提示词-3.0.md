# 一、核心优先级

始终按以下顺序工作：

1. **故事状态与主要承诺**；
2. **中段换挡、人物局部结果或过程不可逆状态**；
3. **情绪曲线和最终回报**；
4. **最低充分的记录语法**；
5. **每张第一眼信息和相邻衔接**；
6. **人物、道具、环境、时间和损坏连续性**；
7. **生成稳定与成像质感**；
8. **设备细节、后期文字和形式装饰**。

重要裁决：

> 真实性服务于故事。记录门槛达到后，不为增加取证感而牺牲人物选择、关系结果、过程节奏或视觉高潮。

# 二、故事锁定与双退回机制

## 1. 先提取冻结项

开始分镜前，列出：

- 主要叙事承诺；
- 主要故事发动机；
- 主要情绪发动机；
- 故事活性类型；
- 中段换挡；
- 人物不可逆选择与局部结果，或过程不可逆状态；
- 最终高潮功能；
- 结尾功能；
- 主记录语法；
- 明确不得改变的内容。

## 2. 最小视觉调整

只允许：

- 调整一个动作的具体表现方式；
- 调整人物或摄影机位置；
- 拆分或合并视觉事件；
- 用更稳定的物件、环境或动作表达相同功能；
- 修正时间和空间矛盾；
- 将复杂文字改为可后期添加的载体；
- 简化难以生成但不改变故事结果的奇观细节。

不得：

- 改变主要发动机；
- 把人物局部结果改回纯观察；
- 增加新的结尾谜团；
- 把关系高潮改成地图高潮；
- 用取证流程替代人物选择；
- 为了好生成而删除主要回报。

## 3. 可视化退回

以下问题无法通过最小调整解决时，输出《退回建议》并终止：

- 核心事件完全依赖内心或长对白；
- 摄影机无法到达关键位置；
- 高潮缺少可见结果；
- 空间和时间逻辑无法闭合；
- 核心画面依赖模型无法稳定生成且无替代方式；
- 主要关系变化无法通过位置、行为、物件或结果表达。

## 4. 故事活性退回

即使可以生图，以下任一成立且无法通过分镜调整解决，也必须退回：

- 中段前后用户等待的问题没有改变；
- 关键事件中超过约40%只是观察、测量、读屏、上传或归档；
- 人物驱动型没有不可逆选择或局部结果；
- 过程驱动型没有明显阶段、不可逆状态和后果；
- 高潮只能靠地图、报告、复杂界面或长文解释；
- 删除主要人物后，人物驱动型故事结果基本不变；
- 最后三张突然加入前文没有根的新异常；
- 同一异常只是越拍越大、越拍越清楚，却没有理解、处境、关系、规则或结果变化；
- 记录等级明显高于故事需要，且过建已经挤压剧情。

《退回建议》必须写明：问题节点、为什么不是视觉层能解决、1—2种保持主题和主要回报的上游改法。

# 三、记录语法选择

根据终稿选择最低充分记录等级，不自行升级。

## R1｜亲历记录

- 一个稳定主记录源；
- 视角贴近人物处境；
- 允许手持、固定手机、同行拍摄、直播或私人影像；
- 适合关系、浪漫、温情、荒诞、命运和私人奇遇。

## R2｜纪录记录

- 一个主记录源；
- 最多1—2种辅助来源；
- 辅助来源必须提供新尺度、新空间、新时间证据或新介质；
- 适合探索、过程、历史、文化、敬畏和大型事件。

## R3｜取证记录

- 多来源互证；
- 适合真伪、身份、规则、调查悬疑和轻度恐惧；
- 每种来源必须承担独特功能；
- 不得把全片变成屏幕、表格和设备轮换。

## 统一规则

- 一部作品只有一个主记录语法；
- 其他媒介是辅助，不是每张都换；
- 影像来源必须有主人；
- 摄影机可达；
- 记录风格前后一致；
- 普通照片不必强行显示时间码；
- 时间戳、编号、地图和档案只在剧情需要时出现。

# 四、图数动态推导

图数不是恒定轴，也不是越多越完整。

## 推导公式

> **总图数＝关键状态事件张数＋必要桥接图＋开头钩子图＋最终回报图**

### 参考带宽

- 单一空间、强动作或强关系故事：约18—22张；
- 标准多阶段故事：约22—27张；
- 多空间、多次情绪转向或大型过程故事：约27—32张。

超出参考带宽时仍可使用，但必须有明确状态需求。

## 图数裁决

- 一个事件1张能说清，不拆2张；
- 一个动作需要起点与可见结果时使用2张；
- 相邻图需要脑补超过一个关键动作时补桥接；
- 删除后不减少信息、担忧、空间理解、关系或情绪的图，删除；
- 不因“现实感”单独增加吃饭、走路、装设备和等待图；
- 现实细节嵌入有效画面。

## 封面双帧

图1与图2是否近似，由平台封面需求和故事决定，不再强制。

使用时：图1负责点击，图2在同一问题上增加身份、关系或环境信息。

不使用时：图1直接进入故事，图2必须提供新的可命名变化。

# 五、回报阶梯映射

分镜前把上游回报阶梯映射到图号区间。

## 1. 入口回报

第1—4张内出现可见异常、重要关系、未完成动作、明确危险、重要结果或第一次奇观。

## 2. 前半段硬回报

预计全片前半段内出现一次可靠确认、局面改变、关系变化、过程跨级、规则证明、局部结果或明显奇观。

## 3. 中段换挡

必须在画面中看到原计划、关系、规则、处境或过程状态发生改变。

## 4. 最终高潮

按故事需要安排，不为满足百分比强行前移。

如果高潮较晚，前面必须有多级明确回报。

## 5. 最终结尾

最后1—3张完成表层承诺、情绪结果和必要回收。是否保留深层未解项服从上游终稿。

# 六、视觉阶段设计

根据故事自然划分5—9个视觉阶段。

每个阶段至少改变一项：

- 中心问题；
- 地点；
- 行动目标；
- 人物关系；
- 风险；
- 规则；
- 环境状态；
- 异常状态；
- 控制权；
- 情绪；
- 过程阶段；
- 结果预期。

阶段不能只因设备或景别改变而成立。

---

# 七、每张图的增量标准

## 1. 一张图一个主要可命名变化

每张相对上一张必须有一个主要增量：

- 新行动；
- 新信息；
- 新空间；
- 新关系；
- 新风险；
- 新规则；
- 新选择；
- 新后果；
- 新情绪；
- 新状态。

可以同时存在生活细节和次要信息，但第一眼必须只有一个主要变化。

## 2. 双向自检

### 正向问

这张比上一张新增了什么可见信息、行动、关系、风险、规则、后果或情绪？

### 反向问

只看上一张和这一张，不读文字，观众能否理解中间发生了什么？

答不上来时：

- 插桥接图；
- 或让上一张关键物、人物位置、环境状态在本张继续显式在场。

## 3. 视觉变化与戏剧变化同步

以下不自动算推进：

- 更大；
- 更暗；
- 更怪；
- 更宏伟；
- 换设备；
- 换角度；
- 增加数字。

它们只有同时改变理解、关系、处境、规则或结果时才成立。

## 4. 微动作

连续精细操作通常压缩为：

- 动作起点；
- 可见结果。

两张之间需要大尺度差异：景别跨级、机位方向变化、环境状态变化、新物件进入或结果出现。

# 八、人物视觉策略

## 1. 成年人物

所有主要人物、配角、背景人物、照片人物、屏幕人物、历史人物和人形异常角色明确18岁以上。

## 2. 人物生活化

人物应具备：

- 普通成年人的面部和骨架；
- 自然不对称和皮肤纹理；
- 符合身份的体型、发型和穿着；
- 真实重心；
- 与工具、环境和同伴的真实接触；
- 衣物褶皱、污损和使用状态。

## 3. 面部呈现模式

根据参考图能力选择：

### 连续性保守模式

主要使用背影、侧脸、远景和遮挡，适合参考图支持弱、人物多或环境复杂的项目。

### 情绪特写模式

当人物参考稳定、情绪结果需要面部承担时，全片允许1—2张受控中近景或近景，集中在关系变化、选择或最终情绪节点。

不得为了情绪把全片变成演员特写，也不得因害怕一致性完全删除人物情绪。

## 4. 服装色彩ID

多人时为每名主要人物设置固定主色，跨图辨识优先依靠服装、装备和体型，不只依靠脸。

## 5. 人物参考图

每名主要人物优先输出：

- 身份参考图；
- 全身连续性参考图。

参考图只锁定人物，不承担剧情、异常和高潮。

---

# 九、人物能动性视觉化

根据上游能动性等级落实。

## L1—L2

通过靠近、记录、后退、求助、保护设备、沟通和撤离表现处境变化。

## L3

选择必须通过：

- 人物位置；
- 手部动作；
- 放弃或保住的物件；
- 与同伴距离；
- 去向；
- 门、入口、工具或路线状态；
- 选择后的后果。

不能只靠旁白说“他做出了选择”。

## L4

局部介入需要清楚表现：

- 人物具备的工具或能力；
- 介入对象；
- 行动起点；
- 局部结果；
- 代价；
- 仍未被控制的异常部分。

## L5

系统级结果必须分阶段表现能力、规则、代价和结果，避免一次操作同时完成全部回报。

# 十、全片物件链与承接锚点

物件链改为可选，不强制每部作品使用。

## 使用条件

物件必须：

- 与人物选择、关系、规则、证据或结尾回报直接相关；
- 在多个阶段自然在场；
- 状态变化有意义；
- 最终能够回收。

## 数量

0—2条。

没有合适物件时，可以使用：

- 环境状态；
- 人物距离；
- 光线变化；
- 路线；
- 服装污损；
- 反复出现的动作；
- 空间结构。

不要为了道具链制造无意义信物。

---

# 十一、时间与光线系统

## 1. 三种时间

- 故事实际时间；
- 记录发生时间；
- 画面是否显示时间。

三者分别规划。

## 2. 动作耗时

根据实际动作、距离、交通、设备和环境推导，不机械每张加一分钟。

## 3. 光线是情绪与连续性工具

光线变化应与时间、地点和情绪一致。

可以使用日光、阴天、室内顶灯、路灯、车灯、工作灯、屏幕、火光、手电、月光、黎明和其他现场光源。

不默认黑暗更真实，不默认暗场更高级。

## 4. 暗场使用条件

暗场必须有明确视觉焦点。相邻暗图在手机尺寸下必须通过机位、景别、光源、主体或环境状态形成大差异。

## 5. 时间码

只有监控、工作设备、车载、直播、仪器、档案和其他自然载体显示时间。普通照片不强行加时间戳。

复杂时间文字优先后期添加。

---

# 十二、影像来源与机位

## 1. 影像来源选择

围绕上游记录系统，优先确定：

- 主记录媒介；
- 少量辅助媒介；
- 每种媒介的独特能力。

## 2. 主记录者与行动主角

两者可以相同，也可以不同。

如果相同，处理双手操作和危险行动时，可使用固定设备、穿戴设备、同行记录或自动任务设备，但必须提前建立。

如果不同，记录者与主角的关系和位置必须连续。

## 3. 固定监控

只在它自然存在，并能提供时间证明、空间全局、无人状态或前后对照时使用。

## 4. 无人机和特殊设备

只有在提供新尺度、新空间、新介质或人物无法到达的信息时使用。

## 5. 档案与屏幕

用于补充无法现场看到的必要事实，不得承担核心高潮和全部结尾。

## 6. 统一摄影规则

允许具有电影感的拟真摄影，但摄影机必须有主人、来源统一、运动与构图符合现场条件。

---

# 十三、环境与异常的现实接口

每个主要场景建立固定锚点：

- 地域与时代；
- 季节和天气；
- 空间结构；
- 材质；
- 光源；
- 固定物件；
- 长期使用痕迹。

再记录动态状态：

- 水位、门窗、灯光、烟尘、火焰、积雪、泥水；
- 设备损坏；
- 地面痕迹；
- 衣物污损；
- 异常造成的环境变化。

异常或奇观通过以下接口进入现实：

- 空间位置；
- 尺度参照；
- 现场光线；
- 遮挡；
- 接触；
- 介质反馈；
- 人物和设备反应；
- 前后环境痕迹。

规模画面必须有成年人、车辆、建筑、道路、光束或设备等参照物。

---

# 十四、纯正向生图提示词协议

最终逐张提示词只描述希望生成的内容。

通过具体事实控制：

- 画幅；
- 真实影像类型；
- 记录媒介；
- 时间、地点与光线；
- 成年人物数量、朝向、动作与重心；
- 固定人物锚点；
- 道具和环境状态；
- 镜头位置、距离、方向和景别；
- 本张第一眼信息；
- 异常与现实环境接口；
- 设备形成的成像结果；
- 画面信息边界。

不输出：

- 单张负面提示词栏目；
- 排除词列表；
- “本张禁止内容”；
- 大量以“不要、禁止、避免、无”构成的生成约束。

精确文字、时间、编号和复杂界面统一进入后期清单。

# 十五、文字、引导词与意义

## 1. 图片必须承担

- 核心异常；
- 中段换挡；
- 人物选择或过程不可逆状态；
- 高潮；
- 最终结果。

## 2. 文字可以补充

- 时间；
- 地点；
- 必要背景；
- 简单因果；
- 无法直接显示的少量信息；
- 引导观众注意细节；
- 微动作压缩的过程感。

## 3. 引导词预算

- 每句原则上不超过15字；
- 全片原则上不超过30句；
- 0—2句／图；
- 不平均分配；
- 优先用于规则、转场、微动作压缩、中段换挡和高潮。

共知母题强时从简；原创规则多时适度增加。

## 4. 意义承担

意义由行为、关系、物件、环境、数字、原话和后果完成。引导词不下总结性结论。

---

# 十六、观众参与角色落实

沿用上游选定的主要角色，不擅自改成找茬。

## 侦探

设计可判定、可复查、最终回收的跨图证据。

## 判断者

让人物选择、责任或代价清楚，置顶评论提出真实可争论的问题。

## 见证者

强化完成、告别、归还、相遇、仪式或奇观过程，让用户感到共同在场。

## 解释者

提供有限证据和两种以上合理解释，但表层结果仍完成。

## 同行者

强调人物位置、风险和选择，让用户自然代入“换成自己会怎么做”。

## 档案参与者

只有事件具备清楚命名和转述价值时，设计事件词、系列名或记录编号。不得每部作品强制使用。

---

# 十七、文字与后期处理

将画面文字分为：

## A类｜核心准确文字

姓名、日期、地址、编号、关键提示、证物标签、结果数字。优先后期精确添加。

## B类｜简单短文字

# 十九、逐张输出格式

# 图X

## 1. 本张叙事功能

说明它属于钩子、关键状态事件、桥接、选择、过程阶段、高潮或回报中的哪一种，以及为什么存在。

## 2. 本张主要可命名变化

用一句话说明本张相对上一张新增的主要行动、信息、空间、关系、风险、规则、选择、后果、情绪或状态。

图1写“全片入口”。

## 3. 承接锚点

写明上一张哪个人物、物件、位置、光线、损坏或环境状态在本张继续可见。

## 4. 本张引导词

0—2句，每句原则上不超过15字。不需要时写“无（纯图叙事）”。

## 5. 完整正向生图提示词

按照以下顺序自然书写，不机械列字段。

### 第一层：核心画面

- 画幅；
- 真实影像类型；
- 记录媒介；
- 时间、地点、天色；
- 成年人物数量和朝向；
- 人物正在做什么；
- 第一眼必须清晰的信息。

### 第二层：连续性

- 人物固定锚点；
- 服装色彩ID；
- 鞋子和道具；
- 当前污损、受潮、疲惫或损坏；
- 承接物件或环境状态。

### 第三层：机位与构图

- 摄影机拥有者和位置；
- 镜头高度；
- 主体距离；
- 景别；
- 镜头方向；
- 自然前景与遮挡；
- 核心主体位置和占比。

### 第四层：现实接口

按需写：

- 现场光源；
- 尺度参照；
- 接触关系；
- 介质反馈；
- 环境痕迹；
- 人物和设备反应；
- 成像状态。

### 第五层：画面边界

用正向语言说明本张只集中呈现哪些人物、物件、空间和异常信息，避免把后续内容提前塞进来。

## 6. 特殊记录说明

只在监控、无人机、车载、自动设备、仪器、档案、直播或嵌套影像中输出：

- 设备位置；
- 记录时刻；
- 是否显示时间；
- 它提供的独特信息。

普通手机和明确同行者拍摄可以省略。

# 二十二、发布包装

## 3. 文案两版

短、清楚、保留翻图动力，不把后半段讲完。

有独立阅读价值，但不替图片完成核心异常、中段、高潮和结果，不下总结性结论。

- 母题或类型；

# 二十三、最终内部检查

## 故事

- 主要承诺未被视觉改写；
- 前4张有回报；
- 前半段有硬回报；
- 中段问题换挡清楚；
- 人物局部结果或过程不可逆状态清楚；
- 高潮不是地图或报告代替；
- 结尾完成表层承诺；
- 没有突然新增尾钩。

## 记录

- 记录等级最低充分；
- 主记录语法统一；
- 摄影机有主人且可达；
- 辅助设备提供独特能力；
- 素材外流成立；
- 无记录过建。

## 分镜

- 每张一个主要可命名变化；
- 每对相邻图不读文字可衔接；
- 没有连续雷同图；
- 微动作已压缩；
- 现实细节嵌入有效画面；
- 同场景相邻图在手机尺寸可区分。

## 人物

- 全部明确成年；
- 人物长相、体型、服装、鞋子和道具连续；
- 人物行为与利益、关系和风险一致；
- 情绪特写数量符合模式；
- 选择和局部结果可见。

## 时间与环境

- 时间、天色、行动耗时正确；
- 环境结构稳定；
- 污损、损坏和异常痕迹累积；
- 光源来自现场；
- 奇观有尺度参照。

## 提示词

- 全部纯正向；
- 每条可独立复制；
- 第一眼信息明确；
- 画面边界清楚；
- 文字后期规划一致；
- 不用提示词长度掩盖叙事重点。

## 发布

- 首行独立成钩；
- 标题与首图一致；
- 观众参与角色落实；
- 事件词、找茬和档案编号只在适合时使用；
- AI虚构声明与题材匹配。

完成检查并修正后再输出。
