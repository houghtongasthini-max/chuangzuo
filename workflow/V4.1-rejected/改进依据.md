# V4.1 Candidate 改进依据

## 1. 直接问题来源

本次升级针对三组生产事实：

### 8.1案例

- 引导词机械，像逐图事实说明；
- 完整文案与逐图引导词来自两套写法，容易时间、动作和信息释放不一致；
- 平行房间故事的中段多次依赖同一墙面、同一显影机制和相近夜景；
- 审查识别到重复风险，却将其主要交给04镜头变化处理；
- 结果是故事级重复可能被误判为分镜级问题。

### 8.2案例

- 选题数量多，但机制和情绪收敛到空间异常、系统抹除、时间因果、影子分身、物件自主、公共规则等少数族群；
- 部分成熟作品学习没有稳定提供创作者可见的作品名和来源索引；
- 生产风险、入口宽度、市场理解和创意发散集中在同一模块，容易过早收敛；
- 创意、情绪调动、悬念、转折、结尾与视觉冲击的上限不足。

### V3.0失败经验

- 前期能够产生大胆创意；
- 但故事、视觉、记录方式和当前图像模型无法继续接住；
- 为了保住题材，后期不断增加解释、桥接图和复杂规则；
- 最终无法稳定生产，或成品远低于创意上限。

## 2. 根因判断

不是“发散不够”或“制作限制太严”中的单一问题，而是缺少以下结构：

1. 创意核心与当前实现没有分离；
2. 第一次故事失败容易被误判成主题失败；
3. 第一次视觉失败容易被误判成题材不适合；
4. 审查只有致命错误和通过备注，中间缺少`UNDERPOWERED／REBUILD`；
5. 关键图测试主要验证能否生成，没有发放正式生产资格的清晰门槛；
6. 没有暂停高潜资产的状态，只能硬做或淘汰；
7. 01职责过载，市场与制作顾虑过早介入；
8. 05把引导词当附属注释，而不是和画面共同组成的叙事轨。

## 3. 设计选择

### 保留

- 00全局权限和最高裁决；
- 一次运行一个模块；
- 02、03、T2角色隔离；
- T2单变量挑战；
- 关键视觉实际测试；
- 最低充分记录；
- 不强制反转、成长、牺牲、档案尾钩；
- 事实与证据纪律；
- 主要承诺完成后停止增加结构。

### 新增

- 创意核心锁；
- 当前实现假设；
- R1整体重构通道；
- 分层失败分类；
- 生产资格卡；
- 暂停高潜创意库；
- 三轴风险设置；
- 统一图文叙事对齐表；
- Prompt改动状态机；
- 候选版和回滚机制。

### 明确不做

- 不把“每个好创意都必须立刻做完”写成规则；
- 不因保护创意而允许无限返工；
- 不强制每篇有大反转或大奇观；
- 不让R1成为多路线无限发散器；
- 不让05用文字补未生产的核心场面；
- 不以镜头变化掩盖故事状态没有变化；
- 不把成熟作品名称隐藏在抽象资产卡后面。

## 4. 成功标准

V4.1成功不是“文件更多”，而是：

- 好创意不会因一次失败实现被错误处死；
- 差故事能被返回R1整体重构，而不是局部补丁；
- 差视觉能更换等价表达，而不是降低创意承诺；
- 当前能力确实不够时可以暂停，并保留完整失败知识；
- 只有通过关键测试图的版本才进入批量生产；
- 引导词、完整文案和最终图片处于同一时间线和信息释放结构；
- 创意上限、生产稳定和返工边界同时存在。
