# CHANGELOG

## V4.1 Candidate｜2026-08-02

### 核心升级

- 将“创意价值、故事实现、视觉实现、生产资格”拆为四个判断层；
- 新增《创意核心锁》，使好创意不会因第一版剧情或视觉失败被错误淘汰；
- 新增R1高潜创意保全与生产转化模块；
- 新增`PAUSE ASSET`状态，保存当前能力无法实现但仍有价值的创意；
- 生产资格必须建立在2—4张实际关键测试图上。

### 结构变化

- 原01拆分为01A创意扩张和01B压力测试；
- 02升级为冠军故事实现，新增观看问题曲线、回报阶梯、情绪压力曲线、视觉状态曲线和结尾压力测试；
- 03升级为分层审查、R1路由和生产资格门控；
- 04只执行已获得生产资格的资产；
- 05移除发布后复盘，改为统一图文叙事对齐；
- B2新增创作者可见来源索引和暂停高潜创意库；
- B3新增问题分类、Prompt改动状态机和回归记录。

### 风险设置变化

原单一“市场姿态”拆为：

- 市场不确定性容忍度；
- 创意突破强度；
- 生产复杂度预算。

允许在低生产复杂度预算下追求高创意突破。

### 来源规则变化

使用电影、小说、短片、动画、神话、新闻或其他成熟资产时，必须向创作者显示：

- 作品／事件名称；
- 作者、导演或创作者；
- 媒介和年份，能确认时填写；
- 借用的叙事功能；
- 明确未复制的内容；
- 可核查来源或“待核查”。

### 引导词变化

- 不再限制字数；
- 不要求每张都必须有一句；
- 有引导词时必须承担观察、推进、提问、延迟、判断变化、转折、情绪爆发、回报、停顿或保留未知中的至少一种功能；
- 逐图引导词和完整文案必须由同一图文对齐表生成；
- 禁止用文案补图片和故事中不存在的事实。

### 兼容与回滚

- V4.0冻结保留；
- V4.1 Candidate不原位覆盖；
- 候选期不删除旧文件；
- 晋升和归档在回归测试通过后执行。
