## 共现能力，不是复制模板

1. **生活或任务入口清楚**：寻找、调查、测量、翻译、引路、郊游都能在一两句内理解。
2. **世界陌生度晚于入口展开**：陌生并非靠开头堆设定，而是由后续事实逐级改变对象类别。
3. **事件拥有主角之外的状态**：空间、区域、语言、海洋或制度在人物进入前已经存在。
4. **人物推动接触，不垄断因果**：人物能选择路线、保存记录或完成局部动作，但不必关闭整个世界。
5. **事件结果与本体解释分开**：可以确认“发生了什么／人物做了什么”，同时保留“它究竟是什么”。

## 不能从该矩阵推出的结论

- 不能推出“科考、失踪导师、禁区、遗迹天然有流量”；
- 不能把所有新作品改成探索型；
- 不能把开放本体误解成没有结尾；
- 不能把任一作品的场景顺序、人物组合、标志物和转折链直接迁移。

## 当前最可信的内部结论

### 1. 世界增长比“功能齐全”更能保持后半程活性

《长城烽火》的有效部分不是仅仅宏大，而是观众对冷火、军队和烽火用途的理解持续改变。人物只完成局部关键动作，世界没有缩成主角的心理问题。

### 2. 高完成度不自动带来评论与转述

《深海光缆》具有明确过程和结果，但同时支付事件、人物、情绪和解释后，可供观众继续讨论的余量较少。该判断仍是机制假设，不等于单因果证明。

### 3. 主题明确不等于市场优势

《零号线》《返厂旧手机》和V4.1候选显示：当异常主要用于证明心理、家庭或社会命题时，故事可能更工整，却不一定更有观看欲望。

### 4. 必须把平台失败与故事失败分离

《替死影衣》的推荐异常不能直接写成叙事机制失败。B3必须同时保留平台、审核、包装、样本窗口和故事解释。

## 待补证据

- 每篇作品的完整发布窗口、首图、标题、发布时间与流量来源；
- 逐图状态链和实际成图失败记录；
- 同一作品不同包装的对照；
- V4.2独立模型运行结果。

## 关键因果链

```text
为解决“故事不完整”
→ 增加人物利益、中段换挡、不可逆选择和结尾支付
→ 评分偏爱关系与价值冲突最完整的候选
→ 异常被改造成社会命题的证明工具
→ 作品更工整但世界更小、结尾更可预测
```

V4.2的修复不是删除人物和情绪，而是重新安排顺序：

```text
具体事件
→ 世界事实增长
→ 解释模型变化
→ 人物局部行动
→ 选择必要功能
→ 支付主要结果
→ 最后诊断主题
```
