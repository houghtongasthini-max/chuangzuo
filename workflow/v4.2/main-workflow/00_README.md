# AI拟真连续图片故事工作流 V4.2 Candidate

> 状态：候选试运行。V4.1完整冻结保留；V4.2只有在来源比例、反寓言、全链路退化、低预算高陌生和关键图测试均通过后，才可晋升。

V4.2不是把V4.1推翻重做。它保留V4.1正确的分层架构、创意核心锁、独立审查、R1修复、关键图测试和暂停资产机制，重新校准了上游价值模型：

> 先发现真正值得观看的具体事件，再按事件本性选择性调用人物、情绪、关系、主题和解释功能。

它解决的主要问题不是“故事不完整”，而是：

- 选题阶段过早把事件压成缩略剧本；
- 中段被默认理解为人物选择、关系变化或社会议题升级；
- 人物行动性被放大成对整个异常系统的因果主权；
- 结尾同时支付事件、人物、情绪和本体解释，导致世界余量消失；
- 生产预算在创意上游提前把高陌生核心改造成普通现实流程；
- 对标作品被直接塞入主体Prompt，导致持续模仿和同质化；
- 反寓言只靠“不要做什么”约束，AI仍不知道应该怎样正确发展事件。

## 1｜核心转向

V4.2的默认顺序：

```text
具体事件
→ 第一观看问题
→ 世界事实递增
→ 解释模型换挡
→ 人物进入与局部行动
→ 功能预算
→ 主要结果支付
→ 主题后置诊断
→ 视觉与生产转化
```

不再默认使用：

```text
抽象主题
→ 人物局部利益
→ 社会或关系冲突
→ 不可逆选择
→ 多层回报闭合
→ 拟真记录包装
```

## 3｜两套独立研究系统

### 3.1 参考样本研究系统

位置：`../independent-research/`

用途：

- 保存完整样本卡和来源；
- 研究第一问题、剧情运动、世界事实、人物因果主权和回报结构；
- 按本轮需要生成3—6个临时参考源包；
- 支持F1—F4不同改编深度。

主体工作流不会默认加载样本库。只有以下情况调用：

- 创作者选择参考主导或近源改编；
- 创作者指定作品；
- 本轮需要研究某种结构能力；
- AI原创连续退化；
- B2缺少足够来源。

### 3.2 工作流失败史系统

位置：`research/workflow-failure-history/`

用途：

- 记录V1—V4.1每次改进的原问题；
- 记录正向修复和随后产生的过度纠正；
- 为新规则设计监测信号与回滚方式；
- 防止下一版本重新走同一条失败路径。

失败史供工作流设计和回归测试使用，不直接作为创作Prompt。

## 4｜四种来源模式

默认候选数为12，可在10—12之间调整。

| 模式 | 单一参考衍生 | 多源融合 | 现实材料 | 纯原创 |
|---|---:|---:|---:|---:|
| 原创主导 | 2 | 2 | 2 | 6 |
| 平衡 | 4 | 3 | 2 | 3 |
| 参考主导 | 7 | 3 | 0 | 2 |
| 近源改编 | 8 | 2 | 0 | 0 |

改编层级：

- **F1 功能借鉴**：只借观看欲望、信息释放、中段或高潮功能；
- **F2 核心前提借鉴**：保留一个高价值不可能关系，但改变人物、因果、结果和高身份元素；
- **F3 结构骨架借鉴**：保留剧情运动方式，重新建立题材、对象、场景和具体转折；
- **F4 近源变体**：有意识保留更多源作品身份，必须确认权利和发布边界。

来源模式是创作者控制项。系统不得用固定原创配额抵消创作者选择。

## 5｜八条全局创作合同

1. **事件先于主题**：先建立对象、变化、问题和结果可能，主题最后诊断。
2. **事件拥有主权**：异常在主角到来前有状态，对主角之外有历史、范围或后果。
3. **世界事实递增**：中段优先增加类别、尺度、空间、历史、介质或因果方向。
4. **解释模型换挡**：中段让观众原有解释失效或扩大，而非只增加证据。
5. **人物局部行动**：人物能进入、求证、接触、保存、打开或选择路径，但不必控制全部世界。
6. **选择性支付**：必须支付一个主要回报，可增加一个辅助回报；不默认四层全付。
7. **生产后置转化**：先确认核心价值，再缩小实现；不能缩小类型承诺和世界陌生度。
8. **参考样本隔离**：主体Prompt保留能力，不长期携带具体作品情节。

## 6｜五类正式交接对象

1. `《01A创意空间与来源索引》`
2. `《冠军承诺资产卡2.0》`
3. `《冠军故事与故事锁定卡3.0》`
4. `《独立审查裁决卡／生产资格卡》`
5. `《最终视觉生产包与发布包》`

从01B开始，每个冠军必须区分：

- **承重核心**：不可能关系、第一问题、解释模型变化方向、主要回报、核心视觉关系、来源保留项、必须保留的未知；
- **当前实现**：人物、地点、职业、行动链、记录来源、视觉调度和具体结尾画面。

下游可以重构当前实现，不能擅自改写承重核心。

## 8｜候选版晋级条件

V4.2 Candidate只有在以下条件全部满足后才可晋级：

- 四种来源模式的数量服从测试通过；
- F1—F3保留度测试通过；
- 至少三次完整链路未出现普通化退化；
- 至少一次低预算高陌生案例获得生产资格或被诚实暂停；
- 12个候选中抽象议题主导不超过2个；
- 6张高潜卡中抽象议题主导不超过1个；
- 人物小于事件的过程型、探索型作品不会被03误判；
- 默认回报支付层数不超过2层；
- 实际关键图通过；
- 与V4.1盲测时，创作者对候选池和冠军故事有明确偏好；
- 创作者最终批准。

结构校验通过不等于创作质量测试通过。没有真实运行记录时不得宣布晋级。
