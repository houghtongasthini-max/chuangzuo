# M6｜关键视觉原型与Gate C视觉生产门

本模块在完整分镜之前运行。

目标不是一次性规划全片，而是先证明：

> 封面、主体、核心异常、中段、高潮、末图和连续性，真的能用当前图像模型自然、清楚、稳定地生成。

本文件包含两种模式：

1. **视觉原型设计模式**：输出测试图方案和短提示词；
2. **Gate C审查模式**：接收实际测试图，判断PASS／REVISE／RETURN／KILL。

---

# 一、输入

- Gate B故事锁定合同；
- Gate A锁定卡；
- 图像模型、参考图与制作限制；
- 可用人物参考能力；
- 可选的现有成图或视觉风格样本；
- 平台安全与后期文字能力。

M6无权改变：

- 主要承诺；
- 故事主形态；
- 中段功能；
- 高潮功能；
- 末图结果；
- 核心人物关系；
- M0唯一实验假设。

无法视觉化时必须退回，不得用更长文案掩盖。

# 二、先选择最低充分视觉语法

## W1｜粗粝亲历

适用：私人奇遇、关系、通勤、旅行、日常异常、低成本短篇。

特征：

- 手机、普通相机、同行拍摄、直播截帧；
- 允许轻微偏斜、遮挡、曝光不均、运动拖影和不完整信息；
- 人物距离近，但不追求演员式表演；
- 真实感主要来自现场关系与动作。

## W2｜工作纪录

适用：工程、巡查、科研、工厂、救援、过程与大型现实事件。

特征：

- 一个主记录源；
- 必要时加入1种提供新能力的辅助源；
- 设备界面只在真正改变判断时出现；
- 工作服、工具和环境有使用痕迹；
- 画面不是单位宣传照。

## W3｜档案复原

适用：历史材料、旧设备、遗留照片、多来源复原、非连续亲历事件。

特征：

- 明确每组材料来自谁、何时、为何保存；
- 不把所有画面统一成同一种滤镜；
- 允许缺帧、不同成像、残损和时间差；
- 档案差异必须帮助理解，不是形式装饰。

可混合，但只能有一个主语法。辅助语法必须提供新尺度、时间或空间能力。

---

# 三、测试图数量

- S1：5—6张；
- S2：6—8张；
- S3：8—10张。

最低覆盖：

1. 封面；
2. 前三张中的一张新回报；
3. 主人物或主要主体测试；
4. 核心异常与现实环境接触；
5. 中段核心变化；
6. 高潮；
7. 末图；
8. 连续三张组合，S2／S3必须。

同一张可以承担两个测试目的，但不能因此变得信息过载。

---

# 四、视觉真实性原则

## 1. 真实感来自画面事实

优先证明：

- 人物为什么在这里；
- 手、脚、工具和环境如何接触；
- 异常如何改变真实物体、光线、地面、水、空气或空间；
- 摄影机在哪；
- 画面为什么恰好只能看到这些。

不依赖：

- 时间戳；
- 监控边框；
- 低清滤镜；
- 专业摄影术语；
- 大量设备；
- 过度做旧。

## 2. 受控不完美

可以使用：

- 主体略偏中心；
- 前景遮挡；
- 边缘裁切；
- 轻微曝光不均；
- 人物没有看镜头；
- 环境杂物；
- 不完整信息；
- 普通光源。

不能故意制造：

- 看不清核心事实；
- 严重糊片；
- 错误手指和肢体；
- 无逻辑机位；
- 随机噪点掩盖问题。

## 3. 人物策略按项目选择

### P1｜身份优先

参考能力弱或人物多。以背影、侧脸、中远景、服装和动作识别人物。

### P2｜情绪优先

参考稳定且关系结果需要面部。允许少量受控中近景，不强制全片回避正脸。

### P3｜主体弱人物

事件、空间或过程是主角。人物只提供尺度、操作和后果，不建立复杂面部表演。

不把背影、侧脸、正脸任何一种写成恒定账号风格。

# 五、视觉原型提示词协议

每张测试图只写7项：

1. 画幅与设备来源；
2. 当前主体；
3. 可见动作或状态；
4. 环境与现实尺度；
5. 核心异常的接触关系；
6. 光源与自然成像；
7. 必要连续性锚点。

使用纯正向表达。复杂文字只写“留出后期文字区域”或描述载体，不要求模型生成准确长文。

每张提示词建议120—260字。S3复杂图可以更长，但不得把整部故事塞进单张提示。

# 七、Gate C审查模式

## 1. 决策

- **PASS／LOCK**：进入M7；
- **REVISE**：只返修1—3张测试图；
- **RETURN M4**：故事动作、空间或高潮本身不可画；
- **RETURN M3**：标题、封面或结果承诺无法形成强图；
- **KILL**：平台、模型能力或成本风险不可接受。

## 2. Gate C硬门

- C0：封面在手机尺寸能一眼读懂；
- C1：人物／主体自然，不像资料照或海报；
- C2：核心异常与环境发生真实接触；
- C3：中段图改变等待，不是换角度；
- C4：高潮图不依赖长文；
- C5：末图形成结果；
- C6：连续三张人物、空间、物件和状态可追踪；
- C7：摄影机位置和成像合理；
- C8：复杂文字可后期处理；
- C9：两轮以内存在稳定生成路径；
- C10：完整制作预计在M0预算内。

## 3. 视觉自然度检查

逐项判断：

- 人物重心；
- 手与物件接触；
- 服装和环境使用痕迹；
- 光源；
- 构图偶然性；
- 遮挡与边缘；
- 材质；
- 异常对现实的影响；
- 是否每张都像影视剧照；
- 是否依赖滤镜假装真实。

# 八、两轮规则

同一关键图最多进行两轮结构性测试。

第二轮仍失败时：

- 若画面换一种表现方式即可：RETURN M4；
- 若承诺核心图本身不可行：RETURN M3；
- 不得进入M7后用更多桥接和文案掩盖。
