# AI拟真连续图片故事工作流 V4.1 Candidate

> 当前状态：候选版。V4.0继续冻结保留；V4.1通过回归测试与创作者确认后，才可晋升为正式版本。

这套工作流面向“AI拟真连续图片＋旁白／字幕／环境声音”的故事生产。它不追求让所有创意都变得容易，而是建立一条可追踪的转化路径：

> 发现高潜创意 → 锁定创意核心 → 把剧情与视觉视为可替换实现 → 独立定位失败层级 → 纠正或重构 → 关键图验证 → 获得生产资格 → 完整生产。

V4.1解决的核心矛盾是：

- V3.0敢于发散，但好创意经常因为故事、视觉和当前模型能力接不住而生产失败；
- V4.0提高了稳定性，但前期容易因为生产顾虑提前选择保守题材；
- V4.1不再把“创意价值”“当前剧情质量”“当前视觉质量”“当前生产资格”混为一个判断。

# 0｜第一次使用前必须理解的七条规则

## 规则1｜`00`伴随所有生产模块

每次运行01A、01B、02、03、R1、04、05或T1—T3，都加载：

```text
core/00-全局原则、权限与创意保全.md
```

`00`负责最高裁决、创意核心锁、证据纪律、返回关系和停止条件，不直接创作单篇作品。

## 规则2｜一次只运行一个阶段

每次只加载：

```text
00
＋ 当前模块
＋ 上一阶段正式交接对象
＋ 与本问题直接相关的少量背景
```

不要一次要求AI从选题做到发布，不要默认加载全部历史、全部研究和全部失败稿。

## 规则3｜创意核心和当前实现必须分开保存

从01B开始，每个冠军候选都必须分成：

- **创意核心锁**：不可能关系、主要观看问题、结果类别、核心视觉承诺、情绪／关系潜力和禁止偷换；
- **当前实现假设**：人物、空间、行动链、中段、记录方式、高潮路径、图片规模等可替换设计。

下游发现故事或视觉失败时，只否定当前实现，除非03明确判定`CORE FAILURE`。

## 规则4｜02、03、R1、T2尽量隔离会话

推荐最低配置：

```text
会话A｜01A、01B、02：主创AI
会话B｜03：独立审查AI
会话C｜R1：纠正与生产转化AI
会话D｜T2：单变量挑战者AI，仅触发时建立
会话E｜04：生产AI
会话F｜05：图文对齐与发布包装AI
```

底层模型可以相同，但03不得读取02的思考过程；R1读取正式诊断，不读取无关发散；T2只读取单变量门控结果。

## 规则5｜没有实际测试图，不得授予生产资格

- 文字方案通过，不等于可生产；
- 03模式A只能输出测试方案和待验证状态；
- 只有03模式B收到实际关键测试图并通过后，才能输出《生产资格卡》；
- 04不得在没有生产资格的情况下批量生成完整作品。

默认测试2—4张：入口、中段换挡、高潮／结果；必要时增加连续性压力图。

## 规则6｜纠正优先，暂停次之，淘汰最后

- 故事写差 → R1模式A；
- 视觉翻译差 → R1模式B；
- 故事与视觉互相拖累 → R1模式C；
- 当前模型或资源仍无法实现 → `PAUSE ASSET`；
- 只有核心本身不成立时才`RETURN 01`；
- `RETIRE CORE`必须由创作者确认。

## 规则7｜精简的是重复，不是必要判断

V4.1不强制每篇都出现：职业主角、微恐、中段反转、人物成长、不可逆牺牲、群体接管、档案尾钩、精确时间戳或28张图片。

但也不得因为追求“简单”而删除：观看问题、状态变化、情绪推进、结果支付、视觉换挡和生产验证。

# 3｜三类风险必须分开设置

V4.1不再用一个“稳妥／平衡／探索”同时控制一切。

每篇分别填写：

1. **市场不确定性容忍度**：低／中／高；
2. **创意突破强度**：低／中／高；
3. **生产复杂度预算**：低／中／高。

因此允许：

```text
市场不确定性：中
创意突破强度：高
生产复杂度预算：低
```

这意味着可以追求大胆关系和强情绪，但要求通过更聪明的故事载体和视觉调度完成，而不是自动增加群像、机械动作或复杂世界规则。

# 5｜各阶段最小操作说明

## 01A

目标：扩大真正不同的创意空间，建立可核查来源索引，不用生产难度过早扼杀高潜创意。

交给01B：创意场短名单、机制族群、来源索引、初步风险，不交完整故事。

## 01B

目标：把创意核心价值与当前实现成熟度分开判断，形成3—5张《冠军创意资产卡》。

创作者只需选择一个冠军，并写明必须保留、明确拒绝和风险设置。

## 02

目标：第一次把冠军创意资产发展为单一完整故事。必须设计观看问题曲线、回报阶梯、情绪压力曲线、视觉状态曲线和结尾功能。

02是第一次实现，不拥有“这个创意不行”的最终裁决权。

## 03

目标：独立判断问题属于核心、故事、视觉、局部难图还是当前能力。只有通过实际测试图，才能发放生产资格。

## R1

目标：保留创意核心，整体重构失败的故事和／或视觉实现。R1不是润色器，允许废弃旧实现。

## 04

目标：执行已经获得生产资格的故事与视觉方案。不得用桥接图或提示词偷偷修复上游结构。

## 05

目标：基于最终图片建立统一图文对齐表，写逐图引导词、完整发布文案和包装。引导词不设字数上限，但每句必须承担明确叙事功能。

## B3

目标：记录真实生产和发布事实、竞争解释、问题分类和工作流改动状态。发布后复盘不再由05承担。

# 6｜晋升与回滚

V4.1 Candidate满足以下条件后，才可晋升：

- 唯一输入模板；
- 所有默认值只在00定义，其他文件引用而不另设冲突默认；
- 8.1故事案例能把重复问题返回正确层级；
- 8.1文案案例能保证图文同一时间线且引导词不机械；
- 8.2选题案例能提供明确作品名和更高机制差异；
- 至少一个V3.0高潜失败案例经R1得到新的可测实现，或被诚实暂停；
- 不出现为了“救创意”无限返工；
- 创作者批准。

若试运行发现严重回归，V4.0继续作为可用稳定版，V4.1 Candidate保留问题记录后修订，不覆盖旧版本。
