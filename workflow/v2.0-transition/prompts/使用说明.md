# 工作流 2.0 使用说明

> 本文件夹是完整的一代升级（2.0），不修改原「总提示词」文件夹。切换后前两部作品的数据与旧版四部对照验证，之后的一切调整回到单变量纪律。

---

## 一、链路总图

```
prompt3-创作版 × N个AI并跑（只管创作，无检查）
        ↓ N份主题池+主题卡
融合审查-选题（1次调用：对比融合 + 22项最终门禁）
        ↓ 终版12池+6卡 → 选定1张主题卡
prompt4-创作版 × 4个AI并跑（只管创作，3条内联硬约束）
        ↓ 4份故事方案
融合审查-故事（1次调用：对比矩阵 + 取长补短融合 + 16项审查含三大预算）
        ↓ 《最终故事创作方案》终稿
prompt5（1个模型：分镜 + 逐张生图提示词 + 发布包装）
        ↓ 若视觉不可行 → 输出《退回建议》退回故事层
成图（自用成图提示词照旧）
        ↓ 发布
复盘统计prompt（发布48小时后运行）
        ↓ 去重档案 + 表现归因 → 回填 prompt3 输入区（闭环）
```

**核心设计**：检查从创作端移到融合端只跑一遍——调用总次数与旧工作流完全一致，创作端更自由，检查不重复。

## 二、每环节模型数量建议

- **prompt3-创作版**：当前 N=4。观察项：下次融合选题时看 4 份主题池的重合率，若超过一半，砍到 N=2（省一半工作量，多样性几乎不损失）。
- **prompt4-创作版**：保持 4 个模型并跑。故事层的创意方差是多模型真正值钱的地方，不要省。
- **融合审查（两个）**：各 1 次调用，建议用你手头最强的模型（审查和融合吃推理能力）。
- **prompt5 / 复盘统计**：各 1 次调用。

## 三、战略定位纪律（最重要的一节）

**学工艺，不学定位。** 对标账号（鼠鼠脑洞批发）占据的是"恐怖悬疑伪实拍"生态位；本账号的爆款象限是**悲壮/荣耀/浪漫的正情绪**（长城、深海光缆）——这是对标未占据的空白象限，且限流风险天然更低。替死影衣的失败可重新解读为：闯进对标的恐怖象限、却没带他们的工艺（零直拍、构图恐怖）。

- 工艺层全抄：道具链、背影语法、零直拍、找茬帧、急停结尾、比例尺、光线时间轴。
- 情绪定位不跟随：选题被恐怖题材吸引时，先问"这个题材能否用正情绪做"（对标做恐惧，我们做敬畏/感动/浪漫）。

**共知母题是第一选题杠杆。** 对标三大爆款（桃花源记/八尺大人/香巴拉）与本账号爆款（长城）共享同一规律：全民认知底本的新编。强预装母题同时解决理解成本（引导词可趋零）、评论引擎（人人有解读资格）、转发话术（社交货币）。长城系列 = 本账号的"国民符号新编"母题库。

## 四、发布运营规则

1. **文案两极公式**：钩子式（一两句+省略号，只写到第5张图）或文学重述式（有独立审美价值的微小说，末行可承担反转）。**禁止平铺直叙的剧情说明书**——对标对照组的头号死因。
2. **标签公式**：IP/母题词（#桃花源记 #克苏鲁 类）+ 题材地域词 + 可蹭平台热点活动标签；每部标配虚构声明「本作品纯属虚构，由AI制作，含有○○元素，请谨慎观看」；**禁止明星标签**（对照组 #王一博探索秘境 是负资产）。
3. **置顶评论是找茬帧的引信**：发布后立即置顶一条引导评论（"数一下我们几个人""注意第X张的背景"）。埋了彩蛋不装引信等于没做。
4. **发布时间**：对标高峰作品集中在上午 8–12 点发布，样本不足仅供参考。

## 五、数据纪律与闭环

1. 每部发布 **48小时后**：记录六率 + 三点留存（3秒/中段/结尾）→ 填入 数据反馈.md → 运行复盘统计prompt → 精简档案回填 prompt3。
2. 限流嫌疑时记录具体信号：推荐量断崖时间点、是否收到违规提示（供平台层归因）。
3. 观众评论按 FB-xxx 编号记入 数据反馈.md，归因层标注（选题/故事/视觉/成图/平台）。
4. **对标监测（每周一次）**：用小书匠采集对标账号新作品与数据，记入 数据反馈.md 新开的「对标动态」分区（记：日期/标题/母题/图数/四项数据/新工艺观察）。对标在以日更速度做实验，他们的新作是免费研发。

## 六、迭代纪律

- 2.0 整体切换算一代升级；上线后先跑 2 部作品看数据，期间**不再改任何提示词**。
- 之后一切修改回到单变量：一次只改一处，看一部作品数据再动下一处。
- 实验作品在选题卡上写明"本次实验变量是什么、验证什么假设"（prompt3 已内置此要求）。
- 排期参考：稳定线（已验证方向/系列）: 新方向 : 实验 ≈ 2 : 1 : 1。

## 七、系列化（长城宇宙）

- 复盘统计prompt 已内置系列标注：系列内续作免全维度去重，只查三项必须全新——核心问题、高潮功能、结尾类型。
- 系列感来自世界观和视觉语言的延续，不来自结构复读。烽火之后的方向示例：同世界观下"守护者需要活人帮它完成一件它做不到的事"，或情绪轴从悲壮换成浪漫/爽感。
- 结尾类型强制轮换已内置到 prompt4-创作版（输入区需填"上一部结尾类型"）。

## 八、操作规范增补（2026-07-26 系统级评估后新增）

以下三项从**人工操作习惯**起步，不写入提示词本体（保持"前两部不改提示词"纪律）；首轮复盘验证有效后再条款化。

1. **锋利保护**（用于两个融合审查环节）：融合与审查的修改意见只许用于修复违规项（门禁/预算/禁令），不得以"更稳妥/更保险"为由削弱创意强度；大胆版路线被淘汰时必须写明淘汰原因是「违规」还是「口味」——口味级淘汰，你有权否决并保留原案。爆款的本质是高概念的锋利，不是没有毛病的平庸。
2. **直觉卡**：每轮选题你有权无理由将 1 个未过推荐的主题捞进「立即开发」，标注"直觉选题"记入数据反馈.md 的直觉卡台账；复盘时长期对比直觉选题与流程选题的成绩——直觉跑赢则流程向你学习，反之你有了信任流程的数据理由。
3. **形态签名清单**（账号垂直度资产，对应抖音账号标签沉淀）：
   - **恒定轴**（每部必须一致）：伪实拍第一人称语法、正情绪象限（敬畏/感动/荣耀/浪漫为主）、图数带宽 22–28、"记录感"画质语言、成年主角。
   - **变化轴**（由去重体系强制变化）：题材、发动机、高潮功能、结尾类型、情绪细分。
   - 判据：观众刷到任何一部，0.5 秒内能认出"是这个账号"；但讲的是全新的故事。
4. **排期对称规则**：已验证方向连续出现 2 部后，第 3 部强制来自新方向（防止探索保底反向滑坡成模板复辟）。
