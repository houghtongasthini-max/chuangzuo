# 第一部分｜模式A：独立故事审查与T2门控

## 四、强制审查顺序

必须按以下顺序执行，不得跳过：

1. 锁定冠军承诺；
2. 比较承诺与02实际故事；
3. 检查FATAL；
4. 检查MAJOR与合法缺口；
5. 判断故事是否已经足够；
6. 只有无FATAL且故事基本成立时，才扫描高权重分叉；
7. 无阻断且无需T2时，才进入关键视觉测试设计。

存在FATAL时，只允许RETURN 01、RETURN 02或PAUSE，不得触发T2。

---

## 五、什么才叫致命问题

只允许以下问题进入FATAL：

### F1｜表层事件不成立

普通用户无法说清“谁或什么遇到了什么”，或异常只能靠长篇意义解释成立。

### F2｜承诺背叛

标题、首图或开头承诺了一个主要结果，但故事实际提供的是另一种作品。

### F3｜核心因果矛盾

关键行动、规则或结果互相冲突，且不修无法理解主要事件。

### F4｜核心事实无法视觉化

最重要的中段、高潮或结果只能靠长篇旁白宣布，没有任何稳定视觉替代。

### F5｜核心动作无可行调度

作品依赖一个高概率无法生成的多人、手部、机械、文字或空间动作，且暂时找不到替代表达。

### F6｜安全、法律、版权或平台阻断

主要入口或主要结果依赖明显不可接受的表达，且无法通过诚实、低敏感的替代调度保留作品核心。

### F7｜作品级换皮

核心异常、关系、行动、中段、高潮、结果和独特表达多数与某一成熟作品高度重合。

### RETURN 01与RETURN 02的边界

- 必须改变一句话表层事件、用户主要等待或标题／首图核心关系才能修复 → RETURN 01；
- 冠军承诺成立，但需要重写人物行动、因果、中段、高潮或结果到达路径 → RETURN 02。

---

## 六、重大但非致命的问题

以下通常属于MAJOR，不应自动阻断：

- 中段继续理由偏弱，但仍有可见过程；
- 角色过多但可以视觉合并；
- 记录来源偏重但可降档；
- 结尾略过满或略开放；
- 某些动机不够充分但不影响表层因果；
- 图片可能影视化；
- 文案将来可能解释过多；
- 视觉需要后期文字。

MAJOR最多列2项，只说明风险，不提供完整重写稿。

若问题会阻断承诺支付，不得用PASS WITH NOTE掩盖，必须RETURN 01或RETURN 02。

---

## 七、高权重分叉门控

只有无FATAL且当前冠军故事已经基本成立时，才执行本节。

依次扫描：

1. 主要观看发动机；
2. 叙事视角；
3. 中段继续方式；
4. 结尾闭合度；
5. 主情绪产品；
6. 记录方式；
7. 人物功能。

最多保留一个最强潜在分叉。

### 真实高权重分叉必须同时满足

1. 一句话表层事件不变；
2. 用户主要等待的结果类别不变；
3. 标题与首图核心关系不变；
4. 只改变一个高权重变量；
5. 会重写中段、高潮、结果到达方式中的至少两项；
6. 两条路线不能简单融合；
7. 替代方向至少改善一个重要维度，同时牺牲另一个重要维度；
8. 不是换职业、地点、道具、人物数量、线索数量、机位或局部节拍。

### POSSIBLE T2

存在潜在单变量方向，但无法确认比较收益是否值得额外调用。创作者可以选择不调用T2，保留当前冠军。

### TRIGGER T2

存在明确、完整、互斥且具有重要取舍价值的单变量方向。建议调用T2，但创作者仍有最终否决权。

### 不得触发的情况

- 只是还能想到另一种写法；
- 当前故事已满足停止条件，替代方案没有明显解决重要问题；
- 可以直接作为局部修改融合；
- 挑战者必须改变冠军承诺；
- 同一变量已经被创作者裁决锁定，且没有新事实。

# 第二部分｜模式A：关键视觉测试设计

## 九、测试数量

默认3张：

1. **入口图**：第一次看见核心异常或不可能关系；
2. **最难图**：最容易失败的动作、接触、群体、空间、文字或连续性节点；
3. **结果图**：高潮或最后结果能否被看见。

低风险项目可2张；高风险项目最多4张。第四张只能用于：

- 连续三张测试；
- 核心人物一致性；
- 多阶段异常状态；
- 另一种必要的视觉语法。

不得为了“更全面”默认测试5—10张。

---

## 十、视觉测试选择原则

优先测试真正可能阻断生产的画面，而不是最容易的普通场景。

每张测试必须回答：

- 第一眼必须看懂什么；
- 摄影机是谁的、为什么在这里；
- 人物或物件如何与环境发生接触；
- 哪些文字必须后期；
- 失败后能否换调度；
- 通过标准是什么。

### 高风险动作优先级

- 手与物件的准确接触；
- 纸张、屏幕和签字方向；
- 多人物递交或共同动作；
- 机械插拔、连接、旋转和扣合；
- 同一人物前后状态；
- 大群体与复杂天气；
- 巨物落地、承重、挤压、浸水和投影；
- 需要准确数字或长文字的画面。

---

## 十一、视觉语法

选择最低充分的一种主语法：

### W1｜粗粝亲历

手机、同行拍摄、行车记录、直播截帧。允许轻微偏斜、遮挡、自动曝光波动和不完整取景。

### W2｜工作纪录

工作手机、固定监控、无人机、任务相机。设备只在提供新尺度、位置或介质时出现。

### W3｜档案复原

旧胶片、旧相机、回收存储、受损视频或多源资料。不同介质必须有稳定差异，而不是统一滤镜。

可以混合，但只能有一种主语法。辅助来源必须带来主语法无法提供的新能力。

---

## 十二、测试提示词协议

每张提示词按以下顺序写：

1. 画幅与记录设备；
2. 第一眼主体；
3. 可见动作或状态；
4. 现实环境与尺度；
5. 异常与地面、物件、光线、水、风、烟、人物的接触；
6. 现场光源和自然成像；
7. 必要连续性锚点。

使用纯正向可见描述。

不把整部故事、人物全部过去和大量禁止词塞进单张提示。

复杂文字只描述载体、朝向、行数和留白，准确文字后期添加。

---

## 十三、每张测试至少两种替代调度

若核心动作难生成，先提供替代方式，例如：

- 直接动作 → 动作起点＋动作结果；
- 多人同时接触 → 前后两张状态；
- 准确文字 → 后期排版；
- 大群体 → 前景代表人物＋远景规模；
- 复杂机械 → 局部接触特写＋结果状态；
- 正面冲突 → 现场痕迹或物件后果；
- 上帝视角 → 可达机位或屏幕中的远景；
- 抽象意义 → 具体物件、位置或环境变化。

视觉失败不能只回答“再写得更详细”。

# 第三部分｜模式B：实际测试图审查

## 十五、审查维度

逐张检查：

1. 手机尺寸能否一眼看懂核心事实；
2. 人物、物件和动作是否符合身体与物理逻辑；
3. 异常是否真实接触环境，而不是贴在背景上；
4. 摄影机位置是否可能存在；
5. 构图是否自然，是否每张都像影视海报；
6. 角色、服装、物件和空间是否可继续追踪；
7. 复杂文字是否已正确留给后期；
8. 结果图是否无需长文即可理解；
9. 是否存在更简单、更稳定的调度；
10. 当前失败来自图像波动、视觉调度还是故事本身。

---

## 十六、模式B决策

- **PASS／LOCK**：进入04；
- **REVISE LOCAL**：局部返修1—3张；
- **RETURN VISUAL**：改变视觉调度，不改故事；
- **RETURN 02**：故事动作、空间或结果本身不可画；
- **RETURN 01**：标题／入口／结果承诺没有强视觉；
- **PAUSE**：当前模型和成本暂时不适合，但不否定题材价值。

### 两轮规则

- 第1轮失败：优先换调度或局部返修；
- 第2轮仍失败：必须判断返回VISUAL、02、01或PAUSE；
