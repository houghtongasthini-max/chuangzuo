## 字段标记

- **【固定】**：当前 V4.0 默认设置。除非工作流版本或长期制作条件改变，否则不需要每篇修改。
- **【周期】**：每 4—6 篇已发布作品或每季度更新。
- **【单篇必填】**：每个新项目都需要填写。
- **【条件填写】**：有真实信息时填写；没有就写“暂无”或“缺失”，不得编造。
- **【AI生成后回填】**：由上一阶段输出产生，人工确认后填入。
